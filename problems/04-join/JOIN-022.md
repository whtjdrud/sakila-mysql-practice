# JOIN-022. 영화 목록 뷰 활용

**유형:** 조인 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `VIEW`

## 문제

Sakila 에 미리 만들어진 뷰 `film_list` 에서 장르가 `Horror` 이고 등급이 `R` 인 영화의 `FID`, `title`, `price`, `actors` 를 조회하세요.
`FID` 순.

**사용 테이블:** `film_list` (뷰)

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT FID, title, price, actors
FROM film_list
WHERE category = 'Horror' AND rating = 'R'
ORDER BY FID;
```

## 해설

**뷰(VIEW)** 는 저장된 SELECT 문입니다. 복잡한 조인을 숨겨 주지만, 내부적으로는 매번 원래 쿼리가 실행됩니다.
`SHOW CREATE VIEW film_list;` 로 뷰의 정의를 보고 직접 조인으로 다시 써 보세요.
