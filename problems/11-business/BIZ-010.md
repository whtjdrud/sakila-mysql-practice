# BIZ-010. 해외 확장 후보 국가

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `시장 분석` `1인당 매출` `HAVING`

## 문제

> **요청자:** 전략기획팀 · **용도:** 신규 매장 후보 국가 선정

고객이 **10명 이상**인 국가 중 **고객 1인당 매출**이 높은 5개국을 뽑아 주세요.

**요구 컬럼:** `country`, `customers`, `revenue`, `revenue_per_customer`(소수 2자리), `rentals_per_customer`(소수 2자리)

**정렬:** `revenue_per_customer` 내림차순, `country` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH cust AS (
    SELECT c.customer_id, co.country
    FROM customer c
    JOIN address a  ON a.address_id  = c.address_id
    JOIN city ci    ON ci.city_id    = a.city_id
    JOIN country co ON co.country_id = ci.country_id
), rev AS (
    SELECT customer_id, SUM(amount) AS paid FROM payment GROUP BY customer_id
), rent AS (
    SELECT customer_id, COUNT(*) AS rentals FROM rental GROUP BY customer_id
)
SELECT cu.country, COUNT(*) AS customers, SUM(rv.paid) AS revenue,
       ROUND(SUM(rv.paid) / COUNT(*), 2) AS revenue_per_customer,
       ROUND(SUM(rt.rentals) / COUNT(*), 2) AS rentals_per_customer
FROM cust cu
JOIN rev rv  ON rv.customer_id = cu.customer_id
JOIN rent rt ON rt.customer_id = cu.customer_id
GROUP BY cu.country
HAVING COUNT(*) >= 10
ORDER BY revenue_per_customer DESC, cu.country
LIMIT 5;
```

## 해설

"최소 표본 수(10명 이상)" 조건은 **작은 국가의 우연한 고액 고객 1명**이 순위를 왜곡하는 것을 막습니다. 비율 지표 순위에는 항상 최소 표본 조건을 두세요.
