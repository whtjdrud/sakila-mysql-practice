# BIZ-013. 피크 시간대 인력 배치

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `요일` `시간대` `평균` `운영`

## 문제

> **요청자:** 매장 운영팀 · **용도:** 아르바이트 근무표 작성

**요일 × 시간대**별 **하루 평균** 대여 건수를 구해, 가장 바쁜 5개 슬롯을 알려 주세요.
평균의 분모는 "그 요일 중 대여가 1건 이상 있었던 날의 수" 입니다 (2006년 제외).

**요구 컬럼:** `day_name`, `hour`, `days`(분모 날짜 수), `total_rentals`, `avg_per_day`(소수 1자리)

**정렬:** `avg_per_day` 내림차순, `day_name`, `hour` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH base AS (
    SELECT DATE(rental_date) AS d, DAYNAME(rental_date) AS day_name, HOUR(rental_date) AS hour
    FROM rental
    WHERE rental_date < '2006-01-01'
), days AS (
    SELECT day_name, COUNT(DISTINCT d) AS days FROM base GROUP BY day_name
)
SELECT b.day_name, b.hour, dy.days, COUNT(*) AS total_rentals,
       ROUND(COUNT(*) / dy.days, 1) AS avg_per_day
FROM base b
JOIN days dy ON dy.day_name = b.day_name
GROUP BY b.day_name, b.hour, dy.days
ORDER BY avg_per_day DESC, b.day_name, b.hour
LIMIT 5;
```

</details>

## 해설

"합계"로 비교하면 데이터에 많이 등장한 요일이 유리합니다. **하루 평균**으로 바꿔야 요일 간 공정 비교가 됩니다.
분모를 "그 요일·시간대에 대여가 있었던 날" 로 잡으면 0건인 날이 빠져 평균이 부풀려집니다 — 그래서 분모는 요일 단위로 따로 셌습니다.
