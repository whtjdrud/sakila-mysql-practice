# BIZ-009. 데이터 품질 점검 리포트

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `데이터 품질` `UNION ALL` `검증`

## 문제

> **요청자:** 데이터팀 · **용도:** 월간 데이터 품질 점검

아래 점검 항목별 **위반 건수**를 한 표로 주세요. 위반이 0건인 항목도 표시해야 합니다.

| check_name | 위반 조건 |
|---|---|
| `반납일 < 대여일` | rental.return_date < rental.rental_date |
| `결제 금액 0 이하` | payment.amount <= 0 |
| `대여 없는 결제` | payment.rental_id 가 NULL 이거나 rental 에 없음 |
| `결제·대여 고객 불일치` | payment.customer_id ≠ 연결된 rental.customer_id |
| `이메일 형식 오류` | customer.email 이 `%_@_%._%` 패턴이 아님 |
| `중복 이메일` | 같은 이메일을 쓰는 고객 중 두 번째 이후 (고객 수 − 고유 이메일 수) |

**요구 컬럼:** `check_name`, `violations` — 위 표 순서

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT '반납일 < 대여일' AS check_name, COUNT(*) AS violations
FROM rental WHERE return_date < rental_date
UNION ALL
SELECT '결제 금액 0 이하', COUNT(*) FROM payment WHERE amount <= 0
UNION ALL
SELECT '대여 없는 결제', COUNT(*) FROM payment p
WHERE NOT EXISTS (SELECT 1 FROM rental r WHERE r.rental_id = p.rental_id)
UNION ALL
SELECT '결제·대여 고객 불일치', COUNT(*) FROM payment p
JOIN rental r ON r.rental_id = p.rental_id
WHERE p.customer_id <> r.customer_id
UNION ALL
SELECT '이메일 형식 오류', COUNT(*) FROM customer WHERE email IS NULL OR email NOT LIKE '%_@_%._%'
UNION ALL
SELECT '중복 이메일', COUNT(*) - COUNT(DISTINCT email) FROM customer;
```

</details>

## 해설

품질 점검 쿼리는 **"위반 건수 = 0 이 정상"** 인 형태로 만들어 두면 매일 자동 실행해 0 이 아닌 항목만 알림을 보내기 좋습니다.
`COUNT(*)` 는 조건에 맞는 행이 없어도 0 을 돌려주므로 UNION ALL 로 이어 붙이면 0건 항목도 자연스럽게 표시됩니다.
(이 문제는 행 순서를 채점하지 않습니다.)
