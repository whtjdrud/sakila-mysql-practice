# BIZ-015. 액션 신작 안내 대상

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `선호 장르` `비중` `타깃팅`

## 문제

> **요청자:** 마케팅팀 · **용도:** 액션 신작 입고 안내 문자

다음 조건을 모두 만족하는 활성 고객을 뽑아 주세요.

- 2005-08-01 이후(2006년 제외) 대여가 있음
- 전체 대여 중 **Action 비중 15% 이상**
- 전체 대여 **20회 이상** (비중이 우연히 높은 소수 대여 고객 제외)

**요구 컬럼:** `customer_id`, `name`, `rentals`, `action_rentals`, `action_pct`(소수 1자리)

**정렬:** `action_pct` 내림차순, `customer_id` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH r AS (
    SELECT rt.customer_id, rt.rental_date, c.name AS category
    FROM rental rt
    JOIN inventory i      ON i.inventory_id = rt.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
), agg AS (
    SELECT customer_id, COUNT(*) AS rentals,
           SUM(category = 'Action') AS action_rentals,
           MAX(rental_date >= '2005-08-01' AND rental_date < '2006-01-01') AS recent
    FROM r
    GROUP BY customer_id
)
SELECT a.customer_id, CONCAT(cu.first_name, ' ', cu.last_name) AS name,
       a.rentals, a.action_rentals, ROUND(100 * a.action_rentals / a.rentals, 1) AS action_pct
FROM agg a
JOIN customer cu ON cu.customer_id = a.customer_id
WHERE cu.active = 1
  AND a.recent = 1
  AND a.rentals >= 20
  AND a.action_rentals / a.rentals >= 0.15
ORDER BY action_pct DESC, a.customer_id;
```

## 해설

`MAX(조건)` 은 "한 번이라도 조건을 만족했는가" (존재 여부) 를 집계 안에서 판정하는 트릭입니다. EXISTS 서브쿼리를 따로 쓰지 않아도 됩니다.
타깃팅 조건은 **최근성 + 선호도 + 최소 활동량** 의 조합이 기본입니다.
