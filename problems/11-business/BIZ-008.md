# BIZ-008. 대여료 조정 후보

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `가격 정책` `PERCENT_RANK` `후보 추출`

## 문제

> **요청자:** 가격전략팀 · **용도:** 다음 분기 대여료 조정안

재고가 있는 영화를 대여 횟수로 백분위(`PERCENT_RANK`, 대여 횟수 오름차순)를 매겨 다음 후보를 뽑아 주세요.

- **인상 후보:** 대여료 0.99 이면서 백분위 0.8 이상 (많이 빌려 감)
- **인하 후보:** 대여료 4.99 이면서 백분위 0.2 미만 (거의 안 빌려 감)

**요구 컬럼:** `proposal`(`인상`/`인하`), `title`, `rental_rate`, `rentals`, `pct_rank`(소수 3자리)

**정렬:** 인상 → 인하, 그 안에서 `rentals` 내림차순, `title` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH fr AS (
    SELECT f.title, f.rental_rate, COUNT(*) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    GROUP BY f.film_id, f.title, f.rental_rate
), ranked AS (
    SELECT *, PERCENT_RANK() OVER (ORDER BY rentals) AS pr
    FROM fr
)
SELECT CASE WHEN rental_rate = 0.99 THEN '인상' ELSE '인하' END AS proposal,
       title, rental_rate, rentals, ROUND(pr, 3) AS pct_rank
FROM ranked
WHERE (rental_rate = 0.99 AND pr >= 0.8)
   OR (rental_rate = 4.99 AND pr < 0.2)
ORDER BY FIELD(proposal, '인상', '인하'), rentals DESC, title;
```

## 해설

백분위를 **전체 영화 기준**으로 먼저 매긴 뒤 대여료 조건으로 거릅니다. 대여료로 먼저 거르면 "0.99 영화 중 상위 20%" 라는 다른 질문이 됩니다.
`PERCENT_RANK` 는 동점에 같은 값을 주므로 경계(0.8) 근처 동점 영화가 함께 포함·제외됩니다.
