# BIZ-004. 연체 독촉 대상과 예상 연체료

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `연체` `비즈니스 규칙` `LEAST`

## 문제

> **요청자:** 매장 운영팀 · **용도:** 연체 고객 독촉 전화

기준 시각 `2006-02-20 00:00:00` 에 **미반납이면서 반납 예정일(대여일 + 대여 기간)이 지난** 대여를 고객별로 정리해 주세요.
예상 연체료는 **연체 1일당 1.00, 단 DVD 교체 비용(`replacement_cost`)을 넘지 않음**으로 계산합니다. 연체일은 `DATEDIFF(기준 시각, 반납 예정일)`.

**요구 컬럼:** `customer_id`, `name`, `phone`, `overdue_items`, `max_overdue_days`, `expected_fee`

**정렬:** 예상 연체료 내림차순, `customer_id` 순 · **상위 15명**

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH overdue AS (
    SELECT r.customer_id,
           DATEDIFF('2006-02-20 00:00:00', r.rental_date + INTERVAL f.rental_duration DAY) AS overdue_days,
           f.replacement_cost
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.return_date IS NULL
      AND r.rental_date + INTERVAL f.rental_duration DAY < '2006-02-20 00:00:00'
)
SELECT c.customer_id, CONCAT(c.first_name, ' ', c.last_name) AS name, a.phone,
       COUNT(*) AS overdue_items,
       MAX(o.overdue_days) AS max_overdue_days,
       SUM(LEAST(o.overdue_days * 1.00, o.replacement_cost)) AS expected_fee
FROM overdue o
JOIN customer c ON c.customer_id = o.customer_id
JOIN address a  ON a.address_id  = c.address_id
GROUP BY c.customer_id, c.first_name, c.last_name, a.phone
ORDER BY expected_fee DESC, c.customer_id
LIMIT 15;
```

## 해설

"1일당 1달러, 최대 교체 비용까지" 같은 **상한이 있는 비즈니스 규칙**은 `LEAST(계산값, 상한)` 으로 표현합니다. 하한은 `GREATEST`.
미반납 183건 중 182건은 2006-02-14 대여라, 기준을 02-15 로 잡으면 연체가 1건뿐입니다. 02-20 기준이면 대여 기간이 3~5일인 영화가 연체로 잡혀 118건이 됩니다.
"미반납 = 연체" 가 아니라는 점, 그리고 **기준 시각에 따라 대상이 크게 바뀐다**는 점을 요청자에게 설명할 수 있어야 합니다.
