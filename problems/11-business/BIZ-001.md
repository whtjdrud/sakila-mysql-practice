# BIZ-001. 휴면 고객 리스트 추출

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `고객 추출` `기준일` `마케팅`

## 문제

> **요청자:** 마케팅팀 · **용도:** 휴면 고객 재방문 이메일 발송

2005년 데이터만 보고, 기준일 `2005-08-24` 에 **마지막 대여로부터 3일 이상 지난** 활성 고객(`active = 1`) 리스트를 뽑아 주세요.

**요구 컬럼**
- `customer_id`, `name`(이름 성), `email`
- `last_rental`(마지막 대여 일시), `days_inactive`(기준일 − 마지막 대여 **날짜**)
- `total_paid`(2005년 결제 합계)

**정렬:** 휴면 일수 내림차순, 결제 합계 내림차순, `customer_id` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH last AS (
    SELECT customer_id, MAX(rental_date) AS last_rental
    FROM rental
    WHERE rental_date < '2006-01-01'
    GROUP BY customer_id
), paid AS (
    SELECT customer_id, SUM(amount) AS total_paid
    FROM payment
    WHERE payment_date < '2006-01-01'
    GROUP BY customer_id
)
SELECT c.customer_id,
       CONCAT(c.first_name, ' ', c.last_name) AS name,
       c.email,
       l.last_rental,
       DATEDIFF('2005-08-24', l.last_rental) AS days_inactive,
       p.total_paid
FROM customer c
JOIN last l      ON l.customer_id = c.customer_id
LEFT JOIN paid p ON p.customer_id = c.customer_id
WHERE c.active = 1
  AND DATEDIFF('2005-08-24', l.last_rental) >= 3
ORDER BY days_inactive DESC, total_paid DESC, c.customer_id;
```

## 해설

실무 추출 요청은 **기준일·기간·대상 조건**을 명확히 해야 합니다. "휴면"이 마지막 대여 기준인지 결제 기준인지, 비활성 고객을 포함할지를 요청자와 먼저 맞추세요.
이메일 발송용 리스트라면 `active = 1` 같은 **수신 가능 조건**을 빠뜨리지 않는 것이 중요합니다.
결제 합계는 정렬·우선순위용이라 LEFT JOIN 으로 붙였습니다 (결제가 없어도 리스트에서 빠지면 안 됨).
