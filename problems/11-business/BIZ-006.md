# BIZ-006. 직원 월별 인센티브 계산

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `인센티브` `구간 계산` `GREATEST`

## 문제

> **요청자:** 인사팀 · **용도:** 2005년 월별 성과급 지급

직원별·월별 인센티브를 계산해 주세요. 결제 처리 직원(`payment.staff_id`), 결제일 기준.

- **기본 인센티브** = 처리 결제액의 1%
- **건수 보너스** = 처리 건수가 1,000건을 넘으면 초과 1건당 0.10
- 2005년만, 금액은 모두 소수 2자리 반올림

**요구 컬럼:** `month`, `staff_name`, `payments`, `amount`, `base_incentive`, `volume_bonus`, `total_incentive`

**정렬:** `month`, `staff_name` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DATE_FORMAT(p.payment_date, '%Y-%m') AS month,
       CONCAT(s.first_name, ' ', s.last_name) AS staff_name,
       COUNT(*) AS payments,
       SUM(p.amount) AS amount,
       ROUND(SUM(p.amount) * 0.01, 2) AS base_incentive,
       ROUND(GREATEST(COUNT(*) - 1000, 0) * 0.10, 2) AS volume_bonus,
       ROUND(SUM(p.amount) * 0.01 + GREATEST(COUNT(*) - 1000, 0) * 0.10, 2) AS total_incentive
FROM payment p
JOIN staff s ON s.staff_id = p.staff_id
WHERE p.payment_date < '2006-01-01'
GROUP BY month, s.staff_id, s.first_name, s.last_name
ORDER BY month, staff_name;
```

## 해설

"N 초과분" 은 `GREATEST(값 − N, 0)` 이 정석입니다. 그냥 `값 − N` 을 쓰면 실적이 적은 달에 **음수 보너스**가 생깁니다.
합계 금액은 **반올림 전 값으로 더한 뒤 반올림**해야 단수 차이가 안 생깁니다 (각각 반올림 후 더하면 1센트 차이 가능).
