# BIZ-005. 매장 간 재고 재배치 추천

**유형:** 실무 요청 · **난이도:** ★★★★★ 최고급 · **태그:** `재고` `회전율` `재배치` `다중 CTE`

## 문제

> **요청자:** 물류팀 · **용도:** 다음 주 매장 간 DVD 이동 계획

같은 영화의 **재고 1장당 대여 횟수(회전율)** 가 매장 간에 크게 다르면, 회전율이 낮은 매장에서 높은 매장으로 1장을 옮기려 합니다.

**조건**
- 두 매장 모두 재고가 있고, 회전율이 낮은 매장의 재고가 **2장 이상**인 영화
- 회전율 = 그 매장 재고의 대여 횟수 / 그 매장 재고 장수 (대여 위치는 `inventory.store_id`)
- 회전율 차이(높은 쪽 − 낮은 쪽) 상위 10편

**요구 컬럼:** `title`, `from_store`, `to_store`, `from_copies`, `from_turnover`, `to_turnover`(소수 2자리), `gap`(소수 2자리)

**정렬:** `gap` 내림차순, `title` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH inv AS (
    SELECT store_id, film_id, COUNT(*) AS copies
    FROM inventory
    GROUP BY store_id, film_id
), rent AS (
    SELECT i.store_id, i.film_id, COUNT(*) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.store_id, i.film_id
), turn AS (
    SELECT inv.store_id, inv.film_id, inv.copies,
           COALESCE(rent.rentals, 0) / inv.copies AS turnover
    FROM inv
    LEFT JOIN rent ON rent.store_id = inv.store_id AND rent.film_id = inv.film_id
)
SELECT f.title, lo.store_id AS from_store, hi.store_id AS to_store, lo.copies AS from_copies,
       ROUND(lo.turnover, 2) AS from_turnover, ROUND(hi.turnover, 2) AS to_turnover,
       ROUND(hi.turnover - lo.turnover, 2) AS gap
FROM turn lo
JOIN turn hi ON hi.film_id = lo.film_id AND hi.store_id <> lo.store_id AND hi.turnover > lo.turnover
JOIN film f  ON f.film_id = lo.film_id
WHERE lo.copies >= 2
ORDER BY gap DESC, f.title
LIMIT 10;
```

## 해설

재배치 추천은 **(영화 × 매장) 단위의 회전율**을 만든 뒤 같은 영화끼리 셀프 조인해 비교합니다.
"재고가 2장 이상일 때만 옮긴다" 같은 **운영 제약**을 조건에 넣지 않으면 마지막 1장을 빼 가는 추천이 나옵니다. 실무 추천 쿼리는 항상 제약 조건을 먼저 확인하세요.
