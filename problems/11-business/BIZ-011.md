# BIZ-011. 주간 리포트 (전주 대비)

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `주간` `YEARWEEK` `WoW`

## 문제

> **요청자:** 영업팀 · **용도:** 주간 회의

2005년 7~8월의 **주별**(월요일 시작) 대여 건수와 전주 대비 증감을 주세요. 대여가 있는 주만 표시합니다.

**요구 컬럼:** `week_start`(그 주 월요일 날짜), `rentals`, `prev_rentals`, `wow_pct`(소수 1자리)

**정렬:** `week_start` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH w AS (
    SELECT DATE(rental_date) - INTERVAL WEEKDAY(rental_date) DAY AS week_start, COUNT(*) AS rentals
    FROM rental
    WHERE rental_date >= '2005-07-01' AND rental_date < '2005-09-01'
    GROUP BY week_start
)
SELECT week_start, rentals,
       LAG(rentals) OVER (ORDER BY week_start) AS prev_rentals,
       ROUND(100 * (rentals / LAG(rentals) OVER (ORDER BY week_start) - 1), 1) AS wow_pct
FROM w
ORDER BY week_start;
```

</details>

## 해설

주 시작일은 `날짜 − WEEKDAY(날짜)`(월요일=0) 로 구하면 사람이 읽기 좋은 날짜가 됩니다. `YEARWEEK()` 는 숫자(202527)라 리포트에는 불친절합니다.
⚠️ 결과를 보면 07-18 주와 08-08 주가 **통째로 없습니다**(대여 0건). 그래서 LAG 의 "전주" 가 실제로는 2주 전이 되어 WoW 가 왜곡됩니다.
또 주마다 데이터가 있는 날 수가 달라 건수 자체가 크게 출렁입니다. 실무라면 주 달력을 먼저 만들어 빈 주를 0으로 채우고(CTE-006 참고), 주당 데이터 일수도 함께 보고해야 합니다.
