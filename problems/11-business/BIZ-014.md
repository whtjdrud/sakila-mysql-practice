# BIZ-014. 장르별 재고 적정성

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `재고 점유율` `수요 점유율` `비교`

## 문제

> **요청자:** 구매팀 · **용도:** 다음 분기 장르별 구매 예산 배분

장르별 **재고 점유율**(전체 재고 중 비율)과 **대여 점유율**(전체 대여 중 비율)을 비교해, 차이(대여 − 재고, %p)를 주세요.
양수면 수요 대비 재고가 부족한 장르입니다.

**요구 컬럼:** `category`, `stock_pct`, `rental_pct`, `gap_pp` (모두 소수 2자리), `judgement`(`부족` gap ≥ 0.3 / `과잉` gap ≤ −0.3 / `적정`)

**정렬:** `gap_pp` 내림차순, `category` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH s AS (
    SELECT fc.category_id, COUNT(*) AS copies
    FROM inventory i JOIN film_category fc ON fc.film_id = i.film_id
    GROUP BY fc.category_id
), r AS (
    SELECT fc.category_id, COUNT(*) AS rentals
    FROM rental rt
    JOIN inventory i      ON i.inventory_id = rt.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    GROUP BY fc.category_id
), x AS (
    SELECT c.name AS category,
           100 * s.copies  / SUM(s.copies)  OVER () AS stock_pct,
           100 * r.rentals / SUM(r.rentals) OVER () AS rental_pct
    FROM category c
    JOIN s ON s.category_id = c.category_id
    JOIN r ON r.category_id = c.category_id
)
SELECT category, ROUND(stock_pct, 2) AS stock_pct, ROUND(rental_pct, 2) AS rental_pct,
       ROUND(rental_pct - stock_pct, 2) AS gap_pp,
       CASE WHEN rental_pct - stock_pct >= 0.3 THEN '부족'
            WHEN rental_pct - stock_pct <= -0.3 THEN '과잉'
            ELSE '적정' END AS judgement
FROM x
ORDER BY gap_pp DESC, category;
```

## 해설

비율끼리의 차이는 **%p(퍼센트포인트)** 입니다. "5% 에서 6%" 는 1%p 증가이자 20% 증가 — 리포트에서 둘을 혼동하지 마세요.
판정 기준(±0.3%p)은 반올림 전 값으로 비교해야 경계에서 표시값과 판정이 어긋나지 않습니다.
