# BIZ-003. 월간 경영 KPI 리포트

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `KPI` `월간 리포트` `LAG`

## 문제

> **요청자:** 경영지원팀 · **용도:** 월간 경영회의 자료

2005-05 ~ 2005-08 의 월별 핵심 지표를 한 표로 주세요.

| 컬럼 | 정의 |
|---|---|
| `month` | YYYY-MM |
| `rentals` | 그 달 대여 건수 (대여일 기준) |
| `revenue` | 그 달 결제 합계 (결제일 기준) |
| `active_customers` | 그 달 1회 이상 대여한 고객 수 |
| `arpu` | revenue / active_customers (소수 2자리) |
| `revenue_mom_pct` | 전월 대비 매출 증감률 % (소수 1자리, 첫 달은 NULL) |

**정렬:** `month` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH r AS (
    SELECT DATE_FORMAT(rental_date, '%Y-%m') AS month,
           COUNT(*) AS rentals, COUNT(DISTINCT customer_id) AS active_customers
    FROM rental
    WHERE rental_date >= '2005-05-01' AND rental_date < '2005-09-01'
    GROUP BY month
), p AS (
    SELECT DATE_FORMAT(payment_date, '%Y-%m') AS month, SUM(amount) AS revenue
    FROM payment
    WHERE payment_date >= '2005-05-01' AND payment_date < '2005-09-01'
    GROUP BY month
)
SELECT r.month, r.rentals, p.revenue, r.active_customers,
       ROUND(p.revenue / r.active_customers, 2) AS arpu,
       ROUND(100 * (p.revenue / LAG(p.revenue) OVER (ORDER BY r.month) - 1), 1) AS revenue_mom_pct
FROM r
JOIN p ON p.month = r.month
ORDER BY r.month;
```

</details>

## 해설

대여 건수는 **대여일**, 매출은 **결제일** 기준으로 서로 다른 날짜 컬럼을 씁니다. 월말 대여의 결제가 다음 달에 잡히면 두 지표의 기간이 어긋날 수 있다는 점을 리포트 각주로 남기세요.
서로 다른 테이블의 지표는 **각각 월 단위로 집계한 뒤** 조인해야 팬아웃이 생기지 않습니다.
