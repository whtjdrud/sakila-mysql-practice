# BIZ-020. 교차 판매 - Action 고객이 함께 보는 장르

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `교차 판매` `고객 비율` `장바구니`

## 문제

> **요청자:** MD팀 · **용도:** Action 코너 옆에 둘 장르 결정

Action 영화를 **한 번이라도** 빌린 고객들이, Action 외에 **가장 많이 빌린 고객 수 기준** 상위 3개 장르를 알려 주세요.
비교를 위해 **전체 고객** 중 그 장르를 빌린 고객 비율도 함께 주세요.

**요구 컬럼:** `category`, `action_customers_pct`(Action 고객 중 해당 장르를 빌린 비율), `all_customers_pct`, `lift`(앞 ÷ 뒤, 소수 2자리) — 비율은 소수 1자리

**정렬:** `action_customers_pct` 내림차순, `category` 순 · 상위 3개

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH cc AS (
    SELECT DISTINCT r.customer_id, c.name AS category
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
), flag AS (
    SELECT customer_id, MAX(category = 'Action') AS is_action
    FROM cc
    GROUP BY customer_id
), totals AS (
    SELECT SUM(is_action) AS n_action, COUNT(*) AS n_all FROM flag
)
SELECT cc.category,
       ROUND(100 * SUM(f.is_action) / t.n_action, 1) AS action_customers_pct,
       ROUND(100 * COUNT(*) / t.n_all, 1) AS all_customers_pct,
       ROUND((SUM(f.is_action) / t.n_action) / (COUNT(*) / t.n_all), 2) AS lift
FROM cc
JOIN flag f ON f.customer_id = cc.customer_id
CROSS JOIN totals t
WHERE cc.category <> 'Action'
GROUP BY cc.category, t.n_action, t.n_all
ORDER BY action_customers_pct DESC, cc.category
LIMIT 3;
```

</details>

## 해설

"Action 고객의 90% 가 Drama 도 빌렸다" 는 그 자체로는 의미가 약합니다. **전체 고객도 88% 가 Drama 를 빌렸다면** 연관이 거의 없는 것이죠.
그래서 기준선(`all_customers_pct`) 대비 배수인 **lift** 를 함께 보고해야 합니다. Sakila 처럼 고객당 대여가 많은 데이터에서는 대부분의 장르 비율이 높게 나옵니다.
고객마다 "Action 고객인가" 플래그(`MAX(category = 'Action')`)를 먼저 만들어 조인하면, 분자·분모를 같은 기준으로 셀 수 있습니다.
