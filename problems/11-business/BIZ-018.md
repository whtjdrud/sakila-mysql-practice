# BIZ-018. 신규 고객 2주 내 재방문율

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `온보딩` `재방문` `첫 대여`

## 문제

> **요청자:** 그로스팀 · **용도:** 신규 고객 온보딩 개선

고객의 **첫 대여 매장**(재고 기준)별로, 첫 대여 후 **14일 이내**(첫 대여 시각 초과 ~ 14일 이하)에 다시 대여한 고객의 비율을 구해 주세요.

**요구 컬럼:** `first_store`, `new_customers`, `returned_14d`, `return_rate_pct`(소수 1자리)

**정렬:** `first_store` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH ordered AS (
    SELECT r.customer_id, r.rental_date, i.store_id,
           ROW_NUMBER() OVER (PARTITION BY r.customer_id ORDER BY r.rental_date, r.rental_id) AS rn
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
), firsts AS (
    SELECT customer_id, rental_date AS first_at, store_id AS first_store
    FROM ordered WHERE rn = 1
)
SELECT f.first_store,
       COUNT(*) AS new_customers,
       SUM(EXISTS (SELECT 1 FROM rental r2
                    WHERE r2.customer_id = f.customer_id
                      AND r2.rental_date > f.first_at
                      AND r2.rental_date <= f.first_at + INTERVAL 14 DAY)) AS returned_14d,
       ROUND(100 * AVG(EXISTS (SELECT 1 FROM rental r2
                    WHERE r2.customer_id = f.customer_id
                      AND r2.rental_date > f.first_at
                      AND r2.rental_date <= f.first_at + INTERVAL 14 DAY)), 1) AS return_rate_pct
FROM firsts f
GROUP BY f.first_store
ORDER BY f.first_store;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| first_store | new_customers | returned_14d | return_rate_pct |
|---|---|---|---|
| 1 | 301 | 210 | 69.8 |
| 2 | 298 | 209 | 70.1 |

> 총 2행

</details>

## 해설

`EXISTS(...)` 는 MySQL 에서 1/0 값이라 `SUM`, `AVG` 안에 넣어 비율을 바로 구할 수 있습니다.
"첫 대여와 같은 시각의 두 번째 대여" 는 재방문이 아니므로 `> first_at` (초과) 로 정의했습니다 — 같은 방문에서 여러 장 빌린 경우를 재방문으로 세지 않기 위해서입니다.
