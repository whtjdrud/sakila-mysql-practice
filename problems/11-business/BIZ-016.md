# BIZ-016. 두 매장 운영 지표 비교표

**유형:** 실무 요청 · **난이도:** ★★★★☆ 고급 · **태그:** `매장 비교` `언피벗` `지표 정의`

## 문제

> **요청자:** 대표이사 · **용도:** "두 매장 중 어디가 더 잘 운영되나?"

두 매장(재고 `inventory.store_id` 기준)의 지표를 **행 = 지표, 열 = 매장** 형태로 주세요.

| metric | 정의 |
|---|---|
| `대여 건수` | 대여 수 |
| `건당 매출` | 대여에 연결된 결제 합계 / 대여 수 (소수 2자리) |
| `고객당 대여` | 대여 수 / 고유 고객 수 (소수 2자리) |
| `연체율(%)` | 반납된 대여 중 대여 기간 초과 비율 (소수 1자리) |
| `평균 대여일` | 반납된 대여의 평균 `DATEDIFF` (소수 2자리) |

**요구 컬럼:** `metric`, `store_1`, `store_2` — 위 표 순서

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH base AS (
    SELECT i.store_id, r.rental_id, r.customer_id, r.rental_date, r.return_date, f.rental_duration
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
), pay AS (
    SELECT b.store_id, SUM(p.amount) AS revenue
    FROM base b JOIN payment p ON p.rental_id = b.rental_id
    GROUP BY b.store_id
), m AS (
    SELECT b.store_id,
           COUNT(*) AS rentals,
           ROUND(pay.revenue / COUNT(*), 2) AS rev_per_rental,
           ROUND(COUNT(*) / COUNT(DISTINCT b.customer_id), 2) AS rentals_per_customer,
           ROUND(100 * AVG(CASE WHEN b.return_date IS NOT NULL
                                THEN DATEDIFF(b.return_date, b.rental_date) > b.rental_duration END), 1) AS late_pct,
           ROUND(AVG(DATEDIFF(b.return_date, b.rental_date)), 2) AS avg_days
    FROM base b
    JOIN pay ON pay.store_id = b.store_id
    GROUP BY b.store_id, pay.revenue
)
SELECT '대여 건수' AS metric, SUM(IF(store_id = 1, rentals, 0)) AS store_1, SUM(IF(store_id = 2, rentals, 0)) AS store_2 FROM m
UNION ALL SELECT '건당 매출', SUM(IF(store_id = 1, rev_per_rental, 0)), SUM(IF(store_id = 2, rev_per_rental, 0)) FROM m
UNION ALL SELECT '고객당 대여', SUM(IF(store_id = 1, rentals_per_customer, 0)), SUM(IF(store_id = 2, rentals_per_customer, 0)) FROM m
UNION ALL SELECT '연체율(%)', SUM(IF(store_id = 1, late_pct, 0)), SUM(IF(store_id = 2, late_pct, 0)) FROM m
UNION ALL SELECT '평균 대여일', SUM(IF(store_id = 1, avg_days, 0)), SUM(IF(store_id = 2, avg_days, 0)) FROM m;
```

## 해설

경영진 보고용 비교표는 **지표가 행, 비교 대상이 열**인 형태가 읽기 쉽습니다. 매장별 지표를 한 번 계산한 뒤(`m`) 언피벗(UNION ALL) + 피벗(조건부 합)으로 모양을 바꿨습니다.
"어디가 더 잘 운영되나" 같은 모호한 질문은 이렇게 **지표 정의표로 바꿔서** 합의하는 것이 분석가의 첫 번째 일입니다.
