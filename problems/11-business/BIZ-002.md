# BIZ-002. VIP 감사 쿠폰 대상자

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `NTILE` `상위 %` `CRM`

## 문제

> **요청자:** CRM팀 · **용도:** 7월 VIP 감사 쿠폰

**2005년 7월 결제 합계 상위 10%** 고객에게 쿠폰을 보내려 합니다. 7월에 결제한 고객을 대상으로 `NTILE(10)` 1구간을 VIP 로 정의합니다
(합계 내림차순, 동률이면 `customer_id` 순).

**요구 컬럼:** `customer_id`, `name`, `email`, `july_paid`, `july_payments`(결제 건수)

**정렬:** `july_paid` 내림차순, `customer_id` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH july AS (
    SELECT customer_id, SUM(amount) AS july_paid, COUNT(*) AS july_payments
    FROM payment
    WHERE payment_date >= '2005-07-01' AND payment_date < '2005-08-01'
    GROUP BY customer_id
), ranked AS (
    SELECT *, NTILE(10) OVER (ORDER BY july_paid DESC, customer_id) AS decile
    FROM july
)
SELECT c.customer_id, CONCAT(c.first_name, ' ', c.last_name) AS name, c.email,
       r.july_paid, r.july_payments
FROM ranked r
JOIN customer c ON c.customer_id = r.customer_id
WHERE r.decile = 1
ORDER BY r.july_paid DESC, c.customer_id;
```

## 해설

"상위 10%" 는 정의가 여러 개입니다: ① 인원 기준 상위 10% (`NTILE`, `ROW_NUMBER <= 0.1 × N`) ② 금액 백분위 90 이상 (`PERCENT_RANK >= 0.9`).
①은 동점자가 경계에서 갈릴 수 있고, ②는 인원이 정확히 10% 가 아닐 수 있습니다. 요청서에 정의를 적어 두면 나중에 "왜 이 사람은 빠졌냐" 는 질문에 답할 수 있습니다.
