# BIZ-007. 배우 기획전 후보

**유형:** 실무 요청 · **난이도:** ★★★☆☆ 중급 · **태그:** `기획전` `대표작` `ROW_NUMBER`

## 문제

> **요청자:** MD팀 · **용도:** "이 배우 특별전" 기획

출연작들의 **총 대여 횟수** 상위 5명의 배우와, 각 배우의 **대표작**(출연작 중 대여 횟수 1위, 동률이면 제목순)을 뽑아 주세요.

**요구 컬럼:** `actor`, `films`(출연 편수), `total_rentals`, `top_title`, `top_title_rentals`

**정렬:** `total_rentals` 내림차순, `actor` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH film_rentals AS (
    SELECT i.film_id, COUNT(*) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.film_id
), actor_films AS (
    SELECT fa.actor_id, f.title, COALESCE(fr.rentals, 0) AS rentals,
           ROW_NUMBER() OVER (PARTITION BY fa.actor_id ORDER BY COALESCE(fr.rentals, 0) DESC, f.title) AS rn
    FROM film_actor fa
    JOIN film f ON f.film_id = fa.film_id
    LEFT JOIN film_rentals fr ON fr.film_id = fa.film_id
), summary AS (
    SELECT actor_id, COUNT(*) AS films, SUM(rentals) AS total_rentals,
           MAX(CASE WHEN rn = 1 THEN title END) AS top_title,
           MAX(CASE WHEN rn = 1 THEN rentals END) AS top_title_rentals
    FROM actor_films
    GROUP BY actor_id
)
SELECT CONCAT(a.first_name, ' ', a.last_name) AS actor, s.films, s.total_rentals, s.top_title, s.top_title_rentals
FROM summary s
JOIN actor a ON a.actor_id = s.actor_id
ORDER BY s.total_rentals DESC, actor
LIMIT 5;
```

## 해설

"배우별 합계"와 "배우별 1위 작품"을 한 행에 담는 전형적인 **요약 + 대표값** 패턴입니다.
재고가 없어 대여 0회인 출연작도 편수에는 포함되도록 LEFT JOIN + COALESCE 를 썼습니다. "출연 편수" 가 전체 출연작인지 대여 가능한 작품인지도 확인 포인트입니다.
