# AGG-008. 매장별 월간 매출

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `GROUP BY` `DATE_FORMAT` `JOIN`

## 문제

매장(store)별, 월별 결제 건수와 합계를 구하세요.

- 출력: `store_id`, `month`(YYYY-MM), `payments`(건수), `revenue`(합계)
- 매장 → 월 순 정렬
- 결제(`payment`)는 처리한 직원(`staff`)을 통해 매장과 연결됩니다.

**사용 테이블:** `payment`, `staff`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT s.store_id,
       DATE_FORMAT(p.payment_date, '%Y-%m') AS month,
       COUNT(*)                             AS payments,
       SUM(p.amount)                        AS revenue
FROM payment p
JOIN staff s ON s.staff_id = p.staff_id
GROUP BY s.store_id, month
ORDER BY s.store_id, month;
```

## 해설

- `payment` 에는 `store_id` 가 없어 **처리 직원의 소속 매장**으로 연결했습니다. 고객의 매장(`customer.store_id`)으로 연결하면 결과가 달라지므로 "매장 매출"의 정의를 먼저 정해야 합니다.
- 전체 매출 **67,416.51**(16,049건), 두 매장이 거의 반반이며 **2005-07 이 정점**입니다.
- 2005-09 ~ 2006-01 은 **데이터가 없고**, 2006-02 는 2/14 하루치뿐입니다. "2006-02 매출 급감"은 추세가 아니라 **데이터 수집 기간의 경계**입니다. 시계열 분석 전에는 `MIN/MAX` 날짜와 빈 구간을 먼저 확인하세요.
