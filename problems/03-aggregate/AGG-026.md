# AGG-026. 하루 최대 대여일

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `GROUP BY` `DATE`

## 문제

대여 건수가 가장 많았던 날짜 5일의 `rental_day`, `rentals` 를 구하세요. `rentals` 내림차순, `rental_day` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DATE(rental_date) AS rental_day, COUNT(*) AS rentals
FROM rental
GROUP BY rental_day
ORDER BY rentals DESC, rental_day
LIMIT 5;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rental_day | rentals |
|---|---|
| 2005-07-31 | 679 |
| 2005-08-01 | 671 |
| 2005-08-21 | 659 |
| 2005-07-27 | 649 |
| 2005-08-02 | 643 |

> 총 5행

</details>

## 해설

`DATETIME` 을 날짜 단위로 묶으려면 `DATE()` 로 시각을 잘라야 합니다. 그대로 GROUP BY 하면 초 단위로 그룹이 나뉩니다.
