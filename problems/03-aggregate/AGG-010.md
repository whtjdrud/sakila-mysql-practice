# AGG-010. 문자열 이어 붙이기 집계

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `GROUP_CONCAT`

## 문제

`film_id` 1~5번 영화마다 출연 배우의 성(`last_name`)을 알파벳 순으로 쉼표로 이어 붙인 `actors` 를 구하세요.

- 출력: `film_id`, `actor_count`, `actors` — `film_id` 순

**사용 테이블:** `film_actor`, `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT fa.film_id,
       COUNT(*) AS actor_count,
       GROUP_CONCAT(a.last_name ORDER BY a.last_name, a.actor_id SEPARATOR ', ') AS actors
FROM film_actor fa
JOIN actor a ON a.actor_id = fa.actor_id
WHERE fa.film_id <= 5
GROUP BY fa.film_id
ORDER BY fa.film_id;
```

</details>

## 해설

`GROUP_CONCAT` 은 기본 최대 길이가 **1024바이트**(`group_concat_max_len`)라 넘으면 조용히 잘립니다. 긴 목록을 만들 때는 이 설정을 늘려야 합니다.
