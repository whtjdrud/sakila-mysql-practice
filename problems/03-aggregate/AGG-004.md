# AGG-004. 등급별 평균 대여료

**유형:** 집계 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `GROUP BY` `AVG`

## 문제

관람 등급(`rating`)별 영화 수 `films` 와 평균 대여료 `avg_rate`(소수 2자리)를 구하세요. `rating` 순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rating, COUNT(*) AS films, ROUND(AVG(rental_rate), 2) AS avg_rate
FROM film
GROUP BY rating
ORDER BY rating;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rating | films | avg_rate |
|---|---|---|
| G | 178 | 2.89 |
| PG | 194 | 3.05 |
| PG-13 | 223 | 3.03 |
| R | 195 | 2.94 |
| NC-17 | 210 | 2.97 |

> 총 5행

</details>

## 해설

`GROUP BY` 에 쓴 컬럼과 집계 함수만 SELECT 에 올 수 있습니다 (`ONLY_FULL_GROUP_BY`, MySQL 5.7.5+ 기본값).
