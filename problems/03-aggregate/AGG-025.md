# AGG-025. 표준편차와 분산

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `STDDEV` `VARIANCE` `통계`

## 문제

장르별 상영 시간의 평균 `avg_len`, 표준편차 `std_len`(모집단), 변동계수 `cv`(표준편차/평균, 소수 3자리)를 구하세요.
변동계수 내림차순, `category` 순.

**사용 테이블:** `category`, `film_category`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category,
       ROUND(AVG(f.length), 2)        AS avg_len,
       ROUND(STDDEV_POP(f.length), 2) AS std_len,
       ROUND(STDDEV_POP(f.length) / AVG(f.length), 3) AS cv
FROM category c
JOIN film_category fc ON fc.category_id = c.category_id
JOIN film f           ON f.film_id      = fc.film_id
GROUP BY c.category_id, c.name
ORDER BY cv DESC, category;
```

## 해설

`STDDEV_POP`(모집단)과 `STDDEV_SAMP`(표본, n-1 로 나눔)은 다릅니다. MySQL 의 `STDDEV`/`STD` 는 **모집단** 표준편차입니다.
평균이 다른 집단끼리 흩어짐을 비교할 때는 표준편차보다 **변동계수**가 공정합니다.
