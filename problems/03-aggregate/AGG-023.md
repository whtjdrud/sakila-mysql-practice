# AGG-023. 연체료가 포함된 결제

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `조인 집계` `비교`

## 문제

결제 금액이 해당 영화의 대여료(`film.rental_rate`)보다 **큰** 결제(=연체료 포함)를 영화 등급별로 집계하세요.

- 출력: `rating`, `payments`(전체 결제 수), `with_late_fee`(연체료 포함 결제 수), `late_fee_total`(초과 금액 합계)
- `rating` 순

**사용 테이블:** `payment`, `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT f.rating,
       COUNT(*) AS payments,
       SUM(p.amount > f.rental_rate) AS with_late_fee,
       SUM(GREATEST(p.amount - f.rental_rate, 0)) AS late_fee_total
FROM payment p
JOIN rental r    ON r.rental_id    = p.rental_id
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id      = i.film_id
GROUP BY f.rating
ORDER BY f.rating;
```

</details>

## 해설

`GREATEST(x, 0)` 으로 음수(할인 등)를 0으로 막아 초과분만 더했습니다.
`payment.rental_id` 가 NULL 인 결제 5건은 INNER JOIN 에서 자연스럽게 빠집니다.
