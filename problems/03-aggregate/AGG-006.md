# AGG-006. HAVING 으로 그룹 거르기

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `HAVING`

## 문제

결제 합계가 **180 이상**인 고객의 `customer_id`, `total` 을 `total` 내림차순, `customer_id` 순으로 조회하세요.

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, SUM(amount) AS total
FROM payment
GROUP BY customer_id
HAVING total >= 180
ORDER BY total DESC, customer_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| customer_id | total |
|---|---|
| 526 | 221.55 |
| 148 | 216.54 |
| 144 | 195.58 |
| 137 | 194.61 |
| 178 | 194.61 |
| 459 | 186.62 |

> 총 6행

</details>

## 해설

`WHERE` 는 **그룹을 만들기 전 행**을, `HAVING` 은 **그룹을 만든 후 결과**를 거릅니다.
`WHERE SUM(amount) >= 180` 은 오류입니다. MySQL 은 HAVING 에서 SELECT 별칭(`total`)을 허용하지만 표준 SQL 은 아닙니다.
