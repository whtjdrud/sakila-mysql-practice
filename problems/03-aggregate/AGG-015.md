# AGG-015. 평균보다 긴 영화가 많은 장르

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `HAVING` `조건부 집계`

## 문제

장르별로 상영 시간 120분 초과 영화의 **비율**을 구하고, 그 비율이 40% 이상인 장르만 출력하세요.

- 출력: `category`, `films`, `long_films`, `long_pct`(백분율 소수 1자리) — `long_pct` 내림차순, `category` 순

**사용 테이블:** `category`, `film_category`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category,
       COUNT(*) AS films,
       SUM(f.length > 120) AS long_films,
       ROUND(100 * AVG(f.length > 120), 1) AS long_pct
FROM category c
JOIN film_category fc ON fc.category_id = c.category_id
JOIN film f           ON f.film_id      = fc.film_id
GROUP BY c.category_id, c.name
HAVING AVG(f.length > 120) >= 0.4
ORDER BY long_pct DESC, category;
```

</details>

## 해설

비율 조건은 `HAVING long_pct >= 40` 처럼 반올림된 값보다 **원래 값(`AVG(...) >= 0.4`)** 으로 비교하는 것이 정확합니다.
반올림 때문에 39.96% 가 40.0% 로 표시되어 경계에서 결과가 달라질 수 있기 때문입니다.
