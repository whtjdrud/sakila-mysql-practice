# AGG-024. 첫 대여와 마지막 대여

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `MIN` `MAX` `날짜 집계`

## 문제

고객 1~10번의 첫 대여일 `first_rental`, 마지막 대여일 `last_rental`, 활동 기간(일) `active_days` 를 구하세요.
`customer_id` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id,
       MIN(rental_date) AS first_rental,
       MAX(rental_date) AS last_rental,
       DATEDIFF(MAX(rental_date), MIN(rental_date)) AS active_days
FROM rental
WHERE customer_id <= 10
GROUP BY customer_id
ORDER BY customer_id;
```

## 해설

`MIN`/`MAX` 는 숫자뿐 아니라 **날짜와 문자열**에도 씁니다. 집계 함수 결과에 다시 함수를 적용할 수 있습니다.
