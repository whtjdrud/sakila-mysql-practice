# AGG-017. 중복 데이터 찾기

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `HAVING` `중복 검사`

## 문제

이름(`first_name`)이 같은 배우가 **3명 이상**인 이름을 찾아 `first_name`, `cnt` 를 구하세요.
`cnt` 내림차순, `first_name` 순.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT first_name, COUNT(*) AS cnt
FROM actor
GROUP BY first_name
HAVING COUNT(*) >= 3
ORDER BY cnt DESC, first_name;
```

</details>

## 해설

`GROUP BY 키 HAVING COUNT(*) > 1` 은 **중복 데이터를 찾는 기본 패턴**입니다. 데이터 정합성 점검에 매우 자주 씁니다.
