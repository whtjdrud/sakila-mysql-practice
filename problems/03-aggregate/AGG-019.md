# AGG-019. 금액대별 결제 건수

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `GROUP BY` `정확한 값 그룹`

## 문제

결제 금액(`amount`)별 결제 건수를 구하고, 가장 흔한 금액 5개를 출력하세요.
`payments` 내림차순, `amount` 순.

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT amount, COUNT(*) AS payments
FROM payment
GROUP BY amount
ORDER BY payments DESC, amount
LIMIT 5;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| amount | payments |
|---|---|
| 4.99 | 3789 |
| 2.99 | 3542 |
| 0.99 | 2979 |
| 5.99 | 1299 |
| 6.99 | 1119 |

> 총 5행

</details>

## 해설

결제 금액은 대여료(0.99, 2.99, 4.99)에 연체료가 더해진 값이라 특정 금액에 몰려 있습니다. **최빈값(mode)** 을 구하는 기본 방법입니다.
