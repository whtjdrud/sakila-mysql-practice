# AGG-014. ROLLUP 으로 소계 · 총계

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `ROLLUP` `GROUPING`

## 문제

매장(`staff.store_id`)별, 월별 매출에 **매장별 소계와 전체 총계**를 함께 출력하세요.

- 출력: `store`, `month`, `revenue`
- 소계 행의 `month` 는 `'소계'`, 총계 행의 `store` 는 `'전체'`, `month` 는 `'총계'` 로 표시
- 매장 → 월 순 (소계가 각 매장의 마지막, 총계가 맨 마지막)

**사용 테이블:** `payment`, `staff`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT CASE WHEN GROUPING(store_id) = 1 THEN '전체' ELSE CAST(store_id AS CHAR) END AS store,
       CASE WHEN GROUPING(store_id) = 1 THEN '총계'
            WHEN GROUPING(month) = 1    THEN '소계'
            ELSE month END AS month,
       SUM(amount) AS revenue
FROM (
    SELECT s.store_id, DATE_FORMAT(p.payment_date, '%Y-%m') AS month, p.amount
    FROM payment p
    JOIN staff s ON s.staff_id = p.staff_id
) t
GROUP BY store_id, month WITH ROLLUP
ORDER BY GROUPING(store_id), store_id, GROUPING(month), month;
```

## 해설

`WITH ROLLUP` 은 GROUP BY 컬럼을 오른쪽부터 하나씩 빼며 소계를 만들고 마지막에 총계를 붙입니다.
소계 행의 컬럼은 NULL 이 되는데, 원래 데이터의 NULL 과 구분하려면 `GROUPING(컬럼)`(MySQL 8.0+)을 써야 합니다.
`GROUPING()` 을 ORDER BY 에 쓰면 소계·총계 위치를 원하는 대로 정렬할 수 있습니다.
GROUP BY 에 `DATE_FORMAT(...)` 같은 **식**을 직접 쓰면 ROLLUP·GROUPING 과 함께 쓸 때 `ONLY_FULL_GROUP_BY` 오류가 나기 쉬워,
파생 테이블에서 `month` 컬럼으로 먼저 만들어 두었습니다.
