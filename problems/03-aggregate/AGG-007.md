# AGG-007. WHERE 와 HAVING 함께 쓰기

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `WHERE` `HAVING`

## 문제

2005년 7월 결제만 대상으로, 그 달에 **결제를 10건 이상** 한 고객의 `customer_id`, `payments`, `total` 을 구하세요.
`payments` 내림차순, `customer_id` 순.

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, COUNT(*) AS payments, SUM(amount) AS total
FROM payment
WHERE payment_date >= '2005-07-01' AND payment_date < '2005-08-01'
GROUP BY customer_id
HAVING COUNT(*) >= 10
ORDER BY payments DESC, customer_id;
```

## 해설

행 단위로 거를 수 있는 조건(기간)은 **WHERE 에 두는 것이 효율적**입니다. 집계 대상 행이 줄어들기 때문입니다.
