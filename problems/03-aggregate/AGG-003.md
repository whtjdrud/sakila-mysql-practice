# AGG-003. 장르별 영화 수

**유형:** 집계 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `GROUP BY` `JOIN` `COUNT`

## 문제

각 장르(category)별로 등록된 영화 수를 구하세요.

- 출력: `category`(장르명), `film_count`(영화 수)
- 영화 수 내림차순, 같으면 장르명 오름차순

**사용 테이블:** `category`, `film_category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name   AS category,
       COUNT(*) AS film_count
FROM category c
JOIN film_category fc ON fc.category_id = c.category_id
GROUP BY c.category_id, c.name
ORDER BY film_count DESC, category;
```

</details>

## 해설

- `film_category` 는 영화와 장르의 **연결 테이블**입니다. Sakila 는 영화 1편당 장르가 정확히 1개라 합계가 1,000편입니다.
- `GROUP BY c.category_id, c.name` 처럼 PK 를 함께 묶으면 이름이 같은 장르가 생겨도 안전합니다.
- 결과: **Sports(74편)** 최다, **Music(51편)** 최소. Games·Sci-Fi(61편), Classics·Travel(57편)은 동수라
  2차 정렬 기준이 순서를 결정합니다 — 정렬 기준을 끝까지 명시해야 결과가 매번 같습니다.
