# AGG-011. 조건부 집계

**유형:** 집계 · **난이도:** ★★☆☆☆ 초급 · **태그:** `SUM` `조건식` `피벗 기초`

## 문제

매장(`customer.store_id`)별로 전체 고객 수, 활성 고객 수, 비활성 고객 수를 구하세요.

- 출력: `store_id`, `total`, `active_cnt`, `inactive_cnt` — `store_id` 순

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT store_id,
       COUNT(*)                                 AS total,
       SUM(CASE WHEN active = 1 THEN 1 ELSE 0 END) AS active_cnt,
       SUM(CASE WHEN active = 0 THEN 1 ELSE 0 END) AS inactive_cnt
FROM customer
GROUP BY store_id
ORDER BY store_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| store_id | total | active_cnt | inactive_cnt |
|---|---|---|---|
| 1 | 326 | 318 | 8 |
| 2 | 273 | 266 | 7 |

> 총 2행

</details>

## 해설

`SUM(CASE WHEN 조건 THEN 1 ELSE 0 END)` 는 어느 DBMS 에서나 통하는 조건부 개수 세기입니다.
MySQL 에서는 `SUM(active = 1)` 로 줄여 쓸 수도 있습니다.
