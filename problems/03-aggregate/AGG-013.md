# AGG-013. 배우별 출연 편수 분포

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `GROUP BY` `2단계 집계` `파생 테이블`

## 문제

배우별 출연 편수를 구한 뒤, **출연 편수별로 배우가 몇 명인지** 분포를 구하세요.

- 출력: `film_count`(출연 편수), `actors`(그 편수의 배우 수) — `film_count` 순

**사용 테이블:** `film_actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_count, COUNT(*) AS actors
FROM (
    SELECT actor_id, COUNT(*) AS film_count
    FROM film_actor
    GROUP BY actor_id
) t
GROUP BY film_count
ORDER BY film_count;
```

</details>

## 해설

집계 결과를 다시 집계하려면 FROM 절 서브쿼리(**파생 테이블**)로 한 번 감싸야 합니다. 파생 테이블에는 별칭(`t`)이 필수입니다.
히스토그램/분포를 구할 때 자주 쓰는 패턴입니다.
