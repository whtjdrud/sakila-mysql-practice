# AGG-016. 고객별 평균 결제 금액 분포 구간

**유형:** 집계 · **난이도:** ★★★☆☆ 중급 · **태그:** `FLOOR` `구간화` `히스토그램`

## 문제

고객별 결제 합계를 20 단위 구간으로 나눠 구간별 고객 수를 구하세요.
구간은 `40-59.99`, `60-79.99` … 처럼 표시합니다.

- 출력: `bucket_start`, `bucket`(예: `60-79.99`), `customers` — `bucket_start` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT FLOOR(total / 20) * 20 AS bucket_start,
       CONCAT(FLOOR(total / 20) * 20, '-', FLOOR(total / 20) * 20 + 19.99) AS bucket,
       COUNT(*) AS customers
FROM (
    SELECT customer_id, SUM(amount) AS total
    FROM payment
    GROUP BY customer_id
) t
GROUP BY bucket_start, bucket
ORDER BY bucket_start;
```

</details>

## 해설

`FLOOR(값 / 폭) * 폭` 은 값을 구간 시작점으로 내리는 **버킷팅** 공식입니다. 분포를 볼 때 가장 먼저 쓰는 도구입니다.
