# SEL-008. 여러 등급 중 하나

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `IN`

## 문제

등급이 `G` 또는 `PG` 이고 대여료가 0.99 인 영화의 `title`, `rating` 을 조회하세요.
`title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, rating
FROM film
WHERE rating IN ('G', 'PG')
  AND rental_rate = 0.99
ORDER BY title;
```

</details>

## 해설

`IN (...)` 은 `rating = 'G' OR rating = 'PG'` 와 같습니다.
`OR` 를 직접 쓰면 `AND` 와 섞일 때 괄호를 빠뜨리기 쉬운데, `IN` 은 그런 실수를 막아 줍니다.
