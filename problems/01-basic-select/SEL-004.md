# SEL-004. 등급 목록 중복 제거

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `DISTINCT`

## 문제

영화 테이블에 존재하는 관람 등급(`rating`)의 종류를 중복 없이 조회하세요. `rating` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DISTINCT rating
FROM film
ORDER BY rating;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rating |
|---|
| G |
| PG |
| PG-13 |
| R |
| NC-17 |

> 총 5행

</details>

## 해설

`rating` 은 `ENUM('G','PG','PG-13','R','NC-17')` 타입입니다.
ENUM 을 `ORDER BY` 하면 **문자열 순서가 아니라 정의된 순서(인덱스)** 로 정렬됩니다.
그래서 결과가 알파벳 순(G, NC-17, PG ...)이 아니라 G → PG → PG-13 → R → NC-17 로 나옵니다.
