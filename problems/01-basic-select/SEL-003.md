# SEL-003. 비싸고 긴 영화

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `WHERE` `숫자 비교`

## 문제

대여료(`rental_rate`)가 4.99 인 영화 중 상영 시간(`length`)이 180분 이상인 영화의
`title`, `length` 를 조회하세요. `length` 내림차순, 같으면 `title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, length
FROM film
WHERE rental_rate = 4.99
  AND length >= 180
ORDER BY length DESC, title;
```

## 해설

`AND` 로 조건을 결합합니다. `rental_rate` 는 `DECIMAL(4,2)` 라서 `= 4.99` 비교가 정확하게 동작합니다.
(FLOAT 였다면 부동소수점 오차 때문에 `=` 비교가 위험합니다.)
