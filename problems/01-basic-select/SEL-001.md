# SEL-001. 전체 배우 이름 조회

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `SELECT` `ORDER BY`

## 문제

모든 배우의 `actor_id`, `first_name`, `last_name` 을 `actor_id` 오름차순으로 조회하세요.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT actor_id, first_name, last_name
FROM actor
ORDER BY actor_id;
```
