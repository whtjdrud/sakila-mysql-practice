# SEL-020. 정규식 검색

**유형:** 기본 조회 · **난이도:** ★★★☆☆ 중급 · **태그:** `REGEXP`

## 문제

성(`last_name`)이 모음(A, E, I, O, U)으로 시작하고 모음으로 끝나는 배우의 `first_name`, `last_name` 을 조회하세요.
`last_name`, `first_name` 순.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT first_name, last_name
FROM actor
WHERE last_name REGEXP '^[AEIOU].*[AEIOU]$'
ORDER BY last_name, first_name;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| first_name | last_name |
|---|---|
| ANGELINA | ASTAIRE |

> 총 1행

</details>

## 해설

`^` 는 시작, `$` 는 끝, `[AEIOU]` 는 문자 집합, `.*` 는 임의 문자 0개 이상입니다.
LIKE 로는 "모음 중 하나" 같은 조건을 표현하기 어려워 `REGEXP` 가 유용합니다. 다만 인덱스는 사용할 수 없습니다.
