# SEL-021. 지역·우편번호 조합 중복 제거

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DISTINCT` `다중 컬럼`

## 문제

고객이 사는 주소(`address`) 테이블에서 `district` 가 `California` 이거나 `Texas` 인 주소의
`district`, `postal_code` 조합을 중복 없이 조회하세요. `district`, `postal_code` 순.

**사용 테이블:** `address`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DISTINCT district, postal_code
FROM address
WHERE district IN ('California', 'Texas')
ORDER BY district, postal_code;
```

</details>

## 해설

`DISTINCT` 는 **SELECT 목록 전체의 조합**에 대해 중복을 제거합니다. 첫 번째 컬럼에만 적용되는 것이 아닙니다.
