# SEL-002. 특정 성을 가진 배우

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `WHERE` `=`

## 문제

성(`last_name`)이 `WAHLBERG` 인 배우의 `actor_id`, `first_name`, `last_name` 을 조회하세요.
`actor_id` 오름차순.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT actor_id, first_name, last_name
FROM actor
WHERE last_name = 'WAHLBERG'
ORDER BY actor_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| actor_id | first_name | last_name |
|---|---|---|
| 2 | NICK | WAHLBERG |
| 95 | DARYL | WAHLBERG |

> 총 2행

</details>

## 해설

MySQL 의 기본 콜레이션(`utf8mb4_0900_ai_ci`)은 대소문자를 구분하지 않으므로
`'wahlberg'` 로 비교해도 같은 결과가 나옵니다. 다른 DBMS 에서는 다를 수 있으니 주의하세요.
