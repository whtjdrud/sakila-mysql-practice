# SEL-007. 제목에 특정 단어가 들어간 영화

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `LIKE`

## 문제

제목(`title`)에 `LOVE` 가 들어가는 영화의 `film_id`, `title` 을 `film_id` 순으로 조회하세요.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id, title
FROM film
WHERE title LIKE '%LOVE%'
ORDER BY film_id;
```

</details>

## 해설

양쪽에 `%` 를 붙이면 "포함" 검색입니다. 단어 경계를 따지지 않으므로 `GLOVE`, `LOVELY` 같은 제목도 함께 잡힙니다.
단어 단위로 찾으려면 `REGEXP '\\bLOVE\\b'` 나 FULLTEXT 인덱스(`film_text` 테이블)를 검토하세요.
