# SEL-018. 다중 정렬 방향

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `ORDER BY` `ASC` `DESC`

## 문제

2005-08-23 이후(해당 일 포함) 결제 중 금액이 10 이상인 결제의 `payment_id`, `customer_id`, `amount`, `payment_date` 를
금액 내림차순, 결제 일시 오름차순, `payment_id` 오름차순으로 조회하세요.

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT payment_id, customer_id, amount, payment_date
FROM payment
WHERE payment_date >= '2005-08-23'
  AND amount >= 10
ORDER BY amount DESC, payment_date, payment_id;
```

</details>

## 해설

정렬 방향은 컬럼마다 따로 지정합니다. `ORDER BY a, b DESC` 는 a 오름차순, b 내림차순입니다.
(`DESC` 가 앞의 컬럼까지 적용되지 않습니다.)
