# SEL-022. 빈 문자열과 NULL 구분

**유형:** 기본 조회 · **난이도:** ★★★☆☆ 중급 · **태그:** `NULL` `빈 문자열` `COALESCE`

## 문제

`address` 테이블에서 `address2` 가 **NULL 이거나 빈 문자열**인 주소가 각각 몇 개인지,
그리고 실제 값이 있는 주소는 몇 개인지 한 행으로 구하세요.

- 출력 컬럼: `null_cnt`, `empty_cnt`, `filled_cnt`

**사용 테이블:** `address`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT SUM(address2 IS NULL)              AS null_cnt,
       SUM(address2 = '')                 AS empty_cnt,
       SUM(address2 IS NOT NULL AND address2 <> '') AS filled_cnt
FROM address;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| null_cnt | empty_cnt | filled_cnt |
|---|---|---|
| 4 | 599 | 0 |

> 총 1행

</details>

## 해설

MySQL 에서 비교식은 1/0 을 돌려주므로 `SUM(조건)` 으로 조건별 개수를 셀 수 있습니다.
`address2 = ''` 는 address2 가 NULL 인 행에서 NULL 이 되고, `SUM` 은 NULL 을 무시합니다.
실무 데이터에는 NULL 과 빈 문자열이 섞여 있는 경우가 많아 둘을 구분해서 확인하는 습관이 중요합니다.
