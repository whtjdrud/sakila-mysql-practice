# SEL-009. 범위 조건 BETWEEN

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `BETWEEN`

## 문제

교체 비용(`replacement_cost`)이 10.00 이상 12.00 이하인 영화의 `title`, `replacement_cost` 를 조회하세요.
`replacement_cost` 오름차순, 같으면 `title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, replacement_cost
FROM film
WHERE replacement_cost BETWEEN 10.00 AND 12.00
ORDER BY replacement_cost, title;
```

## 해설

`BETWEEN a AND b` 는 **양 끝을 포함**합니다 (`>= a AND <= b`).
날짜/시간 컬럼에 `BETWEEN '2005-05-01' AND '2005-05-31'` 을 쓰면 31일 00:00:00 이후 데이터가 빠지는 함정이 있습니다.
