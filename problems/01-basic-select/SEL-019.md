# SEL-019. NULL 이 섞인 정렬

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `NULL 정렬` `IS NULL`

## 문제

고객 1번(`customer_id = 1`)의 대여 기록에서 `rental_id`, `rental_date`, `return_date` 를 조회하되,
**반납일이 늦은 순**으로 정렬하고 NULL(미반납)은 **맨 앞**에 오게 하세요. 같으면 `rental_id` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, rental_date, return_date
FROM rental
WHERE customer_id = 1
ORDER BY return_date IS NULL DESC, return_date DESC, rental_id;
```

## 해설

MySQL 은 오름차순에서 NULL 을 **가장 작은 값**으로 취급해 맨 앞에, 내림차순에서는 맨 뒤에 둡니다.
`NULLS FIRST` 문법이 없으므로 `컬럼 IS NULL` (참=1, 거짓=0) 을 정렬 키로 추가하는 기법을 씁니다.
고객 1번은 미반납이 없어 순수하게 반납일 내림차순으로 나옵니다 — 다른 고객 번호로도 바꿔 실험해 보세요.
