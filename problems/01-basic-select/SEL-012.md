# SEL-012. 특정 기간의 대여

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `날짜 범위` `반열린 구간`

## 문제

2005년 5월 25일 하루 동안 발생한 대여의 `rental_id`, `rental_date` 를 조회하세요.
`rental_date`, `rental_id` 순 정렬.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, rental_date
FROM rental
WHERE rental_date >= '2005-05-25'
  AND rental_date <  '2005-05-26'
ORDER BY rental_date, rental_id;
```

## 해설

날짜 범위는 **반열린 구간 `[시작, 다음날)`** 으로 쓰는 것이 정석입니다.
`DATE(rental_date) = '2005-05-25'` 도 결과는 같지만, 컬럼에 함수를 씌우면 인덱스를 사용할 수 없어 대용량에서 느려집니다.
