# SEL-015. 제외 조건 NOT IN

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `NOT IN` `NOT LIKE`

## 문제

등급이 `G`, `PG`, `PG-13` 이 **아니고**, 제목이 `A` 로 시작하지 않으며,
상영 시간이 180분 이상인 영화의 `title`, `rating`, `length` 를 조회하세요. `title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, rating, length
FROM film
WHERE rating NOT IN ('G', 'PG', 'PG-13')
  AND title NOT LIKE 'A%'
  AND length >= 180
ORDER BY title;
```

## 해설

`NOT IN` 은 목록에 **NULL 이 섞이면 아무 행도 반환하지 않는** 함정이 있습니다.
여기처럼 상수 목록이면 안전하지만, 서브쿼리와 함께 쓸 때는 `NOT EXISTS` 를 권장합니다.
