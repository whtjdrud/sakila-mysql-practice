# SEL-010. 반납되지 않은 대여

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `IS NULL`

## 문제

아직 반납되지 않은(`return_date` 가 NULL) 대여 기록의 `rental_id`, `rental_date`, `customer_id` 를
`rental_id` 순으로 조회하세요.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, rental_date, customer_id
FROM rental
WHERE return_date IS NULL
ORDER BY rental_id;
```

## 해설

NULL 은 `= NULL` 로 비교할 수 없습니다. `NULL = NULL` 의 결과도 TRUE 가 아니라 **NULL(알 수 없음)** 이기 때문입니다.
반드시 `IS NULL` / `IS NOT NULL` 을 사용하세요. 결과는 총 183건입니다.
