# SEL-014. 복합 조건과 괄호

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `AND` `OR` `연산자 우선순위`

## 문제

다음 조건을 만족하는 영화의 `title`, `rating`, `rental_rate` 를 조회하세요.

- 등급이 `R` 또는 `NC-17` 이면서
- 대여료가 0.99 **이거나** 상영 시간이 60분 미만

`title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, rating, rental_rate
FROM film
WHERE rating IN ('R', 'NC-17')
  AND (rental_rate = 0.99 OR length < 60)
ORDER BY title;
```

## 해설

`AND` 가 `OR` 보다 우선순위가 높습니다. 괄호를 빼고
`rating IN (...) AND rental_rate = 0.99 OR length < 60` 이라고 쓰면
"(R/NC-17 이고 0.99) 또는 (등급 무관 60분 미만)" 이 되어 결과가 훨씬 많아집니다.
