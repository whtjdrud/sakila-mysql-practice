# SEL-013. 특별 부록에 예고편이 있는 영화

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `SET 타입` `FIND_IN_SET`

## 문제

`special_features` 에 `Trailers` 가 포함된 영화 중 상영 시간이 50분 미만인 영화의
`title`, `length`, `special_features` 를 조회하세요. `length`, `title` 순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, length, special_features
FROM film
WHERE FIND_IN_SET('Trailers', special_features) > 0
  AND length < 50
ORDER BY length, title;
```

</details>

## 해설

`special_features` 는 `SET` 타입이라 여러 값이 쉼표로 저장됩니다.
`LIKE '%Trailers%'` 도 동작하지만, 값 하나가 다른 값의 부분 문자열일 때 오작동할 수 있어 `FIND_IN_SET` 이 더 정확합니다.
