# SEL-006. 이름이 J로 시작하는 배우

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `LIKE` `와일드카드`

## 문제

이름(`first_name`)이 `J` 로 시작하는 배우의 `first_name`, `last_name` 을 조회하세요.
`first_name`, `last_name` 오름차순.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT first_name, last_name
FROM actor
WHERE first_name LIKE 'J%'
ORDER BY first_name, last_name;
```

## 해설

`%` 는 0글자 이상, `_` 는 정확히 1글자를 뜻합니다.
`LIKE 'J%'` 처럼 **앞부분이 고정된 패턴**은 인덱스를 탈 수 있지만, `'%J'` 처럼 앞이 와일드카드면 인덱스를 쓰지 못합니다.
