# SEL-016. 페이지네이션

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `LIMIT` `OFFSET` `페이징`

## 문제

고객을 `last_name`, `first_name`, `customer_id` 순으로 정렬했을 때,
한 페이지에 10명씩 보여준다면 **3페이지**에 해당하는 고객의 `customer_id`, `first_name`, `last_name` 을 조회하세요.

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, first_name, last_name
FROM customer
ORDER BY last_name, first_name, customer_id
LIMIT 10 OFFSET 20;
```

</details>

## 해설

3페이지는 21~30번째 행이므로 `OFFSET (3-1)*10 = 20` 입니다. `LIMIT 20, 10` 으로도 쓸 수 있습니다.
OFFSET 이 커지면 앞의 행을 모두 읽고 버리므로 느려집니다. 대용량에서는 "마지막으로 본 키보다 큰 것"을 조회하는 **키셋 페이지네이션**을 씁니다.
