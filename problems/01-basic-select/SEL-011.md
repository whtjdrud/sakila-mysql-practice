# SEL-011. 비활성 고객

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `WHERE` `불리언`

## 문제

비활성(`active = 0`) 고객의 `customer_id`, `first_name`, `last_name`, `store_id` 를 `customer_id` 순으로 조회하세요.

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, first_name, last_name, store_id
FROM customer
WHERE active = 0
ORDER BY customer_id;
```

## 해설

MySQL 의 BOOLEAN 은 사실 `TINYINT(1)` 입니다. `WHERE NOT active` 나 `WHERE active = FALSE` 도 같은 결과를 냅니다.
