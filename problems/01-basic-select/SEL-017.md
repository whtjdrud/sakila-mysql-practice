# SEL-017. 계산 컬럼과 별칭

**유형:** 기본 조회 · **난이도:** ★★☆☆☆ 초급 · **태그:** `산술 연산` `별칭`

## 문제

각 영화의 "하루당 대여료"(`rental_rate / rental_duration`)를 소수 둘째 자리로 반올림해 `daily_rate` 로 구하고,
`daily_rate` 가 가장 높은 영화 10편의 `title`, `rental_rate`, `rental_duration`, `daily_rate` 를 조회하세요.
`daily_rate` 내림차순, 같으면 `title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, rental_rate, rental_duration,
       ROUND(rental_rate / rental_duration, 2) AS daily_rate
FROM film
ORDER BY daily_rate DESC, title
LIMIT 10;
```

## 해설

`ORDER BY` 에서는 SELECT 의 별칭(`daily_rate`)을 쓸 수 있습니다.
반면 `WHERE` 는 SELECT 보다 **먼저** 실행되므로 별칭을 쓸 수 없습니다. (논리적 실행 순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT)
