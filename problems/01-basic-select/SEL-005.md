# SEL-005. 가장 긴 영화 5편

**유형:** 기본 조회 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `ORDER BY` `LIMIT`

## 문제

상영 시간(`length`)이 가장 긴 영화 5편의 `title`, `length` 를 조회하세요.
`length` 내림차순, 같으면 `title` 오름차순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, length
FROM film
ORDER BY length DESC, title
LIMIT 5;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| title | length |
|---|---|
| CHICAGO NORTH | 185 |
| CONTROL ANTHEM | 185 |
| DARN FORRESTER | 185 |
| GANGS PRIDE | 185 |
| HOME PITY | 185 |

> 총 5행

</details>

## 해설

최대 상영 시간은 185분이고 이 길이의 영화가 5편보다 많습니다.
따라서 2차 정렬(`title`)이 없으면 어떤 5편이 나올지 **보장되지 않습니다.** `LIMIT` 을 쓸 때는 항상 정렬을 끝까지 정하세요.
