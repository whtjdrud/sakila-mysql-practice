# ADV-017. 미반납 DVD 현황 리포트

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `실무 리포트` `다중 조인` `연락처`

## 문제

데이터 마지막 날(`2006-02-14` 기준, 시각 무시)에 반납되지 않은 대여를 **고객별로** 정리한 연락 리포트를 만드세요.

- 출력: `customer`(이름 성), `email`, `phone`, `unreturned`(미반납 장수), `titles`(제목을 쉼표로, 제목 순), `oldest_rental`(가장 오래된 미반납 대여일)
- 미반납 장수 내림차순, `oldest_rental`, `customer` 순으로 상위 10명

**사용 테이블:** `rental`, `customer`, `address`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT CONCAT(c.first_name, ' ', c.last_name) AS customer,
       c.email, a.phone,
       COUNT(*) AS unreturned,
       GROUP_CONCAT(f.title ORDER BY f.title SEPARATOR ', ') AS titles,
       MIN(r.rental_date) AS oldest_rental
FROM rental r
JOIN customer c  ON c.customer_id  = r.customer_id
JOIN address a   ON a.address_id   = c.address_id
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id      = i.film_id
WHERE r.return_date IS NULL
GROUP BY c.customer_id, c.first_name, c.last_name, c.email, a.phone
ORDER BY unreturned DESC, oldest_rental, customer
LIMIT 10;
```
