# ADV-020. 종합 매장 대시보드 쿼리

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `대시보드` `다중 CTE` `KPI`

## 문제

매장(재고 `store_id` 기준)별로 2005-08 한 달의 KPI 를 한 행에 모으세요.

| 컬럼 | 정의 |
|---|---|
| `rentals` | 8월 대여 건수 |
| `revenue` | 8월 대여에 연결된 결제 합계 |
| `active_customers` | 8월에 대여한 고유 고객 수 |
| `arpu` | revenue / active_customers (소수 2자리) |
| `new_customers` | 8월이 첫 대여 월인 고객 수 (이 매장에서의 첫 대여 기준) |
| `top_category` | 8월 대여 건수 1위 장르 (동점이면 이름순) |
| `late_pct` | 8월 대여 중 연체 반납 비율 (미반납 제외, 소수 1자리) |

출력은 위 순서 + 맨 앞 `store_id` — `store_id` 순

**사용 테이블:** `rental`, `inventory`, `payment`, `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH aug AS (
    SELECT r.rental_id, r.customer_id, r.rental_date, r.return_date, i.store_id, i.film_id, f.rental_duration
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.rental_date >= '2005-08-01' AND r.rental_date < '2005-09-01'
), base AS (
    SELECT store_id, COUNT(*) AS rentals, COUNT(DISTINCT customer_id) AS active_customers,
           ROUND(100 * AVG(CASE WHEN return_date IS NOT NULL
                                THEN return_date > rental_date + INTERVAL rental_duration DAY END), 1) AS late_pct
    FROM aug
    GROUP BY store_id
), rev AS (
    SELECT a.store_id, SUM(p.amount) AS revenue
    FROM aug a JOIN payment p ON p.rental_id = a.rental_id
    GROUP BY a.store_id
), first_seen AS (
    SELECT i.store_id, r.customer_id, MIN(r.rental_date) AS first_at
    FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.store_id, r.customer_id
), newc AS (
    SELECT store_id, COUNT(*) AS new_customers
    FROM first_seen
    WHERE first_at >= '2005-08-01' AND first_at < '2005-09-01'
    GROUP BY store_id
), cat AS (
    SELECT a.store_id, c.name,
           ROW_NUMBER() OVER (PARTITION BY a.store_id ORDER BY COUNT(*) DESC, c.name) AS rn
    FROM aug a
    JOIN film_category fc ON fc.film_id    = a.film_id
    JOIN category c       ON c.category_id = fc.category_id
    GROUP BY a.store_id, c.name
)
SELECT b.store_id, b.rentals, rv.revenue, b.active_customers,
       ROUND(rv.revenue / b.active_customers, 2) AS arpu,
       COALESCE(n.new_customers, 0) AS new_customers,
       ct.name AS top_category,
       b.late_pct
FROM base b
JOIN rev rv     ON rv.store_id = b.store_id
LEFT JOIN newc n ON n.store_id = b.store_id
JOIN cat ct     ON ct.store_id = b.store_id AND ct.rn = 1
ORDER BY b.store_id;
```

## 해설

대시보드 쿼리는 **KPI 마다 CTE 하나**로 나눠 각각 매장 단위까지 집계한 뒤 마지막에 조인합니다. 이렇게 하면 팬아웃 없이 정확하고, KPI 추가·수정도 쉽습니다.
`new_customers` 처럼 0이 될 수 있는 지표는 LEFT JOIN + COALESCE 로, 정의가 까다로운 지표(`late_pct` 의 미반납 제외)는 CASE 로 명확히 했습니다.
