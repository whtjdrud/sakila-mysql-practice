# ADV-013. 매장 간 고객 이동

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `전이 행렬` `피벗`

## 문제

고객의 연속된 두 대여에서 재고 매장(`inventory.store_id`)이 어떻게 바뀌는지 **전이 행렬**을 구하세요.

- 출력: `from_store`, `to_store_1`, `to_store_2`(건수), `stay_pct`(같은 매장에 머문 비율, 소수 1자리) — `from_store` 순

**사용 테이블:** `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH seq AS (
    SELECT i.store_id,
           LEAD(i.store_id) OVER (PARTITION BY r.customer_id ORDER BY r.rental_date, r.rental_id) AS next_store
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
)
SELECT store_id AS from_store,
       SUM(next_store = 1) AS to_store_1,
       SUM(next_store = 2) AS to_store_2,
       ROUND(100 * AVG(next_store = store_id), 1) AS stay_pct
FROM seq
WHERE next_store IS NOT NULL
GROUP BY store_id
ORDER BY from_store;
```

</details>

<summary>실행 결과 보기</summary>

| from_store | to_store_1 | to_store_2 | stay_pct |
|---|---|---|---|
| 1 | 3758 | 3861 | 49.3 |
| 2 | 3864 | 3962 | 50.6 |

> 총 2행

</details>

## 해설

`LEAD` 로 "다음 상태" 를 붙이고 (현재, 다음) 쌍을 피벗하면 **마르코프 전이 행렬**이 됩니다.
Sakila 고객은 등록 매장과 무관하게 두 매장 재고를 섞어 빌려서 stay_pct 가 50% 근처입니다.
