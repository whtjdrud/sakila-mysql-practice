# ADV-003. 동시 대여 최대치 (이벤트 스윕)

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `이벤트 스윕` `UNION ALL` `누적합` `동시성`

## 문제

각 매장(`inventory.store_id`)에서 **동시에 대여 중이던 DVD 수의 최댓값**과 그 시각을 구하세요.
대여 시작은 +1, 반납은 −1 로 보고, 미반납 건은 반납되지 않은 것으로 계속 대여 중이라고 봅니다.
같은 시각에 반납과 대여가 있으면 **반납을 먼저** 처리합니다.

- 출력: `store_id`, `peak_at`, `concurrent` — `store_id` 순 (최댓값 시각이 여럿이면 가장 이른 시각)

**사용 테이블:** `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH events AS (
    SELECT i.store_id, r.rental_date AS at, 1 AS delta
    FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
    UNION ALL
    SELECT i.store_id, r.return_date, -1
    FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
    WHERE r.return_date IS NOT NULL
), running AS (
    SELECT store_id, at,
           SUM(delta) OVER (PARTITION BY store_id ORDER BY at, delta ROWS UNBOUNDED PRECEDING) AS concurrent
    FROM events
), ranked AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY store_id ORDER BY concurrent DESC, at) AS rn
    FROM running
)
SELECT store_id, at AS peak_at, concurrent
FROM ranked
WHERE rn = 1
ORDER BY store_id;
```

</details>

## 해설

"구간이 겹치는 최대 개수" 는 **시작 +1 / 끝 −1 이벤트를 시간순 누적합**하면 구할 수 있습니다 (회의실 배정, 동시 접속자 수 문제).
정렬에 `delta` 를 넣어 같은 시각엔 −1 이 먼저 오도록 했습니다. 이 순서에 따라 최댓값이 1씩 달라질 수 있습니다.
