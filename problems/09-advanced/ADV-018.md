# ADV-018. 국가별 매출 집중도 (HHI)

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `집중도 지수` `HHI` `다단계 집계`

## 문제

고객이 10명 이상인 국가별로 **고객 매출 집중도**를 허핀달-허쉬만 지수(HHI = Σ(각 고객 매출 점유율²) × 10000)로 구하세요.
HHI 가 높을수록 소수 고객에게 매출이 몰려 있습니다.

- 출력: `country`, `customers`, `revenue`, `hhi`(정수 반올림), `top_customer_share_pct`(최대 고객 점유율, 소수 1자리)
- `hhi` 내림차순, `country` 순

**사용 테이블:** `payment`, `customer`, `address`, `city`, `country`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH cust AS (
    SELECT co.country, c.customer_id, SUM(p.amount) AS paid
    FROM payment p
    JOIN customer c ON c.customer_id = p.customer_id
    JOIN address a  ON a.address_id  = c.address_id
    JOIN city ci    ON ci.city_id    = a.city_id
    JOIN country co ON co.country_id = ci.country_id
    GROUP BY co.country, c.customer_id
), share AS (
    SELECT country, paid,
           paid / SUM(paid) OVER (PARTITION BY country) AS s,
           COUNT(*) OVER (PARTITION BY country) AS customers
    FROM cust
)
SELECT country, MAX(customers) AS customers, SUM(paid) AS revenue,
       ROUND(SUM(s * s) * 10000) AS hhi,
       ROUND(100 * MAX(s), 1) AS top_customer_share_pct
FROM share
WHERE customers >= 10
GROUP BY country
ORDER BY hhi DESC, country;
```

## 해설

고객 N명이 매출을 똑같이 나누면 HHI = 10000 / N 입니다. 그래서 HHI 는 **고객 수에 크게 영향**을 받습니다 —
고객 10명 국가의 최솟값은 1000, 30명 국가는 333 입니다. 비교할 때는 `10000 / customers` 기준선과 함께 보세요.
