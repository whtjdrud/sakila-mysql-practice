# ADV-004. RFM 점수화

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `RFM` `NTILE` `세그먼트`

## 문제

2005-08-24 를 기준일로 고객별 RFM 점수(각 1~5, 5가 가장 좋음)를 `NTILE(5)` 로 매기고, 세그먼트별 고객 수를 구하세요.
2006년 데이터는 제외합니다.

- R: 마지막 대여일이 최근일수록 높음 / F: 대여 횟수가 많을수록 높음 / M: 결제 합계가 클수록 높음
- 동률은 `customer_id` 순으로 나눕니다.
- 세그먼트: `챔피언`(R·F·M 모두 4 이상), `잠재 이탈`(R ≤ 2 이고 F ≥ 4), `신규성`(R ≥ 4 이고 F ≤ 2), `기타`

출력: `segment`, `customers`, `avg_m`(평균 결제 합계, 소수 2자리) — 챔피언 → 잠재 이탈 → 신규성 → 기타 순

**사용 테이블:** `rental`, `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH base AS (
    SELECT r.customer_id,
           DATEDIFF('2005-08-24', MAX(r.rental_date)) AS recency,
           COUNT(*) AS frequency,
           (SELECT SUM(p.amount) FROM payment p
             WHERE p.customer_id = r.customer_id AND p.payment_date < '2006-01-01') AS monetary
    FROM rental r
    WHERE r.rental_date < '2006-01-01'
    GROUP BY r.customer_id
), scored AS (
    SELECT customer_id, monetary,
           NTILE(5) OVER (ORDER BY recency DESC, customer_id)  AS r,
           NTILE(5) OVER (ORDER BY frequency, customer_id)     AS f,
           NTILE(5) OVER (ORDER BY monetary, customer_id)      AS m
    FROM base
)
SELECT CASE WHEN r >= 4 AND f >= 4 AND m >= 4 THEN '챔피언'
            WHEN r <= 2 AND f >= 4 THEN '잠재 이탈'
            WHEN r >= 4 AND f <= 2 THEN '신규성'
            ELSE '기타' END AS segment,
       COUNT(*) AS customers,
       ROUND(AVG(monetary), 2) AS avg_m
FROM scored
GROUP BY segment
ORDER BY FIELD(segment, '챔피언', '잠재 이탈', '신규성', '기타');
```

## 해설

NTILE 을 **오름차순**으로 매기면 큰 값이 5점이 됩니다. Recency 는 "작을수록 좋음" 이라 `recency DESC` 로 정렬해 최근 고객이 5점이 되게 했습니다.
실무 RFM 은 이 점수로 마케팅 대상을 고릅니다. 세그먼트 조건의 순서(챔피언 먼저)가 결과를 바꾼다는 점도 확인하세요.
