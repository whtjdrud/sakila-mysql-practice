# ADV-001. 연속 대여일 (갭과 섬)

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `갭/섬` `ROW_NUMBER` `날짜 연산`

## 문제

고객 1~20번의 **연속 대여일 구간**(하루도 빠지지 않고 대여한 기간)을 모두 구하고, 2일 이상인 구간만 출력하세요.

- 출력: `customer_id`, `streak_start`, `streak_end`, `days` — `days` 내림차순, `customer_id`, `streak_start` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH d AS (
    SELECT DISTINCT customer_id, DATE(rental_date) AS day
    FROM rental
    WHERE customer_id <= 20
), g AS (
    SELECT customer_id, day,
           day - INTERVAL ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY day) DAY AS grp
    FROM d
)
SELECT customer_id, MIN(day) AS streak_start, MAX(day) AS streak_end, COUNT(*) AS days
FROM g
GROUP BY customer_id, grp
HAVING COUNT(*) >= 2
ORDER BY days DESC, customer_id, streak_start;
```

</details>

## 해설

**갭과 섬(gaps and islands)** 의 고전 기법: 연속된 날짜에서 `날짜 − 행번호` 는 **같은 값**이 됩니다.
(5/25−1 = 5/24, 5/26−2 = 5/24, 5/27−3 = 5/24 …) 이 값으로 GROUP BY 하면 연속 구간이 하나의 그룹이 됩니다.
CTE-015 의 재귀 풀이와 비교하면 훨씬 간결하고 빠릅니다.
