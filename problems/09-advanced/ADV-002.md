# ADV-002. 월별 코호트 리텐션

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `코호트` `리텐션` `피벗`

## 문제

고객을 **첫 대여 월**(코호트)로 묶고, 이후 각 달에 다시 대여한 고객 비율(리텐션)을 구하세요.

- `month_0` = 첫 달(항상 100), `month_1` = 다음 달 … `month_3` 까지
- 출력: `cohort`(YYYY-MM), `customers`, `month_0`, `month_1`, `month_2`, `month_3` (모두 % 소수 1자리) — `cohort` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH activity AS (
    SELECT DISTINCT customer_id, DATE_FORMAT(rental_date, '%Y-%m-01') AS month
    FROM rental
), cohort AS (
    SELECT customer_id, MIN(month) AS cohort_month
    FROM activity
    GROUP BY customer_id
), aged AS (
    SELECT c.cohort_month, a.customer_id,
           TIMESTAMPDIFF(MONTH, c.cohort_month, a.month) AS age
    FROM activity a
    JOIN cohort c ON c.customer_id = a.customer_id
)
SELECT DATE_FORMAT(cohort_month, '%Y-%m') AS cohort,
       COUNT(DISTINCT customer_id) AS customers,
       ROUND(100 * COUNT(DISTINCT CASE WHEN age = 0 THEN customer_id END) / COUNT(DISTINCT customer_id), 1) AS month_0,
       ROUND(100 * COUNT(DISTINCT CASE WHEN age = 1 THEN customer_id END) / COUNT(DISTINCT customer_id), 1) AS month_1,
       ROUND(100 * COUNT(DISTINCT CASE WHEN age = 2 THEN customer_id END) / COUNT(DISTINCT customer_id), 1) AS month_2,
       ROUND(100 * COUNT(DISTINCT CASE WHEN age = 3 THEN customer_id END) / COUNT(DISTINCT customer_id), 1) AS month_3
FROM aged
GROUP BY cohort_month
ORDER BY cohort_month;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| cohort | customers | month_0 | month_1 | month_2 | month_3 |
|---|---|---|---|---|---|
| 2005-05 | 520 | 100.0 | 98.5 | 100.0 | 100.0 |
| 2005-06 | 78 | 100.0 | 100.0 | 100.0 | 0.0 |
| 2005-07 | 1 | 100.0 | 100.0 | 0.0 | 0.0 |

## 해설

코호트 분석의 3단계: ① 활동 월 정리 → ② 고객별 첫 월(코호트) → ③ 경과 개월(age)로 피벗.
`COUNT(DISTINCT CASE WHEN 조건 THEN id END)` 는 조건을 만족하는 **고유 고객 수**입니다 (ELSE 가 없으면 NULL → 세지 않음).
결과: 2005-05 코호트가 520명으로 대부분이고 리텐션이 거의 100% 입니다.
2005-06 코호트의 month_3, 2005-07 코호트의 month_2 가 0 인 것은 **이탈이 아니라 2005-09 이후 데이터 공백** 때문입니다.
코호트 표의 0 을 보면 먼저 "그 달에 데이터가 존재하는가" 부터 확인하세요.
