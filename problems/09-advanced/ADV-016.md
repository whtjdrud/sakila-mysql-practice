# ADV-016. 배우 조합의 흥행력

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `셀프 조인` `집계 후 조인` `상대 비교`

## 문제

함께 5편 이상 출연한 배우 쌍에 대해, **함께 출연한 영화의 평균 대여 횟수**가 두 배우 각각의 전체 출연작 평균 대여 횟수보다 얼마나 높은지 구하세요.

- `pair_avg`: 공동 출연작의 평균 대여 횟수
- `solo_avg`: 두 배우 각자의 전체 출연작 평균 대여 횟수의 평균
- `lift`: pair_avg / solo_avg (소수 2자리)
- 대여 횟수는 재고가 없는 영화를 0으로 포함

출력: `actor_a`, `actor_b`, `films_together`, `pair_avg`, `solo_avg`, `lift` (평균은 소수 2자리) — `lift` 내림차순, `actor_a`, `actor_b` 순으로 상위 5쌍

**사용 테이블:** `film_actor`, `actor`, `inventory`, `rental`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH film_rentals AS (
    SELECT f.film_id, COUNT(r.rental_id) AS rentals
    FROM film f
    LEFT JOIN inventory i ON i.film_id      = f.film_id
    LEFT JOIN rental r    ON r.inventory_id = i.inventory_id
    GROUP BY f.film_id
), actor_avg AS (
    SELECT fa.actor_id, AVG(fr.rentals) AS avg_rentals
    FROM film_actor fa
    JOIN film_rentals fr ON fr.film_id = fa.film_id
    GROUP BY fa.actor_id
), pairs AS (
    SELECT a.actor_id AS a_id, b.actor_id AS b_id,
           COUNT(*) AS films_together, AVG(fr.rentals) AS pair_avg
    FROM film_actor a
    JOIN film_actor b    ON b.film_id = a.film_id AND b.actor_id > a.actor_id
    JOIN film_rentals fr ON fr.film_id = a.film_id
    GROUP BY a.actor_id, b.actor_id
    HAVING COUNT(*) >= 5
)
SELECT CONCAT(x.first_name, ' ', x.last_name) AS actor_a,
       CONCAT(y.first_name, ' ', y.last_name) AS actor_b,
       p.films_together,
       ROUND(p.pair_avg, 2) AS pair_avg,
       ROUND((aa.avg_rentals + ab.avg_rentals) / 2, 2) AS solo_avg,
       ROUND(p.pair_avg / ((aa.avg_rentals + ab.avg_rentals) / 2), 2) AS lift
FROM pairs p
JOIN actor_avg aa ON aa.actor_id = p.a_id
JOIN actor_avg ab ON ab.actor_id = p.b_id
JOIN actor x ON x.actor_id = p.a_id
JOIN actor y ON y.actor_id = p.b_id
ORDER BY lift DESC, actor_a, actor_b
LIMIT 5;
```

## 해설

"A 와 B 가 같이 나오면 더 잘 되나?" 를 **각자의 기준선 대비 상대값**으로 측정했습니다. 절대값만 보면 원래 인기 배우끼리의 조합이 늘 상위에 옵니다.
공동 출연 5편은 작은 표본이므로 lift 가 높아도 우연일 수 있습니다 — 표본 크기를 결과와 함께 보여주는 것이 정직한 분석입니다.
