# ADV-005. 장바구니 분석 (같은 날 함께 빌린 장르)

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `연관 규칙` `지지도` `신뢰도` `셀프 조인`

## 문제

고객이 **같은 날** 빌린 영화들을 하나의 "장바구니" 로 보고, 장르 쌍(A → B)의 연관 규칙을 구하세요.

- `support_ab`: A 와 B 를 함께 빌린 장바구니 수
- `confidence`: A 를 빌린 장바구니 중 B 도 빌린 비율 (소수 3자리)
- `lift`: confidence / (B 가 포함된 장바구니 비율) (소수 2자리)
- A ≠ B, `support_ab` 50 이상만

출력: `cat_a`, `cat_b`, `support_ab`, `confidence`, `lift` — `lift` 내림차순, `cat_a`, `cat_b` 순으로 상위 10개

**사용 테이블:** `rental`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH basket_items AS (
    SELECT DISTINCT r.customer_id, DATE(r.rental_date) AS day, c.name AS category
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
), baskets AS (
    SELECT COUNT(*) AS n FROM (SELECT DISTINCT customer_id, day FROM basket_items) b
), item_cnt AS (
    SELECT category, COUNT(*) AS cnt FROM basket_items GROUP BY category
), pairs AS (
    SELECT a.category AS cat_a, b.category AS cat_b, COUNT(*) AS support_ab
    FROM basket_items a
    JOIN basket_items b ON b.customer_id = a.customer_id
                       AND b.day         = a.day
                       AND b.category   <> a.category
    GROUP BY a.category, b.category
    HAVING COUNT(*) >= 50
)
SELECT p.cat_a, p.cat_b, p.support_ab,
       ROUND(p.support_ab / ia.cnt, 3) AS confidence,
       ROUND((p.support_ab / ia.cnt) / (ib.cnt / bs.n), 2) AS lift
FROM pairs p
JOIN item_cnt ia ON ia.category = p.cat_a
JOIN item_cnt ib ON ib.category = p.cat_b
CROSS JOIN baskets bs
ORDER BY lift DESC, p.cat_a, p.cat_b
LIMIT 10;
```

## 해설

**연관 규칙 분석**: 지지도(얼마나 자주), 신뢰도(A 이면 B 일 확률), 향상도(우연 대비 몇 배). lift > 1 이면 함께 빌리는 경향이 있습니다.
장바구니 안의 같은 장르는 `DISTINCT` 로 한 번만 셌습니다. Sakila 의 장르 조합은 무작위로 생성되어 lift 가 1 근처에 몰리는 것이 정상입니다 —
"의미 있는 연관이 없다" 는 것도 분석 결과입니다.
