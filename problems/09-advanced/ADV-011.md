# ADV-011. 영화 대여 수명 주기

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `첫/마지막 이벤트` `기간 집계`

## 문제

영화별 첫 대여일과 마지막 대여일 사이 기간(일), 그리고 **첫 대여 후 7일 안의 대여 비율**(초기 흥행도)을 구하세요.
대여 30회 이상 영화 중 초기 흥행도가 높은 5편을 출력합니다.

- 출력: `title`, `rentals`, `life_days`, `first_week_pct`(소수 1자리) — `first_week_pct` 내림차순, `title` 순

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH fr AS (
    SELECT i.film_id, r.rental_date,
           MIN(r.rental_date) OVER (PARTITION BY i.film_id) AS first_at,
           MAX(r.rental_date) OVER (PARTITION BY i.film_id) AS last_at,
           COUNT(*)           OVER (PARTITION BY i.film_id) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
)
SELECT f.title, fr.rentals,
       DATEDIFF(MAX(fr.last_at), MIN(fr.first_at)) AS life_days,
       ROUND(100 * AVG(fr.rental_date < fr.first_at + INTERVAL 7 DAY), 1) AS first_week_pct
FROM fr
JOIN film f ON f.film_id = fr.film_id
WHERE fr.rentals >= 30
GROUP BY f.film_id, f.title, fr.rentals
ORDER BY first_week_pct DESC, f.title
LIMIT 5;
```

</details>

## 해설

윈도우 함수로 영화별 첫 대여 시각을 각 행에 붙인 뒤, 그것과 비교해 조건부 평균을 냈습니다.
