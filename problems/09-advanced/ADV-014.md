# ADV-014. 첫 대여 장르가 재방문에 미치는 영향

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `첫 구매 분석` `코호트` `비교`

## 문제

고객의 **첫 대여 장르**별로, 그 고객들의 **첫 30일간 대여 횟수 평균**과 전체 기간 결제 합계 평균을 비교하세요.

- 출력: `first_category`, `customers`, `avg_rentals_30d`(소수 2자리), `avg_ltv`(소수 2자리) — `avg_rentals_30d` 내림차순, `first_category` 순

**사용 테이블:** `rental`, `payment`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH ordered AS (
    SELECT r.customer_id, r.rental_date, c.name AS category,
           ROW_NUMBER() OVER (PARTITION BY r.customer_id ORDER BY r.rental_date, r.rental_id) AS nth,
           MIN(r.rental_date) OVER (PARTITION BY r.customer_id) AS first_at
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
), cust AS (
    SELECT customer_id,
           MAX(CASE WHEN nth = 1 THEN category END) AS first_category,
           SUM(rental_date < first_at + INTERVAL 30 DAY) AS rentals_30d
    FROM ordered
    GROUP BY customer_id
), ltv AS (
    SELECT customer_id, SUM(amount) AS paid FROM payment GROUP BY customer_id
)
SELECT cu.first_category, COUNT(*) AS customers,
       ROUND(AVG(cu.rentals_30d), 2) AS avg_rentals_30d,
       ROUND(AVG(l.paid), 2) AS avg_ltv
FROM cust cu
JOIN ltv l ON l.customer_id = cu.customer_id
GROUP BY cu.first_category
ORDER BY avg_rentals_30d DESC, first_category;
```

## 해설

`MAX(CASE WHEN nth = 1 THEN category END)` 는 그룹 안에서 **특정 행의 값만 뽑는** 트릭입니다 (나머지 행은 NULL 이라 MAX 가 무시).
장르 간 차이가 작다면, 첫 장르보다 다른 요인이 재방문을 좌우한다는 뜻입니다. 표본 수(`customers`)가 작은 장르는 평균이 크게 흔들린다는 점도 고려하세요.
