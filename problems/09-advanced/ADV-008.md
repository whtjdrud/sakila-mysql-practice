# ADV-008. 재고 가동률

**유형:** 복합 분석 · **난이도:** ★★★★★ 최고급 · **태그:** `구간 합계` `가동률` `날짜 경계`

## 문제

2005년 7월(7/1 00:00 ~ 8/1 00:00) 동안 각 매장 재고가 **대여 중이었던 시간의 비율**(가동률)을 구하세요.
대여 기간이 7월 경계를 넘으면 7월 안에 걸친 부분만 계산합니다. 미반납은 8/1 까지 대여 중으로 봅니다.

- 가동률 = Σ(7월 내 대여 시간) / (재고 장수 × 7월 전체 시간)
- 출력: `store_id`, `copies`, `rented_hours`, `utilization_pct`(소수 2자리) — `store_id` 순

**사용 테이블:** `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH clipped AS (
    SELECT i.store_id,
           TIMESTAMPDIFF(SECOND,
               GREATEST(r.rental_date, '2005-07-01'),
               LEAST(COALESCE(r.return_date, '2005-08-01'), '2005-08-01')) AS secs
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    WHERE r.rental_date < '2005-08-01'
      AND COALESCE(r.return_date, '2005-08-01') > '2005-07-01'
), copies AS (
    SELECT store_id, COUNT(*) AS copies FROM inventory GROUP BY store_id
)
SELECT c.store_id, c.copies,
       ROUND(SUM(cl.secs) / 3600) AS rented_hours,
       ROUND(100 * SUM(cl.secs) / (c.copies * TIMESTAMPDIFF(SECOND, '2005-07-01', '2005-08-01')), 2) AS utilization_pct
FROM copies c
JOIN clipped cl ON cl.store_id = c.store_id
GROUP BY c.store_id, c.copies
ORDER BY c.store_id;
```

## 해설

**구간 겹침 계산**의 공식: 겹치는 길이 = `LEAST(끝1, 끝2) − GREATEST(시작1, 시작2)` (양수일 때만).
WHERE 의 두 조건은 "7월과 조금이라도 겹치는 대여" 를 고르는 표준 조건(`시작 < 구간끝 AND 끝 > 구간시작`)입니다.
