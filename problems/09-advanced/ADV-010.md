# ADV-010. 직원별 처리 성과 비교 (매장 보정)

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `윈도우` `지수화` `공정 비교`

## 문제

월별로 각 직원의 결제 처리액을 구하고, **그 달 두 직원 평균 대비 지수**(평균 = 100)를 구하세요. 2005년 데이터만 대상입니다.

- 출력: `month`(YYYY-MM), `staff`(이름), `amount`, `index_vs_avg`(소수 1자리) — `month`, `staff` 순

**사용 테이블:** `payment`, `staff`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT month, staff, amount,
       ROUND(100 * amount / AVG(amount) OVER (PARTITION BY month), 1) AS index_vs_avg
FROM (
    SELECT DATE_FORMAT(p.payment_date, '%Y-%m') AS month,
           s.first_name AS staff,
           SUM(p.amount) AS amount
    FROM payment p
    JOIN staff s ON s.staff_id = p.staff_id
    WHERE p.payment_date < '2006-01-01'
    GROUP BY month, s.staff_id, s.first_name
) t
ORDER BY month, staff;
```

</details>

## 해설

달마다 전체 규모가 크게 다르므로(5월 vs 7월) 절대 금액 대신 **같은 달 평균 대비 지수**로 비교해야 공정합니다.
지수화(indexing)는 계절성이나 규모 차이를 제거하는 가장 간단한 방법입니다.
