# ADV-006. ABC 재고 분석

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `파레토` `누적 비율` `분류`

## 문제

영화를 매출 기여도로 A/B/C 등급으로 나누세요. 매출 내림차순 누적 비율이 **70% 이하 = A**, **90% 이하 = B**, 나머지 = C 입니다.
(경계를 넘기는 영화는 그 상위 등급에 포함하지 않고 다음 등급으로 봅니다.)

- 출력: `abc`, `films`, `revenue`, `revenue_pct`(소수 1자리), `films_pct`(소수 1자리) — A → B → C 순

**사용 테이블:** `payment`, `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH film_rev AS (
    SELECT i.film_id, SUM(p.amount) AS revenue
    FROM payment p
    JOIN rental r    ON r.rental_id    = p.rental_id
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.film_id
), cum AS (
    SELECT film_id, revenue,
           SUM(revenue) OVER (ORDER BY revenue DESC, film_id ROWS UNBOUNDED PRECEDING) / SUM(revenue) OVER () AS cum_ratio
    FROM film_rev
), classed AS (
    SELECT *, CASE WHEN cum_ratio <= 0.7 THEN 'A' WHEN cum_ratio <= 0.9 THEN 'B' ELSE 'C' END AS abc
    FROM cum
)
SELECT abc, COUNT(*) AS films, SUM(revenue) AS revenue,
       ROUND(100 * SUM(revenue) / SUM(SUM(revenue)) OVER (), 1) AS revenue_pct,
       ROUND(100 * COUNT(*) / SUM(COUNT(*)) OVER (), 1) AS films_pct
FROM classed
GROUP BY abc
ORDER BY abc;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| abc | films | revenue | revenue_pct | films_pct |
|---|---|---|---|---|
| A | 438 | 47160.53 | 70.0 | 45.7 |
| B | 257 | 13481.55 | 20.0 | 26.8 |
| C | 263 | 6764.48 | 10.0 | 27.5 |

## 해설

"상위 20% 상품이 매출 80%" 같은 파레토 법칙을 확인하는 방법입니다. 결과에서 A 등급이 전체 영화의 몇 % 인지 보세요.
결과: 매출 70% 를 영화 **45.7%** 가 만듭니다. 전형적인 "20/80" 보다 훨씬 고르게 퍼져 있다는 것 — 이 또한 상품 구성에 대한 중요한 발견입니다.
집계 결과에 다시 윈도우(`SUM(SUM(revenue)) OVER ()`)를 쓸 수 있다는 점도 기억하세요.
