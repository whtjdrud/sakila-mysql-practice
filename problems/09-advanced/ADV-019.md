# ADV-019. 대여 기간 정책 적정성

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `분위수` `정책 분석` `윈도우`

## 문제

영화의 대여 기간 정책(`rental_duration` 3~7일)별로 실제 대여 기간(반납 − 대여, 일 단위 소수)의 **중앙값**과 **기한 내 반납률**을 구하세요.

- 출력: `rental_duration`, `rentals`, `median_days`(소수 2자리), `on_time_pct`(소수 1자리) — `rental_duration` 순

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH d AS (
    SELECT f.rental_duration,
           TIMESTAMPDIFF(MINUTE, r.rental_date, r.return_date) / 1440 AS days
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.return_date IS NOT NULL
), ranked AS (
    SELECT rental_duration, days,
           ROW_NUMBER() OVER (PARTITION BY rental_duration ORDER BY days) AS rn,
           COUNT(*)     OVER (PARTITION BY rental_duration) AS cnt
    FROM d
)
SELECT rental_duration, MAX(cnt) AS rentals,
       ROUND(AVG(CASE WHEN rn IN (FLOOR((cnt + 1) / 2), CEIL((cnt + 1) / 2)) THEN days END), 2) AS median_days,
       ROUND(100 * AVG(days <= rental_duration), 1) AS on_time_pct
FROM ranked
GROUP BY rental_duration
ORDER BY rental_duration;
```

</details>

## 해설

정책(허용 기간)이 길어도 실제 대여 기간 중앙값이 거의 같다면, **고객 행동은 정책과 무관**하다는 뜻입니다.
그렇다면 짧은 정책일수록 연체가 많아지고, 정책을 바꾸면 연체료 수익이 달라질 것입니다 — 분석이 정책 질문으로 이어지는 전형적인 예입니다.
중앙값을 CASE 로 골라 AVG 하는 방식으로, 한 번의 GROUP BY 안에서 다른 집계와 함께 계산했습니다.
