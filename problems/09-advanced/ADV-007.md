# ADV-007. 연체로 인한 재고 손실 기회

**유형:** 복합 분석 · **난이도:** ★★★★☆ 고급 · **태그:** `날짜 연산` `기회비용` `다중 CTE`

## 문제

반납 예정일(대여일 + `rental_duration`)을 넘겨 반납된 대여에 대해 **연체 일수**(올림한 일 단위)를 구하고,
연체 기간에 그 DVD 를 다른 사람에게 빌려줬다면 벌 수 있었던 **기회 매출**(연체 일수 / 대여 기간 × 대여료)을 장르별로 합산하세요.

- 출력: `category`, `late_rentals`, `late_days`, `lost_revenue`(소수 2자리) — `lost_revenue` 내림차순, `category` 순

**사용 테이블:** `rental`, `inventory`, `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH late AS (
    SELECT fc.category_id, f.rental_rate, f.rental_duration,
           CEIL(TIMESTAMPDIFF(MINUTE, r.rental_date + INTERVAL f.rental_duration DAY, r.return_date) / 1440) AS late_days
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film f           ON f.film_id      = i.film_id
    JOIN film_category fc ON fc.film_id     = f.film_id
    WHERE r.return_date > r.rental_date + INTERVAL f.rental_duration DAY
)
SELECT c.name AS category,
       COUNT(*) AS late_rentals,
       SUM(late_days) AS late_days,
       ROUND(SUM(late_days / rental_duration * rental_rate), 2) AS lost_revenue
FROM late
JOIN category c ON c.category_id = late.category_id
GROUP BY c.category_id, c.name
ORDER BY lost_revenue DESC, category;
```

## 해설

분 단위 차이를 1440 으로 나눠 **올림**하면 "하루라도 걸치면 1일" 규칙이 됩니다. `DATEDIFF` 는 시각을 무시해 연체를 과소 집계할 수 있습니다.
이런 가정 기반 지표는 정의(가정)를 리포트에 함께 적어 두어야 오해가 없습니다.
