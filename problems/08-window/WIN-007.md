# WIN-007. 일별 누적 매출

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `누적합` `SUM OVER ORDER BY`

## 문제

2005-07-05 ~ 2005-07-12 의 일별 매출과 **누적 매출**을 구하세요.

- 출력: `day`, `revenue`, `cumulative` — `day` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT day, revenue,
       SUM(revenue) OVER (ORDER BY day) AS cumulative
FROM (
    SELECT DATE(payment_date) AS day, SUM(amount) AS revenue
    FROM payment
    WHERE payment_date >= '2005-07-05' AND payment_date < '2005-07-13'
    GROUP BY day
) t
ORDER BY day;
```

</details>

## 해설

윈도우에 `ORDER BY` 를 넣으면 기본 프레임이 **"처음부터 현재 행까지"** (`RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`)가 되어 누적합이 됩니다.
CTE-009 의 재귀 누적합과 비교하면 훨씬 간단합니다.
