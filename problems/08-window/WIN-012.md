# WIN-012. 다음 대여까지 걸린 시간 (LEAD)

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `LEAD` `재방문 간격`

## 문제

고객별로 대여 후 **다음 대여까지 걸린 시간(일)** 의 평균을 구하고, 평균 간격이 가장 짧은 고객 5명을 출력하세요.

- 출력: `customer_id`, `rentals`, `avg_next_gap`(소수 2자리) — `avg_next_gap`, `customer_id` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, COUNT(*) AS rentals,
       ROUND(AVG(TIMESTAMPDIFF(MINUTE, rental_date, next_date)) / 1440, 2) AS avg_next_gap
FROM (
    SELECT customer_id, rental_date,
           LEAD(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id) AS next_date
    FROM rental
) t
GROUP BY customer_id
ORDER BY avg_next_gap, customer_id
LIMIT 5;
```

</details>

<summary>실행 결과 보기</summary>

| customer_id | rentals | avg_next_gap |
|---|---|---|
| 148 | 46 | 1.92 |
| 526 | 45 | 2.00 |
| 129 | 34 | 2.02 |
| 30 | 34 | 2.05 |
| 38 | 34 | 2.10 |

> 총 5행

</details>

## 해설

마지막 대여는 `next_date` 가 NULL 이라 `AVG` 에서 자동 제외됩니다. 그래서 `rentals`(전체 횟수)와 평균에 쓰인 개수는 1 차이 납니다.
`DATEDIFF` 대신 분 단위 `TIMESTAMPDIFF` 를 써서 같은 날 재방문도 0이 아닌 시간으로 반영했습니다.
