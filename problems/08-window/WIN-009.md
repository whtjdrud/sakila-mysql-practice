# WIN-009. 7일 이동 평균

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `이동 평균` `ROWS BETWEEN`

## 문제

2005-07-05 ~ 2005-07-31 의 일별 대여 건수와 **직전 6일 + 당일(7일) 이동 평균**(소수 1자리)을 구하세요.
대여가 있는 날만 대상으로 하고, 7일이 다 차지 않은 초반에도 가능한 범위에서 평균을 냅니다.

- 출력: `day`, `rentals`, `ma7` — `day` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT day, rentals,
       ROUND(AVG(rentals) OVER (ORDER BY day ROWS BETWEEN 6 PRECEDING AND CURRENT ROW), 1) AS ma7
FROM (
    SELECT DATE(rental_date) AS day, COUNT(*) AS rentals
    FROM rental
    WHERE rental_date >= '2005-07-05' AND rental_date < '2005-08-01'
    GROUP BY day
) t
ORDER BY day;
```

## 해설

`ROWS BETWEEN 6 PRECEDING AND CURRENT ROW` 는 "현재 행과 앞의 6개 행" 입니다. **날짜가 아니라 행 기준**이라
빠진 날짜가 있으면 7일보다 긴 기간을 평균내게 됩니다. 날짜 기준이 필요하면 CTE-005 처럼 달력을 먼저 채우거나
`RANGE BETWEEN INTERVAL 6 DAY PRECEDING AND CURRENT ROW` 를 사용하세요.
