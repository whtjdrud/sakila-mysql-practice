# WIN-024. 배우 출연작의 개봉 순서별 등급

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `ROW_NUMBER` `PARTITION BY` `다중 정렬`

## 문제

`actor_id` 1~3번 배우마다 출연작을 제목 순으로 번호 매겨 **처음 3편**의 `actor_id`, `nth`, `title`, `rating` 을 구하세요.
`actor_id`, `nth` 순.

**사용 테이블:** `film_actor`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT actor_id, nth, title, rating
FROM (
    SELECT fa.actor_id, f.title, f.rating,
           ROW_NUMBER() OVER (PARTITION BY fa.actor_id ORDER BY f.title) AS nth
    FROM film_actor fa
    JOIN film f ON f.film_id = fa.film_id
    WHERE fa.actor_id <= 3
) t
WHERE nth <= 3
ORDER BY actor_id, nth;
```

</details>

## 해설

여기서는 안쪽 `WHERE fa.actor_id <= 3` 이 결과를 바꾸지 않습니다 — 파티션(배우) 단위로 통째로 거르기 때문입니다.
**파티션 키로 거르는 필터는 안쪽에 둬도 안전하고 더 빠릅니다.** 반면 파티션 내부 행을 거르는 필터는 순위를 바꿉니다.
