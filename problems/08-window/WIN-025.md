# WIN-025. 결제 금액 이상치 탐지

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `AVG OVER` `STDDEV OVER` `Z-점수`

## 문제

고객별 결제 금액의 평균과 표준편차로 **Z-점수**를 계산하고, Z-점수가 3 이상인 결제(이상치)를 찾으세요.

- 출력: `payment_id`, `customer_id`, `amount`, `cust_avg`, `z`(소수 2자리) — `z` 내림차순, `payment_id` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT payment_id, customer_id, amount, cust_avg, z
FROM (
    SELECT payment_id, customer_id, amount,
           ROUND(AVG(amount) OVER (PARTITION BY customer_id), 2) AS cust_avg,
           ROUND((amount - AVG(amount) OVER (PARTITION BY customer_id))
                 / NULLIF(STDDEV_POP(amount) OVER (PARTITION BY customer_id), 0), 2) AS z
    FROM payment
) t
WHERE z >= 3
ORDER BY z DESC, payment_id;
```

## 해설

Z-점수 = (값 − 평균) / 표준편차. **각 고객의 평소 패턴 대비** 비정상적으로 큰 결제를 찾는 이상 거래 탐지의 기초입니다.
표준편차가 0(모든 결제가 같은 금액)인 고객은 `NULLIF` 로 0 나눗셈을 막았습니다.
