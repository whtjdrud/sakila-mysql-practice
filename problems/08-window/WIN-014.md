# WIN-014. N번째 값

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `NTH_VALUE`

## 문제

장르별로 대여료 × 상영 시간(`rental_rate * length`)이 **두 번째로 큰** 영화의 제목을 구하세요. 동점이면 `title` 순.

- 출력: `category`, `second_title` — `category` 순

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DISTINCT c.name AS category,
       NTH_VALUE(f.title, 2) OVER (
           PARTITION BY c.category_id
           ORDER BY f.rental_rate * f.length DESC, f.title
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS second_title
FROM film f
JOIN film_category fc ON fc.film_id    = f.film_id
JOIN category c       ON c.category_id = fc.category_id
ORDER BY category;
```

</details>

## 해설

`NTH_VALUE(컬럼, n)` 은 프레임 안의 n번째 값입니다. 역시 프레임을 전체로 잡지 않으면 앞쪽 행들에서 NULL 이 나옵니다.
`ROW_NUMBER() ... WHERE rn = 2` 로도 같은 결과를 얻을 수 있습니다.
