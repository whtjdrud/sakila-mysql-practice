# WIN-013. 첫 값과 마지막 값

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `FIRST_VALUE` `LAST_VALUE` `프레임`

## 문제

고객 1~5번 각각의 **첫 대여 영화**와 **마지막 대여 영화** 제목을 구하세요.

- 출력: `customer_id`, `first_title`, `last_title` — `customer_id` 순
- 같은 시각이면 `rental_id` 가 작은 것이 먼저

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DISTINCT customer_id,
       FIRST_VALUE(title) OVER w AS first_title,
       LAST_VALUE(title)  OVER w AS last_title
FROM (
    SELECT r.customer_id, r.rental_date, r.rental_id, f.title
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.customer_id <= 5
) t
WINDOW w AS (PARTITION BY customer_id ORDER BY rental_date, rental_id
             ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
ORDER BY customer_id;
```

</details>

## 해설

⚠️ `LAST_VALUE` 의 가장 흔한 실수: 기본 프레임이 "처음 ~ **현재 행**" 이라 프레임을 지정하지 않으면 **항상 현재 행 자신**을 돌려줍니다.
`ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING` 으로 파티션 전체를 프레임으로 잡아야 진짜 마지막 값이 나옵니다.
