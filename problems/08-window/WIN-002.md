# WIN-002. ROW_NUMBER · RANK · DENSE_RANK 비교

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `RANK` `DENSE_RANK` `ROW_NUMBER`

## 문제

대여료(`rental_rate`)가 높은 순으로 세 가지 순위를 매기고, `film_id` 1~10번 영화만 출력하세요.

- 출력: `film_id`, `rental_rate`, `row_num`, `rnk`, `dense_rnk` — `film_id` 순
- `row_num` 은 동점일 때 `film_id` 순으로 매깁니다.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id, rental_rate, row_num, rnk, dense_rnk
FROM (
    SELECT film_id, rental_rate,
           ROW_NUMBER() OVER (ORDER BY rental_rate DESC, film_id) AS row_num,
           RANK()       OVER (ORDER BY rental_rate DESC)          AS rnk,
           DENSE_RANK() OVER (ORDER BY rental_rate DESC)          AS dense_rnk
    FROM film
) t
WHERE film_id <= 10
ORDER BY film_id;
```

</details>

## 해설

대여료는 3종(4.99, 2.99, 0.99)뿐이라 차이가 극명합니다.
- `ROW_NUMBER`: 동점이어도 1, 2, 3 … 고유 번호
- `RANK`: 동점은 같은 순위, 다음 순위는 **건너뜀** (4.99 가 336편이면 2.99 는 337위)
- `DENSE_RANK`: 동점은 같은 순위, 다음 순위는 **연속** (2.99 는 2위)
순위를 **먼저 전체에 매긴 뒤** 바깥에서 거르는 것이 중요합니다 — WHERE 를 안쪽에 두면 10편 안에서만 순위가 매겨집니다.
