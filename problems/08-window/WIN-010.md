# WIN-010. 직전 대여와의 간격 (LAG)

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `LAG` `이전 행`

## 문제

고객 1번의 대여마다 직전 대여일과 간격(일)을 `LAG` 로 구하세요. (SUB-030 과 같은 문제)

- 출력: `rental_id`, `rental_date`, `prev_rental_date`, `gap_days` — `rental_date`, `rental_id` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, rental_date,
       LAG(rental_date) OVER w AS prev_rental_date,
       DATEDIFF(rental_date, LAG(rental_date) OVER w) AS gap_days
FROM rental
WHERE customer_id = 1
WINDOW w AS (ORDER BY rental_date, rental_id)
ORDER BY rental_date, rental_id;
```

## 해설

`LAG(컬럼, n, 기본값)` 은 n행 앞(기본 1), `LEAD` 는 n행 뒤의 값을 가져옵니다. 첫 행의 LAG 는 기본값(생략 시 NULL)입니다.
SUB-030 의 상관 서브쿼리 풀이와 결과는 같지만, 동시각 대여가 있으면 정렬 기준에 따라 미세하게 다를 수 있습니다.
