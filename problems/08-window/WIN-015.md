# WIN-015. 4분위 그룹 나누기

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `NTILE` `분위수`

## 문제

고객을 결제 합계 기준으로 **4개 그룹(NTILE)** 으로 나누고, 그룹별 고객 수·최소·최대·평균 합계를 구하세요.

- 출력: `quartile`(1 = 상위), `customers`, `min_total`, `max_total`, `avg_total`(소수 2자리) — `quartile` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT quartile, COUNT(*) AS customers,
       MIN(total) AS min_total, MAX(total) AS max_total, ROUND(AVG(total), 2) AS avg_total
FROM (
    SELECT customer_id, SUM(amount) AS total,
           NTILE(4) OVER (ORDER BY SUM(amount) DESC, customer_id) AS quartile
    FROM payment
    GROUP BY customer_id
) t
GROUP BY quartile
ORDER BY quartile;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| quartile | customers | min_total | max_total | avg_total |
|---|---|---|---|---|
| 1 | 150 | 128.71 | 221.55 | 145.86 |
| 2 | 150 | 110.73 | 128.70 | 118.81 |
| 3 | 150 | 94.78 | 110.73 | 102.86 |
| 4 | 149 | 50.85 | 94.77 | 82.46 |

> 총 4행

</details>

## 해설

`NTILE(n)` 은 정렬된 행을 **개수 기준으로** n등분합니다. 599명 / 4 = 149.75 이므로 앞 그룹부터 150, 150, 150, 149 명이 됩니다.
값 기준이 아니라 개수 기준이라 경계값의 동점 고객이 서로 다른 그룹에 들어갈 수 있습니다.
