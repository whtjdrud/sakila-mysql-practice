# WIN-004. 공정한 TOP 10 (동점 포함)

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `RANK` `동점 처리`

## 문제

대여 횟수 기준 **10위까지의 모든 영화**(동점 포함)를 구하세요. (JOIN-005 의 LIMIT 함정을 해결하는 문제)

- 출력: `rnk`, `title`, `rental_count` — `rnk`, `title` 순

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rnk, title, rental_count
FROM (
    SELECT f.title, COUNT(*) AS rental_count,
           RANK() OVER (ORDER BY COUNT(*) DESC) AS rnk
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    GROUP BY f.film_id, f.title
) t
WHERE rnk <= 10
ORDER BY rnk, title;
```

## 해설

윈도우 함수 안에 **집계 함수**를 쓸 수 있습니다 (`RANK() OVER (ORDER BY COUNT(*) DESC)`). GROUP BY 가 먼저 실행되고 그 결과에 윈도우가 적용됩니다.
`LIMIT 10` 은 10행을 자르지만 `RANK() <= 10` 은 10위 동점까지 모두 포함해 **16편**이 나옵니다.
