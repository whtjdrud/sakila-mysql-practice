# WIN-021. 고객의 N번째 대여 장르

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `ROW_NUMBER` `첫 구매 분석`

## 문제

모든 고객의 **첫 번째 대여** 영화 장르를 집계해, 첫 대여 장르별 고객 수를 구하세요.

- 출력: `first_category`, `customers` — `customers` 내림차순, `first_category` 순
- 같은 시각이면 `rental_id` 가 작은 것이 첫 대여

**사용 테이블:** `rental`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH ordered AS (
    SELECT r.customer_id, c.name AS category,
           ROW_NUMBER() OVER (PARTITION BY r.customer_id ORDER BY r.rental_date, r.rental_id) AS nth
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
)
SELECT category AS first_category, COUNT(*) AS customers
FROM ordered
WHERE nth = 1
GROUP BY category
ORDER BY customers DESC, first_category;
```

## 해설

"첫 구매 상품" 은 고객 획득 분석의 핵심 질문입니다. `nth = 2` 로 바꾸면 두 번째 대여 장르, 첫 장르와 두 번째 장르를 함께 보면 **전이 행렬**이 됩니다.
