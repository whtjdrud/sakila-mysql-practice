# WIN-016. 백분위 순위

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `PERCENT_RANK` `CUME_DIST`

## 문제

상영 시간 기준 `PERCENT_RANK` 와 `CUME_DIST` 를 구하고, 상영 시간이 정확히 **60, 90, 120, 150, 180분**인 영화의 값만 중복 없이 출력하세요.

- 출력: `length`, `pct_rank`, `cum_dist` (둘 다 소수 4자리) — `length` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DISTINCT length, pct_rank, cum_dist
FROM (
    SELECT length,
           ROUND(PERCENT_RANK() OVER (ORDER BY length), 4) AS pct_rank,
           ROUND(CUME_DIST()    OVER (ORDER BY length), 4) AS cum_dist
    FROM film
) t
WHERE length IN (60, 90, 120, 150, 180)
ORDER BY length;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| length | pct_rank | cum_dist |
|---|---|---|
| 60 | 0.0961 | 0.104 |
| 90 | 0.3203 | 0.325 |
| 120 | 0.5345 | 0.543 |
| 150 | 0.7508 | 0.758 |
| 180 | 0.955 | 0.961 |

> 총 5행

</details>

## 해설

- `PERCENT_RANK` = (RANK − 1) / (전체 행 − 1): 나보다 **작은** 값의 비율 (0 ~ 1)
- `CUME_DIST` = (나 이하인 행 수) / 전체 행: 나 **이하** 값의 비율 (0 초과 ~ 1)
"120분 영화는 하위 몇 %인가?" 같은 질문에 답할 때 씁니다.
별칭을 `cume_dist` 로 지으면 문법 오류가 납니다 — MySQL 8.0 에서 윈도우 함수 이름은 **예약어**입니다. (`rank`, `row_number` 등도 마찬가지)
