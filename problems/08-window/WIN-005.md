# WIN-005. 전체 대비 비율

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `SUM OVER` `비율`

## 문제

등급별 영화 수와 **전체 대비 비율**(%)을 윈도우 함수로 구하세요.

- 출력: `rating`, `films`, `pct`(소수 1자리) — `rating` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rating, COUNT(*) AS films,
       ROUND(100 * COUNT(*) / SUM(COUNT(*)) OVER (), 1) AS pct
FROM film
GROUP BY rating
ORDER BY rating;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rating | films | pct |
|---|---|---|
| G | 178 | 17.8 |
| PG | 194 | 19.4 |
| PG-13 | 223 | 22.3 |
| R | 195 | 19.5 |
| NC-17 | 210 | 21.0 |

> 총 5행

</details>

## 해설

`OVER ()` 는 **전체 결과**를 하나의 윈도우로 봅니다. `SUM(COUNT(*)) OVER ()` = 그룹별 개수의 총합.
SUB-007 의 스칼라 서브쿼리 방식보다 테이블을 한 번만 읽습니다.
