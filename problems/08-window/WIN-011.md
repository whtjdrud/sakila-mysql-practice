# WIN-011. 전월 대비 매출 증감률

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `LAG` `증감률`

## 문제

월별 매출과 전월 매출, 증감률(%)을 구하세요. 데이터가 있는 달만 대상입니다.

- 출력: `month`(YYYY-MM), `revenue`, `prev_revenue`, `mom_pct`(소수 1자리) — `month` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT month, revenue,
       LAG(revenue) OVER (ORDER BY month) AS prev_revenue,
       ROUND(100 * (revenue / LAG(revenue) OVER (ORDER BY month) - 1), 1) AS mom_pct
FROM (
    SELECT DATE_FORMAT(payment_date, '%Y-%m') AS month, SUM(amount) AS revenue
    FROM payment
    GROUP BY month
) t
ORDER BY month;
```

</details>

<details>
<summary>실행 결과 보기</summary>

|---|---|---|---|
| 2005-05 | 4824.43 | NULL | NULL |
| 2005-06 | 9631.88 | 4824.43 | 99.6 |

| 2005-08 | 24072.13 | 28373.89 | -15.2 |

## 해설

⚠️ 2006-02 의 "전월" 은 LAG 기준으로 **2005-08** 입니다. 실제 전월(2006-01)은 데이터가 없는데 LAG 는 단순히 "직전 행"을 가져오기 때문입니다.
빈 달이 있을 수 있는 시계열에서는 CTE-006 처럼 월 달력을 먼저 채우거나 SUB-032 처럼 날짜 연산으로 전월을 찾으세요.
