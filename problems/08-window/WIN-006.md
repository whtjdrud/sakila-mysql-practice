# WIN-006. 그룹 평균과 비교

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `AVG OVER` `PARTITION BY`

## 문제

`film_id` 1~10번 영화마다 자기 등급의 평균 상영 시간 `rating_avg` 와 차이 `diff` 를 구하세요 (둘 다 소수 1자리).

- 출력: `film_id`, `title`, `rating`, `length`, `rating_avg`, `diff` — `film_id` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id, title, rating, length, rating_avg, diff
FROM (
    SELECT film_id, title, rating, length,
           ROUND(AVG(length) OVER (PARTITION BY rating), 1)          AS rating_avg,
           ROUND(length - AVG(length) OVER (PARTITION BY rating), 1) AS diff
    FROM film
) t
WHERE film_id <= 10
ORDER BY film_id;
```

## 해설

`PARTITION BY` 만 있고 `ORDER BY` 가 없으면 윈도우는 **그룹 전체**입니다. 각 행 옆에 그룹 평균이 붙습니다.
역시 순서가 중요합니다 — `WHERE film_id <= 10` 을 안쪽에 두면 10편끼리의 평균이 됩니다.
