# WIN-018. 매장별 매출 점유율 추이

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `PARTITION BY` `점유율`

## 문제

월별로 각 매장(`staff.store_id`)의 매출과 **그 달 전체 매출 중 점유율**(%)을 구하세요.

- 출력: `month`(YYYY-MM), `store_id`, `revenue`, `share_pct`(소수 1자리) — `month`, `store_id` 순

**사용 테이블:** `payment`, `staff`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT month, store_id, revenue,
       ROUND(100 * revenue / SUM(revenue) OVER (PARTITION BY month), 1) AS share_pct
FROM (
    SELECT DATE_FORMAT(p.payment_date, '%Y-%m') AS month, s.store_id, SUM(p.amount) AS revenue
    FROM payment p
    JOIN staff s ON s.staff_id = p.staff_id
    GROUP BY month, s.store_id
) t
ORDER BY month, store_id;
```

## 해설

`SUM() OVER (PARTITION BY month)` 로 "같은 달의 합계" 를 각 행 옆에 붙이면 점유율 계산이 한 줄로 끝납니다.
