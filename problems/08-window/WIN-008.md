# WIN-008. 고객별 누적 결제와 결제 순번

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `누적합` `PARTITION BY` `ROWS`

## 문제

고객 1번의 결제마다 결제 순번 `nth`, 누적 결제액 `running_total`, 지금까지의 평균 결제액 `running_avg`(소수 2자리)를 구하세요.

- 출력: `payment_id`, `payment_date`, `amount`, `nth`, `running_total`, `running_avg` — `payment_date`, `payment_id` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT payment_id, payment_date, amount,
       ROW_NUMBER() OVER w AS nth,
       SUM(amount)  OVER w AS running_total,
       ROUND(AVG(amount) OVER w, 2) AS running_avg
FROM payment
WHERE customer_id = 1
WINDOW w AS (ORDER BY payment_date, payment_id ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)
ORDER BY payment_date, payment_id;
```

## 해설

같은 윈도우를 여러 번 쓸 때는 `WINDOW w AS (...)` 로 이름을 붙여 재사용합니다.
`RANGE` 프레임은 정렬 값이 같은 행(동시각)을 **한꺼번에** 포함하고, `ROWS` 는 **물리적 행 단위**로 셉니다. 누적합에서 동점이 있으면 결과가 달라지니 `ROWS` 를 명시하는 습관을 들이세요.
