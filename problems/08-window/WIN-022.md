# WIN-022. 매장별 일 매출 순위 변동

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `RANK` `LAG` `순위 변동`

## 문제

2005-08-16 ~ 2005-08-23 의 날짜별로 **장르 매출 순위**를 매기고, 전날 대비 순위 변동을 구하세요. `Sports`, `Animation`, `Drama` 장르만 출력합니다.

- 출력: `day`, `category`, `revenue`, `rnk`, `rank_change`(전날 순위 − 오늘 순위, 첫날은 NULL) — `category`, `day` 순

**사용 테이블:** `payment`, `rental`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH daily AS (
    SELECT DATE(p.payment_date) AS day, c.name AS category, SUM(p.amount) AS revenue
    FROM payment p
    JOIN rental r         ON r.rental_id    = p.rental_id
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
    WHERE p.payment_date >= '2005-08-16' AND p.payment_date < '2005-08-24'
    GROUP BY day, c.name
), ranked AS (
    SELECT *, RANK() OVER (PARTITION BY day ORDER BY revenue DESC) AS rnk
    FROM daily
), moved AS (
    SELECT *, CAST(LAG(rnk) OVER (PARTITION BY category ORDER BY day) AS SIGNED) - CAST(rnk AS SIGNED) AS rank_change
    FROM ranked
)
SELECT day, category, revenue, rnk, rank_change
FROM moved
WHERE category IN ('Sports', 'Animation', 'Drama')
ORDER BY category, day;
```

## 해설

윈도우를 **두 번 다른 방향**으로 씁니다: 순위는 날짜별(`PARTITION BY day`), 변동은 장르별(`PARTITION BY category`).
필터(`WHERE category IN ...`)는 순위 계산 **후에** 해야 16개 장르 전체 기준 순위가 유지됩니다.
⚠️ `RANK()` 는 **BIGINT UNSIGNED** 를 돌려줍니다. 순위가 떨어지면(3 − 5) 음수가 되어 `out of range` 오류가 나므로 `CAST(... AS SIGNED)` 가 필요합니다.
