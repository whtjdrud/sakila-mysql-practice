# WIN-017. 중앙값 (윈도우 함수)

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `중앙값` `ROW_NUMBER` `COUNT OVER`

## 문제

장르별 상영 시간의 **중앙값**을 구하세요. (SUB-023 의 서브쿼리 풀이와 비교)

- 출력: `category`, `films`, `median_length` — `category` 순

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT category, MAX(cnt) AS films, AVG(length) AS median_length
FROM (
    SELECT c.name AS category, f.length,
           ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY f.length, f.film_id) AS rn,
           COUNT(*)     OVER (PARTITION BY c.category_id) AS cnt
    FROM film f
    JOIN film_category fc ON fc.film_id    = f.film_id
    JOIN category c       ON c.category_id = fc.category_id
) t
WHERE rn IN (FLOOR((cnt + 1) / 2), CEIL((cnt + 1) / 2))
GROUP BY category
ORDER BY category;
```

## 해설

행 번호와 그룹 크기를 함께 구한 뒤, 가운데 행(홀수면 1개, 짝수면 2개)만 남겨 평균을 냅니다.
cnt = 74 면 rn 37, 38 의 평균, cnt = 51 이면 rn 26 하나입니다. 그룹별 중앙값도 한 번에 구할 수 있습니다.
