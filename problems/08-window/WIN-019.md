# WIN-019. 처음으로 누적 50% 를 넘는 장르 (파레토)

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `누적 비율` `파레토`

## 문제

장르를 매출 내림차순으로 정렬했을 때 누적 매출 비율을 구하고, **누적 비율이 50% 에 도달하기까지 필요한 장르**를 모두 출력하세요.
(50% 를 처음 넘기는 장르까지 포함)

- 출력: `category`, `revenue`, `cum_pct`(소수 1자리) — 매출 내림차순, `category` 순

**사용 테이블:** `payment`, `rental`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH cat_rev AS (
    SELECT c.name AS category, SUM(p.amount) AS revenue
    FROM payment p
    JOIN rental r         ON r.rental_id    = p.rental_id
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
    GROUP BY c.name
), cum AS (
    SELECT category, revenue,
           SUM(revenue) OVER (ORDER BY revenue DESC, category ROWS UNBOUNDED PRECEDING)
             / SUM(revenue) OVER () AS cum_ratio,
           SUM(revenue) OVER (ORDER BY revenue DESC, category ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)
             / SUM(revenue) OVER () AS prev_ratio
    FROM cat_rev
)
SELECT category, revenue, ROUND(100 * cum_ratio, 1) AS cum_pct
FROM cum
WHERE COALESCE(prev_ratio, 0) < 0.5
ORDER BY revenue DESC, category;
```

## 해설

"누적 비율 < 50%" 로 거르면 50% 를 **넘기는 장르**가 빠집니다. 그래서 "**직전까지의** 누적 비율 < 50%" 로 조건을 바꿨습니다.
`ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING` 은 현재 행을 제외한 누적이며, 첫 행에서는 NULL 입니다.
장르 16개 중 절반 매출을 내는 데 몇 개가 필요한지 보면 매출이 얼마나 고르게 퍼져 있는지 알 수 있습니다.
