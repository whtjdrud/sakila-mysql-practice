# WIN-020. 연속 증가 구간 찾기

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `LAG` `플래그` `누적합 그룹`

## 문제

2005-07-05 ~ 2005-07-31 의 일별 대여 건수에서 **전날보다 증가한 날**을 표시하고, 증가가 연속된 구간의 길이를 구하세요.
(대여가 있는 날만 대상, "전날" 은 직전 데이터 행)

- 출력: `day`, `rentals`, `is_up`(1/0), `up_streak`(현재까지 연속 증가 일수, 증가가 아니면 0) — `day` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH d AS (
    SELECT DATE(rental_date) AS day, COUNT(*) AS rentals
    FROM rental
    WHERE rental_date >= '2005-07-05' AND rental_date < '2005-08-01'
    GROUP BY day
), f AS (
    SELECT day, rentals,
           COALESCE(rentals > LAG(rentals) OVER (ORDER BY day), 0) AS is_up
    FROM d
), g AS (
    SELECT *, SUM(is_up = 0) OVER (ORDER BY day ROWS UNBOUNDED PRECEDING) AS grp
    FROM f
)
SELECT day, rentals, is_up,
       CASE WHEN is_up = 1
            THEN SUM(is_up) OVER (PARTITION BY grp ORDER BY day ROWS UNBOUNDED PRECEDING)
            ELSE 0 END AS up_streak
FROM g
ORDER BY day;
```

## 해설

"증가가 끊길 때마다 그룹 번호를 1씩 올리는" 기법입니다: `SUM(끊김 플래그) OVER (ORDER BY ...)`.
같은 그룹 안에서 다시 누적하면 연속 길이가 됩니다. 스트릭(연속 출석, 연속 상승) 계산의 정석입니다.
