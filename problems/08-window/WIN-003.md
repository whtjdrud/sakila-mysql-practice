# WIN-003. 장르별 영화 순위

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `PARTITION BY` `ROW_NUMBER`

## 문제

장르별로 상영 시간이 긴 순서대로 번호를 매기고 **각 장르의 상위 2편**을 조회하세요.

- 출력: `category`, `rn`, `title`, `length` — `category`, `rn` 순
- 동점이면 `title` 순

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH ranked AS (
    SELECT c.name AS category, f.title, f.length,
           ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY f.length DESC, f.title) AS rn
    FROM film f
    JOIN film_category fc ON fc.film_id    = f.film_id
    JOIN category c       ON c.category_id = fc.category_id
)
SELECT category, rn, title, length
FROM ranked
WHERE rn <= 2
ORDER BY category, rn;
```

</details>

## 해설

`PARTITION BY` 는 윈도우를 그룹별로 나눕니다. 그룹마다 번호가 1부터 다시 시작합니다.
**그룹별 TOP N** 의 가장 일반적인 해법입니다 (SUB-010 의 상관 서브쿼리, SUB-028 의 LATERAL 과 비교해 보세요).
