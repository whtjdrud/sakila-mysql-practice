# WIN-023. 이전 최고 기록 갱신

**유형:** 윈도우 함수 · **난이도:** ★★★★☆ 고급 · **태그:** `MAX OVER` `신기록`

## 문제

2005년 7월 일별 대여 건수에서 **그때까지의 최고 기록을 갱신한 날**만 출력하세요.

- 출력: `day`, `rentals`, `prev_best`(그 전날까지의 최고, 첫날은 NULL) — `day` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH d AS (
    SELECT DATE(rental_date) AS day, COUNT(*) AS rentals
    FROM rental
    WHERE rental_date >= '2005-07-01' AND rental_date < '2005-08-01'
    GROUP BY day
), m AS (
    SELECT day, rentals,
           MAX(rentals) OVER (ORDER BY day ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS prev_best
    FROM d
)
SELECT day, rentals, prev_best
FROM m
WHERE prev_best IS NULL OR rentals > prev_best
ORDER BY day;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| day | rentals | prev_best |

| 2005-07-05 | 27 | nan |

| 2005-07-31 | 679 | 649.0 |

> 총 6행

</details>

## 해설

"현재 행을 제외한 누적 최댓값" 과 비교하면 **신기록 여부**를 판정할 수 있습니다. 주가 신고가, 최고 매출일 분석에 씁니다.
