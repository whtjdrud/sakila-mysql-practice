# WIN-026. 대여 간격 분포 (LAG + 구간화)

**유형:** 윈도우 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `LAG` `구간화` `분포`

## 문제

모든 고객의 연속된 두 대여 사이 간격(일, `DATEDIFF`)을 구하고 구간별 건수를 집계하세요.

- 구간: `당일`(0), `1~3일`, `4~7일`, `8~30일`, `31일+`
- 출력: `gap_bucket`, `cnt` — 위 순서대로

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT CASE WHEN gap = 0 THEN '당일'
            WHEN gap <= 3 THEN '1~3일'
            WHEN gap <= 7 THEN '4~7일'
            WHEN gap <= 30 THEN '8~30일'
            ELSE '31일+' END AS gap_bucket,
       COUNT(*) AS cnt
FROM (
    SELECT DATEDIFF(rental_date,
                    LAG(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id)) AS gap
    FROM rental
) t
WHERE gap IS NOT NULL
GROUP BY gap_bucket
ORDER BY FIELD(gap_bucket, '당일', '1~3일', '4~7일', '8~30일', '31일+');
```

</details>

## 해설

각 고객의 첫 대여는 이전 값이 없어 NULL 이므로 제외했습니다. 재방문 주기 분포는 리마인드 메시지 발송 시점을 정하는 근거가 됩니다.
Sakila 는 데이터가 몇 개의 기간에 몰려 있어 `8~30일`, `31일+` 구간이 "빈 기간을 건너뛴 간격" 을 반영한다는 점도 함께 해석하세요.
