# WIN-001. 행 번호 붙이기

**유형:** 윈도우 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `ROW_NUMBER` `OVER`

## 문제

가장 긴 영화부터 순서대로 번호를 붙여 상위 10편의 `rn`, `title`, `length` 를 조회하세요.
`length` 내림차순, 같으면 `title` 순으로 번호를 매깁니다.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT ROW_NUMBER() OVER (ORDER BY length DESC, title) AS rn,
       title, length
FROM film
ORDER BY rn
LIMIT 10;
```

</details>

## 해설

윈도우 함수는 `함수() OVER (...)` 형태이며, **행을 줄이지 않고** 각 행 옆에 계산 결과를 붙입니다. (GROUP BY 와의 가장 큰 차이)
`OVER` 안의 `ORDER BY` 는 번호를 매기는 순서이고, 결과의 출력 순서는 바깥 `ORDER BY` 가 정합니다.
