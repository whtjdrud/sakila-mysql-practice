# CTE-001. 첫 CTE

**유형:** CTE · **난이도:** ★★☆☆☆ 초급 · **태그:** `WITH` `CTE 기초`

## 문제

CTE 로 고객별 결제 합계 `customer_totals` 를 정의한 뒤, 합계가 평균 이상인 고객 수와 전체 고객 수를 구하세요.

- 출력: `above_avg`, `total_customers`

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH customer_totals AS (
    SELECT customer_id, SUM(amount) AS total
    FROM payment
    GROUP BY customer_id
)
SELECT SUM(total >= (SELECT AVG(total) FROM customer_totals)) AS above_avg,
       COUNT(*) AS total_customers
FROM customer_totals;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| above_avg | total_customers |
|---|---|
| 285 | 599 |

> 총 1행

</details>

## 해설

`WITH 이름 AS (쿼리)` 로 정의한 CTE 는 이어지는 쿼리에서 **테이블처럼 여러 번** 참조할 수 있습니다.
파생 테이블은 한 번 정의하면 그 자리에서만 쓸 수 있어 같은 서브쿼리를 반복해야 했지만, CTE 는 이름으로 재사용합니다.
