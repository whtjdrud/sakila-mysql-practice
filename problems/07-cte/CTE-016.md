# CTE-016. 재고 회전율 분석

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `다중 CTE` `비율` `재고`

## 문제

장르별 **재고 회전율**(대여 횟수 / 재고 장수)과 **재고 1장당 매출**을 구하세요.

- 출력: `category`, `copies`, `rentals`, `turnover`(소수 2자리), `revenue_per_copy`(소수 2자리)
- `turnover` 내림차순, `category` 순

**사용 테이블:** `inventory`, `rental`, `payment`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH inv AS (
    SELECT fc.category_id, COUNT(*) AS copies
    FROM inventory i
    JOIN film_category fc ON fc.film_id = i.film_id
    GROUP BY fc.category_id
), rent AS (
    SELECT fc.category_id, COUNT(*) AS rentals, SUM(p.amount) AS revenue
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    LEFT JOIN payment p   ON p.rental_id    = r.rental_id
    GROUP BY fc.category_id
)
SELECT c.name AS category, inv.copies, rent.rentals,
       ROUND(rent.rentals / inv.copies, 2) AS turnover,
       ROUND(rent.revenue / inv.copies, 2) AS revenue_per_copy
FROM category c
JOIN inv  ON inv.category_id  = c.category_id
JOIN rent ON rent.category_id = c.category_id
ORDER BY turnover DESC, category;
```

## 해설

분자(대여)와 분모(재고)를 **따로 집계**해야 정확합니다. 한 번에 `inventory LEFT JOIN rental` 하고 `COUNT(DISTINCT inventory_id)` 로도 되지만,
결제 합계까지 붙이면 팬아웃 문제가 생깁니다. 대여 1건에 결제가 여러 건일 수 있으므로 `rent` CTE 에서도 그 점을 확인해 보세요.
