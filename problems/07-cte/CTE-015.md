# CTE-015. 재귀로 구하는 연속 대여일

**유형:** CTE · **난이도:** ★★★★★ 최고급 · **태그:** `WITH RECURSIVE` `연속 구간`

## 문제

고객 1~20번 중 **며칠 연속으로** 대여한 기록이 가장 긴 고객 5명을 구하세요. 재귀 CTE 로 "다음 날에도 대여했는가" 를 따라가세요.

- 출력: `customer_id`, `streak_start`, `streak_days`
- `streak_days` 내림차순, `customer_id`, `streak_start` 순 (고객당 가장 긴 연속 구간 하나, 동률이면 이른 구간)

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE active_days AS (
    SELECT DISTINCT customer_id, DATE(rental_date) AS day
    FROM rental
    WHERE customer_id <= 20
), streak AS (
    SELECT a.customer_id, a.day AS streak_start, a.day AS cur_day, 1 AS streak_days
    FROM active_days a
    WHERE NOT EXISTS (SELECT 1 FROM active_days b
                      WHERE b.customer_id = a.customer_id AND b.day = a.day - INTERVAL 1 DAY)
    UNION ALL
    SELECT s.customer_id, s.streak_start, a.day, s.streak_days + 1
    FROM streak s
    JOIN active_days a ON a.customer_id = s.customer_id
                      AND a.day = s.cur_day + INTERVAL 1 DAY
), best AS (
    SELECT customer_id, streak_start, MAX(streak_days) AS streak_days
    FROM streak
    GROUP BY customer_id, streak_start
), ranked AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY streak_days DESC, streak_start) AS rn
    FROM best
)
SELECT customer_id, streak_start, streak_days
FROM ranked
WHERE rn = 1
ORDER BY streak_days DESC, customer_id, streak_start
LIMIT 5;
```

</details>

## 해설

앵커는 **연속 구간의 시작일**(전날 대여가 없는 날)이고, 재귀는 "다음 날도 대여했으면 한 칸 늘린다" 입니다.
같은 문제를 윈도우 함수의 **갭/섬(gaps and islands)** 기법(`day - ROW_NUMBER()`)으로도 풀 수 있습니다 (ADV 유형 참고).
