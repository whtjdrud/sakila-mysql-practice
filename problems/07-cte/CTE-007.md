# CTE-007. 쉼표 문자열을 행으로 분리

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `WITH RECURSIVE` `문자열 분리` `SUBSTRING_INDEX`

## 문제

`special_features`(쉼표로 구분된 값)를 **한 행에 하나씩** 분리해, 부록 종류별 영화 수를 구하세요.

- 출력: `feature`, `films` — `films` 내림차순, `feature` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE split AS (
    SELECT film_id,
           SUBSTRING_INDEX(special_features, ',', 1) AS feature,
           IF(LOCATE(',', special_features) > 0,
              SUBSTRING(special_features, LOCATE(',', special_features) + 1), NULL) AS rest
    FROM film
    WHERE special_features IS NOT NULL AND special_features <> ''
    UNION ALL
    SELECT film_id,
           SUBSTRING_INDEX(rest, ',', 1),
           IF(LOCATE(',', rest) > 0, SUBSTRING(rest, LOCATE(',', rest) + 1), NULL)
    FROM split
    WHERE rest IS NOT NULL
)
SELECT feature, COUNT(*) AS films
FROM split
GROUP BY feature
ORDER BY films DESC, feature;
```

</details>

## 해설

"첫 토큰을 떼고 나머지(`rest`)를 다음 재귀로 넘기는" 방식으로 문자열을 분리합니다. 나머지가 없으면(NULL) 재귀가 멈춥니다.
재귀 CTE 의 컬럼 타입은 **앵커 쿼리**에서 정해지므로, 재귀 단계에서 더 긴 값이 나오면 잘릴 수 있다는 점에 주의하세요.
(MySQL 8.0.4+ 는 `JSON_TABLE` 로도 분리할 수 있습니다.)
