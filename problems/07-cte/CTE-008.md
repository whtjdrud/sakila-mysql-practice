# CTE-008. 피보나치 수열

**유형:** CTE · **난이도:** ★★☆☆☆ 초급 · **태그:** `WITH RECURSIVE` `다중 컬럼 재귀`

## 문제

재귀 CTE 로 피보나치 수열의 처음 15항을 구하세요. (1항 = 1, 2항 = 1)

- 출력: `n`, `fib` — `n` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE fib AS (
    SELECT 1 AS n, CAST(1 AS UNSIGNED) AS fib, CAST(1 AS UNSIGNED) AS next_fib
    UNION ALL
    SELECT n + 1, next_fib, fib + next_fib FROM fib WHERE n < 15
)
SELECT n, fib FROM fib ORDER BY n;
```

</details>

## 해설

재귀 단계에서 이전 행의 **여러 컬럼**을 이용할 수 있습니다. 상태(현재 값, 다음 값)를 컬럼으로 들고 다니는 것이 요령입니다.
앵커에서 `CAST(... AS UNSIGNED)` 로 타입을 넉넉히 잡지 않으면 큰 값에서 오버플로가 날 수 있습니다.
