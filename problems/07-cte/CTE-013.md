# CTE-013. 우수 고객 순위 (CTE + 윈도우)

**유형:** CTE · **난이도:** ★★★☆☆ 중급 · **태그:** `CTE` `RANK` `PARTITION BY`

## 문제

고객별 총 결제 금액을 구하고, 전체 순위와 **국가 내 순위**를 함께 출력하세요. 전체 순위 상위 10명만 출력합니다.

- 출력: `customer`(이름 성), `country`, `total_paid`, `overall_rank`, `country_rank`
- 순위는 `RANK()` — 전체 순위, 고객 이름 순

**사용 테이블:** `payment`, `customer`, `address`, `city`, `country`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH totals AS (
    SELECT c.customer_id,
           CONCAT(c.first_name, ' ', c.last_name) AS customer,
           co.country,
           SUM(p.amount) AS total_paid
    FROM payment p
    JOIN customer c ON c.customer_id = p.customer_id
    JOIN address a  ON a.address_id  = c.address_id
    JOIN city ci    ON ci.city_id    = a.city_id
    JOIN country co ON co.country_id = ci.country_id
    GROUP BY c.customer_id, customer, co.country
), ranked AS (
    SELECT customer, country, total_paid,
           RANK() OVER (ORDER BY total_paid DESC)                      AS overall_rank,
           RANK() OVER (PARTITION BY country ORDER BY total_paid DESC) AS country_rank
    FROM totals
)
SELECT *
FROM ranked
WHERE overall_rank <= 10
ORDER BY overall_rank, customer;
```

## 해설

- 윈도우 함수 결과는 같은 SELECT 의 `WHERE` 에서 쓸 수 없어 `ranked` CTE 로 감싼 뒤 거릅니다.
- 1위는 **KARL SEAL(미국, 221.55)**. **MARION SNYDER 와 RHONDA KENNEDY 가 공동 4위**이고 다음은 5가 아니라 **6위** — `RANK()` 의 특징입니다.
- 상위 10명 중 9명이 국가 내 1위인데 **ANA BRADLEY 만 국가 내 2위**입니다. 같은 미국의 KARL SEAL 때문이죠.
