# CTE-002. 다단계 CTE 파이프라인

**유형:** CTE · **난이도:** ★★☆☆☆ 초급 · **태그:** `다중 CTE` `단계별 분해`

## 문제

아래 단계를 CTE 3개로 나눠 작성하세요.

1. `film_rentals`: 영화별 대여 횟수
2. `category_stats`: 장르별 평균 대여 횟수
3. 최종: 장르별 평균 대여 횟수가 전체 장르 평균보다 높은 장르

- 출력: `category`, `avg_rentals`(소수 2자리) — `avg_rentals` 내림차순, `category` 순

**사용 테이블:** `rental`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH film_rentals AS (
    SELECT i.film_id, COUNT(*) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.film_id
), category_stats AS (
    SELECT c.name AS category, AVG(fr.rentals) AS avg_rentals
    FROM film_rentals fr
    JOIN film_category fc ON fc.film_id     = fr.film_id
    JOIN category c       ON c.category_id  = fc.category_id
    GROUP BY c.category_id, c.name
)
SELECT category, ROUND(avg_rentals, 2) AS avg_rentals
FROM category_stats
WHERE avg_rentals > (SELECT AVG(avg_rentals) FROM category_stats)
ORDER BY avg_rentals DESC, category;
```

</details>

## 해설

CTE 는 쉼표로 이어 여러 개를 정의할 수 있고, **뒤의 CTE 가 앞의 CTE 를 참조**할 수 있습니다.
복잡한 쿼리를 "데이터 파이프라인" 처럼 단계별로 읽을 수 있게 만드는 것이 CTE 의 가장 큰 장점입니다.
