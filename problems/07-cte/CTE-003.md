# CTE-003. CTE 로 다시 쓰는 서브쿼리 문제

**유형:** CTE · **난이도:** ★★★☆☆ 중급 · **태그:** `CTE` `리팩터링` `등급 평균`

## 문제

영화별 대여 횟수를 CTE 로 **한 번만** 정의해, 대여 횟수가 자기 등급 평균보다 많은 영화 수를 등급별로 구하세요.
(SUB-018 과 같은 문제를 CTE 로 다시 쓰는 연습입니다.)

- 출력: `rating`, `films`, `above_avg` — `rating` 순

**사용 테이블:** `film`, `inventory`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH film_rentals AS (
    SELECT f.film_id, f.rating, COUNT(*) AS rentals
    FROM film f
    JOIN inventory i ON i.film_id      = f.film_id
    JOIN rental r    ON r.inventory_id = i.inventory_id
    GROUP BY f.film_id, f.rating
), rating_avg AS (
    SELECT rating, AVG(rentals) AS avg_rentals
    FROM film_rentals
    GROUP BY rating
)
SELECT fr.rating, COUNT(*) AS films, SUM(fr.rentals > ra.avg_rentals) AS above_avg
FROM film_rentals fr
JOIN rating_avg ra ON ra.rating = fr.rating
GROUP BY fr.rating
ORDER BY fr.rating;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rating | films | above_avg |
|---|---|---|
| G | 171 | 77 |
| PG | 183 | 91 |
| PG-13 | 213 | 106 |
| R | 189 | 98 |
| NC-17 | 202 | 91 |
