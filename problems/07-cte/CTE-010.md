# CTE-010. 배우 연결 거리 (케빈 베이컨 게임)

**유형:** CTE · **난이도:** ★★★★★ 최고급 · **태그:** `WITH RECURSIVE` `그래프 탐색` `BFS`

## 문제

배우 `PENELOPE GUINESS`(actor_id = 1) 에서 시작해, **함께 출연한 관계**를 따라 각 배우까지의 최소 거리를 구하세요.
거리 1 = 같은 영화에 출연, 거리 2 = 출연자의 출연자. **거리 2 까지만** 탐색합니다.

- 출력: `distance`, `actors`(그 거리의 배우 수) — `distance` 순 (자기 자신 = 거리 0 포함)

**사용 테이블:** `film_actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE costar AS (
    SELECT DISTINCT a.actor_id AS src, b.actor_id AS dst
    FROM film_actor a
    JOIN film_actor b ON b.film_id = a.film_id AND b.actor_id <> a.actor_id
), bfs AS (
    SELECT 1 AS actor_id, 0 AS distance
    UNION ALL
    SELECT c.dst, b.distance + 1
    FROM bfs b
    JOIN costar c ON c.src = b.actor_id
    WHERE b.distance < 2
)
SELECT distance, COUNT(*) AS actors
FROM (
    SELECT actor_id, MIN(distance) AS distance
    FROM bfs
    GROUP BY actor_id
) t
GROUP BY distance
ORDER BY distance;
```

</details>

## 해설

재귀 CTE 로 **그래프 너비 우선 탐색**을 할 수 있습니다. 다만 MySQL 재귀 CTE 에서는 "이미 방문한 노드"를 제외할 수 없어
같은 배우가 여러 경로로 반복 등장하므로, 마지막에 `MIN(distance)` 로 최단 거리만 남겼습니다.
깊이 제한이 없으면 행 수가 기하급수적으로 늘어나니 **반드시 깊이 조건**(`distance < 2`)을 두세요.
