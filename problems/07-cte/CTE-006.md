# CTE-006. 월 목록 생성과 매출 채우기

**유형:** CTE · **난이도:** ★★★☆☆ 중급 · **태그:** `WITH RECURSIVE` `월 생성`

## 문제

2005-05 부터 2006-02 까지 **모든 달**의 매출을 구하세요. 매출이 없는 달은 0.00 입니다.

- 출력: `month`(YYYY-MM), `revenue` — `month` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE months AS (
    SELECT DATE('2005-05-01') AS m
    UNION ALL
    SELECT m + INTERVAL 1 MONTH FROM months WHERE m < '2006-02-01'
)
SELECT DATE_FORMAT(mo.m, '%Y-%m') AS month,
       COALESCE(SUM(p.amount), 0.00) AS revenue
FROM months mo
LEFT JOIN payment p ON p.payment_date >= mo.m
                   AND p.payment_date <  mo.m + INTERVAL 1 MONTH
GROUP BY mo.m
ORDER BY mo.m;
```

</details>

## 해설

LEFT JOIN 결과 매칭이 없으면 `SUM` 은 0이 아니라 **NULL** 을 돌려주므로 `COALESCE(..., 0)` 가 필요합니다.
AGG-008 결과와 비교하면 2005-09 ~ 2006-01 의 빈 구간이 명확하게 드러납니다.
