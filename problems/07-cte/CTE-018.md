# CTE-018. 날짜 × 매장 완전한 일별 리포트

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `WITH RECURSIVE` `CROSS JOIN` `빈 값 채우기`

## 문제

2005-08-15 ~ 2005-08-25 의 모든 날짜 × 모든 매장 조합에 대해 대여 건수와 매출을 구하세요. 없는 조합은 0.

- 매장은 재고(`inventory.store_id`) 기준, 매출은 그 대여에 연결된 결제 합계
- 출력: `day`, `store_id`, `rentals`, `revenue` — `day`, `store_id` 순

**사용 테이블:** `rental`, `inventory`, `payment`, `store`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE days AS (
    SELECT DATE('2005-08-15') AS day
    UNION ALL
    SELECT day + INTERVAL 1 DAY FROM days WHERE day < '2005-08-25'
), daily AS (
    SELECT DATE(r.rental_date) AS day, i.store_id,
           COUNT(DISTINCT r.rental_id) AS rentals,
           SUM(p.amount) AS revenue
    FROM rental r
    JOIN inventory i    ON i.inventory_id = r.inventory_id
    LEFT JOIN payment p ON p.rental_id    = r.rental_id
    WHERE r.rental_date >= '2005-08-15' AND r.rental_date < '2005-08-26'
    GROUP BY day, i.store_id
)
SELECT d.day, s.store_id,
       COALESCE(x.rentals, 0) AS rentals,
       COALESCE(x.revenue, 0) AS revenue
FROM days d
CROSS JOIN store s
LEFT JOIN daily x ON x.day = d.day AND x.store_id = s.store_id
ORDER BY d.day, s.store_id;
```

## 해설

"날짜 차원 × 매장 차원" 의 뼈대를 만들고 실적을 LEFT JOIN 하는 것은 **BI 리포트의 표준 구조**입니다.
8월 하순에는 대여가 없는 날이 섞여 있어, 뼈대 없이 집계하면 그 날짜들이 통째로 사라집니다.
