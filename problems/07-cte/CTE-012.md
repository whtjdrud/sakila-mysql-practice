# CTE-012. 장르별 매출 1위 배우

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `CTE` `RANK` `6단 조인`

## 문제

각 장르에서, 출연 영화들이 벌어들인 **매출 합계가 가장 큰 배우**를 구하세요.

- 출력: `category`, `actor`(이름 성), `revenue`
- 동점이면 모두 출력 (`RANK()` 사용) — 장르명, 배우 순

**사용 테이블:** `payment`, `rental`, `inventory`, `film_category`, `category`, `film_actor`, `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH actor_revenue AS (
    SELECT cat.name AS category,
           a.actor_id,
           CONCAT(a.first_name, ' ', a.last_name) AS actor,
           SUM(p.amount) AS revenue
    FROM payment p
    JOIN rental r         ON r.rental_id     = p.rental_id
    JOIN inventory i      ON i.inventory_id  = r.inventory_id
    JOIN film_category fc ON fc.film_id      = i.film_id
    JOIN category cat     ON cat.category_id = fc.category_id
    JOIN film_actor fa    ON fa.film_id      = i.film_id
    JOIN actor a          ON a.actor_id      = fa.actor_id
    GROUP BY cat.name, a.actor_id, actor
), ranked AS (
    SELECT *, RANK() OVER (PARTITION BY category ORDER BY revenue DESC) AS rnk
    FROM actor_revenue
)
SELECT category, actor, revenue
FROM ranked
WHERE rnk = 1
ORDER BY category, actor;
```

## 해설

- 6단 조인 → 집계 → `RANK() OVER (PARTITION BY ...)` → `rnk = 1`. **"그룹별 1등"** 을 구하는 정석 패턴입니다.
- ⚠️ `film_actor` 를 조인하면 결제 1건이 배우 수만큼 복제됩니다. "배우별 기여 매출"로는 맞지만, 이 값을 더해 "장르 총매출"이라 하면 몇 배로 부풀려집니다 (JOIN-019 참고).
- **Sports 의 BEN WILLIS(900.43)** 가 압도적인데, Sports 영화에만 9편 출연했기 때문입니다. "흥행작"보다 **출연 편수**의 영향이 큽니다.
- RIP CRAWFORD 는 Action·Family, GINA DEGENERES 는 Music·Sci-Fi 두 장르에서 1위입니다.
