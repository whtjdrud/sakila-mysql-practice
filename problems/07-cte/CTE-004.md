# CTE-004. 1부터 10까지 (재귀 CTE 기초)

**유형:** CTE · **난이도:** ★★☆☆☆ 초급 · **태그:** `WITH RECURSIVE` `숫자 생성`

## 문제

재귀 CTE 로 1부터 10까지의 숫자 `n` 과 그 제곱 `square` 를 생성하세요. `n` 순.

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE nums AS (
    SELECT 1 AS n
    UNION ALL
    SELECT n + 1 FROM nums WHERE n < 10
)
SELECT n, n * n AS square
FROM nums
ORDER BY n;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| n | square |
|---|---|
| 1 | 1 |
| 2 | 4 |
| 3 | 9 |
| 4 | 16 |
| 5 | 25 |
| 6 | 36 |
| 7 | 49 |
| 8 | 64 |
| 9 | 81 |
| 10 | 100 |

> 총 10행

</details>

## 해설

재귀 CTE = **시작(anchor) 쿼리** `UNION ALL` **재귀 쿼리**(자기 자신을 참조). 재귀 쿼리가 빈 결과를 낼 때 멈춥니다.
종료 조건(`WHERE n < 10`)을 빼먹으면 `cte_max_recursion_depth`(기본 1000)에 걸려 오류가 납니다.
