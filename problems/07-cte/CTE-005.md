# CTE-005. 빈 날짜 채우기

**유형:** CTE · **난이도:** ★★★☆☆ 중급 · **태그:** `WITH RECURSIVE` `날짜 생성` `LEFT JOIN`

## 문제

2005-05-24 ~ 2005-06-20 의 **모든 날짜**에 대해 대여 건수를 구하세요. 대여가 없는 날도 0으로 표시해야 합니다.

- 출력: `day`, `rentals` — `day` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE days AS (
    SELECT DATE('2005-05-24') AS day
    UNION ALL
    SELECT day + INTERVAL 1 DAY FROM days WHERE day < '2005-06-20'
)
SELECT d.day, COUNT(r.rental_id) AS rentals
FROM days d
LEFT JOIN rental r ON r.rental_date >= d.day
                  AND r.rental_date <  d.day + INTERVAL 1 DAY
GROUP BY d.day
ORDER BY d.day;
```

## 해설

`GROUP BY DATE(rental_date)` 는 대여가 **있는 날만** 결과에 나옵니다. 시계열 차트를 그리면 빈 날이 건너뛰어져 왜곡됩니다.
재귀 CTE 로 **달력(날짜 차원)** 을 만들고 LEFT JOIN 하는 것이 정석입니다. 5/31 이후 6월 중순까지 0 인 날이 많이 보일 것입니다.
