# CTE-017. CTE 를 여러 번 참조하는 자기 비교

**유형:** CTE · **난이도:** ★★★☆☆ 중급 · **태그:** `CTE 재사용` `셀프 조인`

## 문제

CTE 로 배우별 출연 편수를 정의한 뒤, **출연 편수가 정확히 같은 배우 쌍**의 수를 구하세요. (a < b)

- 출력: `pairs`

**사용 테이블:** `film_actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH ac AS (
    SELECT actor_id, COUNT(*) AS films
    FROM film_actor
    GROUP BY actor_id
)
SELECT COUNT(*) AS pairs
FROM ac a
JOIN ac b ON b.films = a.films AND b.actor_id > a.actor_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| pairs |
|---|
| 1114 |

> 총 1행

</details>

## 해설

CTE 는 같은 쿼리 안에서 **여러 별칭으로 반복 참조**할 수 있습니다. 파생 테이블이었다면 같은 서브쿼리를 두 번 써야 합니다.
검산: 출연 편수가 k 인 배우가 n_k 명이면 쌍의 수는 Σ n_k(n_k−1)/2 입니다.
