# CTE-009. 누적 매출 목표 달성일

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `WITH RECURSIVE` `누적합` `목표 달성`

## 문제

재귀 CTE 로 2005-07-01 부터 날짜별 누적 매출을 계산해, 누적 매출이 **처음으로 10,000 을 넘은 날**과 그날의 누적 매출을 구하세요.

- 출력: `day`, `cumulative`

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE daily AS (
    SELECT DATE(payment_date) AS day, SUM(amount) AS revenue
    FROM payment
    WHERE payment_date >= '2005-07-01' AND payment_date < '2005-08-01'
    GROUP BY day
), calendar AS (
    SELECT DATE('2005-07-01') AS day
    UNION ALL
    SELECT day + INTERVAL 1 DAY FROM calendar WHERE day < '2005-07-31'
), running AS (
    SELECT c.day, COALESCE(d.revenue, 0) AS cumulative
    FROM calendar c LEFT JOIN daily d ON d.day = c.day
    WHERE c.day = '2005-07-01'
    UNION ALL
    SELECT c.day, r.cumulative + COALESCE(d.revenue, 0)
    FROM running r
    JOIN calendar c   ON c.day = r.day + INTERVAL 1 DAY
    LEFT JOIN daily d ON d.day = c.day
)
SELECT day, cumulative
FROM running
WHERE cumulative > 10000
ORDER BY day
LIMIT 1;
```

</details>

<summary>실행 결과 보기</summary>

| day | cumulative |
|---|---|
| 2005-07-10 | 10430.03 |

## 해설

`WITH RECURSIVE` 아래에는 일반 CTE 와 재귀 CTE 를 섞어 쓸 수 있습니다. 재귀로 하루씩 누적하는 방식은 원리를 보여주기 위한 것이고,
실무에서는 `SUM(revenue) OVER (ORDER BY day)` 윈도우 함수가 훨씬 간단하고 빠릅니다.
재귀 쿼리에서 집계(`SUM`)나 `GROUP BY` 를 직접 쓸 수 없어서 일별 매출을 별도 CTE 로 먼저 만들었습니다.
