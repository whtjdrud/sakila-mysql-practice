# CTE-011. 재귀로 만드는 경로 문자열

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `WITH RECURSIVE` `경로` `계층`

## 문제

주소 계층(`country → city → address`)을 재귀 없이도 만들 수 있지만, 연습을 위해 **가상의 계층 테이블**을 CTE 로 만들고 재귀로 경로를 펼치세요.

```
node_id | parent_id | name
1       | NULL      | 본사
2       | 1         | 영업본부
3       | 1         | 운영본부
4       | 2         | 1번 매장
5       | 2         | 2번 매장
6       | 3         | 물류팀
7       | 6         | 재고관리파트
```

- 출력: `node_id`, `depth`(본사=0), `path`(예: `본사 > 운영본부 > 물류팀`) — `path` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH RECURSIVE org AS (
    SELECT 1 AS node_id, NULL AS parent_id, '본사' AS name
    UNION ALL SELECT 2, 1, '영업본부'
    UNION ALL SELECT 3, 1, '운영본부'
    UNION ALL SELECT 4, 2, '1번 매장'
    UNION ALL SELECT 5, 2, '2번 매장'
    UNION ALL SELECT 6, 3, '물류팀'
    UNION ALL SELECT 7, 6, '재고관리파트'
), tree AS (
    SELECT node_id, 0 AS depth, CAST(name AS CHAR(200)) AS path
    FROM org WHERE parent_id IS NULL
    UNION ALL
    SELECT o.node_id, t.depth + 1, CONCAT(t.path, ' > ', o.name)
    FROM tree t
    JOIN org o ON o.parent_id = t.node_id
)
SELECT node_id, depth, path
FROM tree
ORDER BY path;
```

</details>

## 해설

조직도·카테고리 트리·댓글 스레드처럼 **자기 참조(parent_id)** 테이블을 펼치는 것이 재귀 CTE 의 대표 용도입니다.
앵커에서 `CAST(name AS CHAR(200))` 로 길이를 넉넉히 잡지 않으면 경로가 앵커 값 길이(`본사` = 2글자)에 맞춰 **잘립니다.**
