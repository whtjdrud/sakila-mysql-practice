# CTE-014. 고객 생애 지표 요약

**유형:** CTE · **난이도:** ★★★★☆ 고급 · **태그:** `다중 CTE` `고객 360`

## 문제

고객 1~10번에 대해 CTE 를 조합해 한 행짜리 고객 요약을 만드세요.

- `rentals`: 대여 횟수, `total_paid`: 결제 합계
- `fav_category`: 가장 많이 빌린 장르 (동점이면 이름순 첫 번째)
- `avg_gap_days`: 대여 간 평균 간격(일, 소수 1자리) = (마지막 − 첫 대여 일수) / (대여 횟수 − 1)

출력: `customer_id`, `rentals`, `total_paid`, `fav_category`, `avg_gap_days` — `customer_id` 순

**사용 테이블:** `rental`, `payment`, `inventory`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
WITH r AS (
    SELECT customer_id, COUNT(*) AS rentals,
           DATEDIFF(MAX(rental_date), MIN(rental_date)) AS span_days
    FROM rental
    WHERE customer_id <= 10
    GROUP BY customer_id
), p AS (
    SELECT customer_id, SUM(amount) AS total_paid
    FROM payment
    WHERE customer_id <= 10
    GROUP BY customer_id
), cat AS (
    SELECT rt.customer_id, c.name, COUNT(*) AS cnt
    FROM rental rt
    JOIN inventory i      ON i.inventory_id = rt.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    JOIN category c       ON c.category_id  = fc.category_id
    WHERE rt.customer_id <= 10
    GROUP BY rt.customer_id, c.name
), fav AS (
    SELECT customer_id, name AS fav_category
    FROM (SELECT customer_id, name,
                 ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY cnt DESC, name) AS rn
          FROM cat) x
    WHERE rn = 1
)
SELECT r.customer_id, r.rentals, p.total_paid, fav.fav_category,
       ROUND(r.span_days / NULLIF(r.rentals - 1, 0), 1) AS avg_gap_days
FROM r
JOIN p   ON p.customer_id   = r.customer_id
JOIN fav ON fav.customer_id = r.customer_id
ORDER BY r.customer_id;
```

## 해설

서로 다른 테이블의 집계를 한 번에 조인하면 팬아웃으로 값이 부풀려집니다. **각각 CTE 로 고객 단위까지 집계한 뒤** 조인하면 안전합니다.
이렇게 "1고객 1행" 으로 만든 요약 테이블은 대시보드·머신러닝 피처의 기본 형태입니다.
