# FN-006. 자릿수 맞추기

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `LPAD` `CAST`

## 문제

`film_id` 를 6자리 코드로 만들어 `F000001` 형식의 `film_code` 를 만드세요.
`film_id` 1~5, 998~1000 번 영화의 `film_id`, `film_code`, `title` 을 `film_id` 순으로 조회하세요.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id,
       CONCAT('F', LPAD(film_id, 6, '0')) AS film_code,
       title
FROM film
WHERE film_id <= 5 OR film_id >= 998
ORDER BY film_id;
```

</details>

<summary>실행 결과 보기</summary>

</details>

## 해설

`LPAD(값, 길이, 채울문자)` 은 왼쪽을 채웁니다. 숫자는 자동으로 문자열로 변환됩니다.
주의: 원래 값이 길이보다 길면 **잘립니다.** `LPAD(1234567, 6, '0')` → `'123456'`
