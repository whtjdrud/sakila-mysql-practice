# FN-015. 0으로 나누기 방지

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `NULLIF` `나눗셈`

## 문제

각 매장(`store_id`)별로 `active = 0` 고객 수 대비 `active = 1` 고객 수의 배율 `ratio`(소수 2자리)를 구하세요.
비활성 고객이 0명일 경우 오류 대신 NULL 이 나와야 합니다.

- 출력: `store_id`, `active_cnt`, `inactive_cnt`, `ratio` — `store_id` 순

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT store_id,
       SUM(active = 1) AS active_cnt,
       SUM(active = 0) AS inactive_cnt,
       ROUND(SUM(active = 1) / NULLIF(SUM(active = 0), 0), 2) AS ratio
FROM customer
GROUP BY store_id
ORDER BY store_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| store_id | active_cnt | inactive_cnt | ratio |
|---|---|---|---|
| 1 | 318 | 8 | 39.75 |
| 2 | 266 | 7 | 38.00 |

> 총 2행

</details>

## 해설

`NULLIF(a, b)` 는 a = b 이면 NULL, 아니면 a 를 돌려줍니다. 분모에 `NULLIF(x, 0)` 을 씌우는 것은 0 나눗셈 방지의 관용구입니다.
(MySQL 은 기본 설정에서 0으로 나누면 NULL 을 주지만, 엄격 모드나 다른 DBMS 에서는 오류가 납니다.)
