# FN-010. 요일별 대여 건수

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DAYNAME` `DAYOFWEEK` `GROUP BY`

## 문제

요일별 대여 건수를 구하세요. 출력: `dow`(1=일요일 … 7=토요일), `day_name`, `rentals`. `dow` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT DAYOFWEEK(rental_date) AS dow,
       DAYNAME(rental_date)   AS day_name,
       COUNT(*)               AS rentals
FROM rental
GROUP BY dow, day_name
ORDER BY dow;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| dow | day_name | rentals |
|---|---|---|
| 1 | Sunday | 2320 |
| 2 | Monday | 2247 |
| 3 | Tuesday | 2463 |
| 4 | Wednesday | 2231 |
| 5 | Thursday | 2200 |
| 6 | Friday | 2272 |
| 7 | Saturday | 2311 |

> 총 7행

</details>

## 해설

`DAYOFWEEK` 는 일요일=1, `WEEKDAY` 는 월요일=0 입니다. 요일 **이름**으로 정렬하면 알파벳 순(Friday, Monday…)이 되므로 숫자로 정렬하세요.
