# FN-009. 날짜 형식 바꾸기

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `DATE_FORMAT`

## 문제

`rental_id` 1~5번 대여의 `rental_id` 와 대여일을 `2005년 05월 24일 (Tue) 22:53` 형식으로 바꾼 `rented_at` 을 조회하세요.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id,
       DATE_FORMAT(rental_date, '%Y년 %m월 %d일 (%a) %H:%i') AS rented_at
FROM rental
WHERE rental_id <= 5
ORDER BY rental_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rental_id | rented_at |
|---|---|
| 1 | 2005년 05월 24일 (Tue) 22:53 |
| 2 | 2005년 05월 24일 (Tue) 22:54 |
| 3 | 2005년 05월 24일 (Tue) 23:03 |
| 4 | 2005년 05월 24일 (Tue) 23:04 |
| 5 | 2005년 05월 24일 (Tue) 23:05 |

> 총 5행

</details>

## 해설

자주 쓰는 지정자: `%Y` 4자리 연도, `%m` 2자리 월, `%d` 일, `%H` 24시, `%i` **분**(`%m` 이 아님!), `%s` 초, `%a` 요일 약어, `%W` 요일 전체.
