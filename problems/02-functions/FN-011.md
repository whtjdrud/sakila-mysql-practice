# FN-011. 대여 기간 계산

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DATEDIFF` `TIMESTAMPDIFF`

## 문제

반납된 대여 중 `rental_id` 1~10번에 대해 `rental_id`, 대여~반납 사이의 일수 `days`(날짜 차이), 시간 `hours` 를 구하세요.
`rental_id` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id,
       DATEDIFF(return_date, rental_date)              AS days,
       TIMESTAMPDIFF(HOUR, rental_date, return_date)  AS hours
FROM rental
WHERE rental_id <= 10
  AND return_date IS NOT NULL
ORDER BY rental_id;
```

</details>

## 해설

`DATEDIFF` 는 **시간을 버리고 날짜만** 비교합니다. 23:59 에 빌려 다음날 00:01 에 반납해도 1일입니다.
`TIMESTAMPDIFF(단위, 시작, 끝)` 는 인자 순서가 DATEDIFF 와 **반대**(시작이 먼저)라는 점에 주의하세요.
