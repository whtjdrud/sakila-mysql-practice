# FN-023. 형 변환과 비교 함정

**유형:** 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `CAST` `암묵적 형 변환`

## 문제

`postal_code` 는 문자열(VARCHAR) 컬럼입니다. 우편번호를 **숫자로 변환했을 때** 90000 이상 90999 이하인 주소의
`address_id`, `postal_code`, `district` 를 조회하세요. `address_id` 순.

**사용 테이블:** `address`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT address_id, postal_code, district
FROM address
WHERE CAST(postal_code AS UNSIGNED) BETWEEN 90000 AND 90999
ORDER BY address_id;
```

</details>

<summary>실행 결과 보기</summary>

| address_id | postal_code | district |
|---|---|---|
| 150 | 90732 | Michigan |

| 238 | 90628 | Hawalli |
| 440 | 90920 | Shandong |
| 508 | 90797 | Nagano |

> 총 5행

</details>

## 해설

문자열끼리 비교하면 사전 순이라 `'9' > '10000'` 이 됩니다. 숫자 범위로 비교하려면 명시적으로 `CAST` 하세요.
`WHERE postal_code = 90000` 처럼 문자열 컬럼과 숫자를 비교하면 MySQL 이 **모든 행을 숫자로 변환**하므로 인덱스를 쓰지 못합니다.
