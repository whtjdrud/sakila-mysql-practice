# FN-012. 반납 예정일 계산

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DATE_ADD` `INTERVAL`

## 문제

대여 1~5번에 대해 영화의 대여 기간(`film.rental_duration` 일)을 더한 반납 예정일 `due_date` 를 구하세요.
출력: `rental_id`, `rental_date`, `rental_duration`, `due_date` (`rental_id` 순)

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT r.rental_id, r.rental_date, f.rental_duration,
       DATE_ADD(r.rental_date, INTERVAL f.rental_duration DAY) AS due_date
FROM rental r
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id      = i.film_id
WHERE r.rental_id <= 5
ORDER BY r.rental_id;
```

</details>

## 해설

`INTERVAL` 뒤에는 컬럼도 올 수 있습니다. `rental_date + INTERVAL 3 DAY` 처럼 연산자 형태로도 쓸 수 있습니다.
