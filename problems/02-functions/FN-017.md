# FN-017. 시간대별 결제

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `HOUR` `GROUP BY`

## 문제

결제 시각의 **시(hour)** 별 결제 건수와 합계를 구하세요.

- 출력: `hour`, `payments`, `total`(합계) — `hour` 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT HOUR(payment_date) AS hour,
       COUNT(*)           AS payments,
       SUM(amount)        AS total
FROM payment
GROUP BY hour
ORDER BY hour;
```

## 해설

`HOUR`, `MINUTE`, `SECOND`, `YEAR`, `MONTH`, `DAY` 처럼 날짜의 일부를 뽑는 함수는 `EXTRACT(HOUR FROM payment_date)` 표준 문법으로도 쓸 수 있습니다.
