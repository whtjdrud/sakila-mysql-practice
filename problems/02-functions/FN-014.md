# FN-014. NULL 을 기본값으로

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `IFNULL` `COALESCE`

## 문제

고객 1~20번이 **2006년에** 대여한 기록을 조회하되, 반납일이 NULL 이면 `'미반납'` 으로 표시하세요.

- 출력: `rental_id`, `customer_id`, `returned`(반납일 문자열 또는 '미반납') — `rental_id` 순

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, customer_id,
       COALESCE(CAST(return_date AS CHAR), '미반납') AS returned
FROM rental
WHERE customer_id BETWEEN 1 AND 20
  AND rental_date >= '2006-01-01'
ORDER BY rental_id;
```

</details>

## 해설

`IFNULL(a, b)` 는 인자 2개, `COALESCE(a, b, c, ...)` 는 **처음으로 NULL 이 아닌 값**을 돌려주며 표준 SQL 입니다.
날짜와 문자열을 섞으면 타입이 암묵 변환되므로 `CAST(... AS CHAR)` 로 명시하는 편이 안전합니다.
