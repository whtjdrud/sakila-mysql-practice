# FN-001. 이름 합치기

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `CONCAT`

## 문제

배우의 이름과 성을 공백으로 이어 `full_name` 으로 만들고, `actor_id` 1~10번 배우의 `actor_id`, `full_name` 을 조회하세요.
`actor_id` 순.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT actor_id, CONCAT(first_name, ' ', last_name) AS full_name
FROM actor
WHERE actor_id BETWEEN 1 AND 10
ORDER BY actor_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

</details>

## 해설

`CONCAT` 은 인자 중 하나라도 NULL 이면 **전체 결과가 NULL** 이 됩니다.
NULL 을 건너뛰고 싶다면 `CONCAT_WS(' ', first_name, last_name)` 을 사용하세요. (구분자를 첫 인자로 받고 NULL 은 무시)
