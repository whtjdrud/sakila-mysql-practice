# FN-003. 가장 긴 영화 제목

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `CHAR_LENGTH` `LENGTH`

## 문제

제목 글자 수가 가장 긴 영화 5편의 `title`, `title_len` 을 조회하세요. 글자 수 내림차순, 같으면 `title` 순.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, CHAR_LENGTH(title) AS title_len
FROM film
ORDER BY title_len DESC, title
LIMIT 5;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| title | title_len |
|---|---|
| ARACHNOPHOBIA ROLLERCOASTER | 27 |
| SATISFACTION CONFIDENTIAL | 25 |
| DESPERATE TRAINSPOTTING | 23 |
| ENTRAPMENT SATISFACTION | 23 |
| EXTRAORDINARY CONQUERER | 23 |

> 총 5행

</details>

## 해설

`CHAR_LENGTH` 는 **문자 수**, `LENGTH` 는 **바이트 수**입니다. 영문은 같지만 한글(utf8mb4 에서 3바이트)은 다릅니다.
`SELECT LENGTH('가'), CHAR_LENGTH('가')` → `3, 1`
