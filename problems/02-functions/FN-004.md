# FN-004. 이메일 도메인 추출

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `SUBSTRING_INDEX`

## 문제

고객 이메일에서 `@` 앞부분(아이디)과 뒷부분(도메인)을 분리해 `customer_id` 1~5번의
`customer_id`, `email`, `user_part`, `domain` 을 조회하세요. `customer_id` 순.

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, email,
       SUBSTRING_INDEX(email, '@', 1)  AS user_part,
       SUBSTRING_INDEX(email, '@', -1) AS domain
FROM customer
WHERE customer_id <= 5
ORDER BY customer_id;
```

</details>

## 해설

`SUBSTRING_INDEX(s, 구분자, n)` 은 n 이 양수면 **앞에서 n번째 구분자 이전**, 음수면 **뒤에서 n번째 구분자 이후**를 돌려줍니다.
`LOCATE('@', email)` 로 위치를 찾아 `SUBSTRING` 으로 자르는 방법보다 간결합니다.
