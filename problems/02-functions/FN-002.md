# FN-002. 대소문자 변환과 이니셜

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `LOWER` `UPPER` `LEFT`

## 문제

고객 `customer_id` 1~5번에 대해 `customer_id`, 이름을 소문자로 바꾼 `first_lower`,
이니셜(`이름첫글자.성첫글자.` 예: `M.S.`)인 `initials` 를 조회하세요. `customer_id` 순.

**사용 테이블:** `customer`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id,
       LOWER(first_name) AS first_lower,
       CONCAT(LEFT(first_name, 1), '.', LEFT(last_name, 1), '.') AS initials
FROM customer
WHERE customer_id <= 5
ORDER BY customer_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| customer_id | first_lower | initials |
|---|---|---|
| 1 | mary | M.S. |
| 2 | patricia | P.J. |
| 3 | linda | L.W. |
| 4 | barbara | B.J. |
| 5 | elizabeth | E.B. |

> 총 5행

</details>

## 해설

`LEFT(s, n)` 은 앞에서 n글자, `RIGHT(s, n)` 은 뒤에서 n글자를 잘라냅니다. `SUBSTRING(s, 1, n)` 과 같습니다.
