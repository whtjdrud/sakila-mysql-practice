# FN-005. 문자열 치환과 위치 찾기

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `REPLACE` `LOCATE`

## 문제

영화 설명(`description`)에서 단어 `Drama` 를 `**DRAMA**` 로 치환한 `new_desc` 와,
`Drama` 의 시작 위치 `pos` 를 구하세요.
`Drama` 가 포함된 영화 중 `film_id` 가 작은 5편만, `film_id`, `pos`, `new_desc` 를 조회하세요.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id,
       LOCATE('Drama', description) AS pos,
       REPLACE(description, 'Drama', '**DRAMA**') AS new_desc
FROM film
WHERE description LIKE '%Drama%'
ORDER BY film_id
LIMIT 5;
```

</details>

## 해설

`LOCATE(찾을것, 문자열)` 은 1부터 시작하는 위치를 돌려주고, 없으면 0 입니다. (`INSTR(문자열, 찾을것)` 은 인자 순서가 반대)
`REPLACE` 는 **모든** 일치 항목을 바꾸고, 대소문자를 구분합니다.
