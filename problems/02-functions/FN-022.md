# FN-022. 제목 단어 수 세기

**유형:** 함수 · **난이도:** ★★★☆☆ 중급 · **태그:** `CHAR_LENGTH` `REPLACE` `문자열 트릭`

## 문제

영화 제목의 단어 수(공백으로 구분)를 구하고, 단어 수별 영화 편수를 집계하세요.

- 출력: `word_count`, `films` — `word_count` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT CHAR_LENGTH(title) - CHAR_LENGTH(REPLACE(title, ' ', '')) + 1 AS word_count,
       COUNT(*) AS films
FROM film
GROUP BY word_count
ORDER BY word_count;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| word_count | films |
|---|---|
| 2 | 1000 |

> 총 1행

</details>

## 해설

"전체 길이 − 공백을 지운 길이 = 공백 개수" 라는 고전적인 트릭입니다. 단어 수는 공백 수 + 1 입니다.
결과는 단 1행 — Sakila 의 영화 제목 1,000개는 **전부 정확히 두 단어**입니다. 샘플 데이터가 "형용사/명사 + 명사" 규칙으로 자동 생성되었기 때문입니다.
