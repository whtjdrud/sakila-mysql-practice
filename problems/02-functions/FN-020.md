# FN-020. 고객 가입 후 경과 일수

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DATEDIFF` `기준일`

## 문제

분석 기준일을 데이터의 마지막 대여일인 `'2006-02-14'` 로 할 때,
고객 1~5번의 `customer_id`, `create_date`, 기준일까지 경과 일수 `days_since_join`,
마지막 대여일로부터 기준일까지 경과 일수 `days_since_last_rental` 을 구하세요. `customer_id` 순.

**사용 테이블:** `customer`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id, c.create_date,
       DATEDIFF('2006-02-14', c.create_date) AS days_since_join,
       DATEDIFF('2006-02-14', MAX(r.rental_date)) AS days_since_last_rental
FROM customer c
JOIN rental r ON r.customer_id = c.customer_id
WHERE c.customer_id <= 5
GROUP BY c.customer_id, c.create_date
ORDER BY c.customer_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| customer_id | create_date | days_since_join | days_since_last_rental |
|---|---|---|---|
| 1 | 2006-02-14 22:04:36 | 0 | 176 |
| 2 | 2006-02-14 22:04:36 | 0 | 175 |
| 3 | 2006-02-14 22:04:36 | 0 | 175 |
| 4 | 2006-02-14 22:04:36 | 0 | 175 |
| 5 | 2006-02-14 22:04:36 | 0 | 0 |

> 총 5행

</details>

## 해설

Sakila 는 모든 고객의 가입일(`create_date`)이 **2006-02-14 22:04** 로 같고, 대여는 그보다 앞선 2005-05 부터 있습니다.
그래서 `days_since_join` 이 모두 0 입니다 — "가입 전에 대여했다"는 비현실적인 샘플 데이터라는 뜻이죠.
실무에서도 이런 이상값을 발견하면 컬럼의 의미(가입일인지, 데이터 이관일인지)부터 확인해야 합니다.
또한 `NOW()` 대신 **고정 기준일**을 쓰면 언제 실행해도 같은 결과를 얻습니다.
