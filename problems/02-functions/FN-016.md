# FN-016. 여러 값 중 최댓값

**유형:** 함수 · **난이도:** ★★☆☆☆ 초급 · **태그:** `GREATEST` `LEAST`

## 문제

`film_id` 1~10번 영화에 대해 `rental_rate * rental_duration`(기간 전체 대여료)과 `replacement_cost / 5` 중
**큰 값**을 `price_floor` 로, **작은 값**을 `price_cap` 으로 구하세요 (둘 다 소수 2자리).

- 출력: `film_id`, `price_floor`, `price_cap` — `film_id` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id,
       ROUND(GREATEST(rental_rate * rental_duration, replacement_cost / 5), 2) AS price_floor,
       ROUND(LEAST(rental_rate * rental_duration, replacement_cost / 5), 2)    AS price_cap
FROM film
WHERE film_id <= 10
ORDER BY film_id;
```

## 해설

`MAX` 는 **여러 행** 중 최댓값(집계), `GREATEST` 는 **한 행 안의 여러 값** 중 최댓값입니다.
인자 중 하나라도 NULL 이면 `GREATEST` 결과도 NULL 이 된다는 점에 주의하세요.
