# FN-008. 홀짝 구분

**유형:** 함수 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `MOD` `%`

## 문제

`actor_id` 가 7의 배수인 배우의 `actor_id`, `first_name`, `last_name` 을 `actor_id` 순으로 조회하세요.

**사용 테이블:** `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT actor_id, first_name, last_name
FROM actor
WHERE MOD(actor_id, 7) = 0
ORDER BY actor_id;
```

## 해설

`MOD(a, b)`, `a % b`, `a MOD b` 모두 같은 나머지 연산입니다. 데이터를 N개 그룹으로 나눌 때(샘플링, 샤딩)도 자주 씁니다.
