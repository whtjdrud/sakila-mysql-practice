# SUB-010. 장르별 가장 긴 영화

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `상관 서브쿼리` `그룹별 최댓값`

## 문제

장르별로 상영 시간이 가장 긴 영화(동점이면 모두)를 구하세요.

- 출력: `category`, `title`, `length` — `category`, `title` 순

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category, f.title, f.length
FROM film f
JOIN film_category fc ON fc.film_id    = f.film_id
JOIN category c       ON c.category_id = fc.category_id
WHERE f.length = (
    SELECT MAX(f2.length)
    FROM film f2
    JOIN film_category fc2 ON fc2.film_id = f2.film_id
    WHERE fc2.category_id = fc.category_id
)
ORDER BY category, f.title;
```

</details>

## 해설

"그룹별 최댓값을 가진 **행 전체**"를 구하는 고전 문제(greatest-n-per-group)입니다.
`GROUP BY` 만으로는 MAX 값은 구해도 그 행의 다른 컬럼(title)을 정확히 가져올 수 없습니다.
