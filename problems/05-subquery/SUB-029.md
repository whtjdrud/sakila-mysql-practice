# SUB-029. 자기보다 비싼 영화의 수

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `상관 서브쿼리` `순위 직접 계산`

## 문제

윈도우 함수 없이, `film_id` 1~10번 영화마다 **자기보다 대여료가 높은 영화의 수**를 구하고 그 값 + 1 을 순위 `rate_rank` 로 표시하세요.

- 출력: `film_id`, `title`, `rental_rate`, `rate_rank` — `film_id` 순

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT f.film_id, f.title, f.rental_rate,
       (SELECT COUNT(*) FROM film f2 WHERE f2.rental_rate > f.rental_rate) + 1 AS rate_rank
FROM film f
WHERE f.film_id <= 10
ORDER BY f.film_id;
```

</details>

## 해설

"나보다 큰 값의 개수 + 1" 은 `RANK()` 와 같은 결과입니다. 윈도우 함수가 없던 시절의 순위 계산법이며, 원리를 이해하는 데 좋습니다.
전체 행에 대해 계산하면 O(n²) 이라 느리므로 실무에서는 윈도우 함수를 사용하세요.
