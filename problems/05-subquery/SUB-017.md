# SUB-017. 파생 테이블로 단계 나누기

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `파생 테이블` `FROM 절 서브쿼리`

## 문제

고객별 결제 합계를 파생 테이블로 구한 뒤, 합계 구간별 고객 수를 구하세요.

- 구간: `VIP`(150 이상), `일반`(100 이상), `저활동`(100 미만)
- 출력: `segment`, `customers` — VIP → 일반 → 저활동 순

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT segment, COUNT(*) AS customers
FROM (
    SELECT customer_id,
           CASE WHEN SUM(amount) >= 150 THEN 'VIP'
                WHEN SUM(amount) >= 100 THEN '일반'
                ELSE '저활동' END AS segment
    FROM payment
    GROUP BY customer_id
) t
GROUP BY segment
ORDER BY FIELD(segment, 'VIP', '일반', '저활동');
```

</details>

<details>
<summary>실행 결과 보기</summary>

| segment | customers |
|---|---|
| VIP | 46 |
| 일반 | 349 |
| 저활동 | 204 |

> 총 3행

</details>

## 해설

`FIELD(값, 'a', 'b', 'c')` 는 값의 위치(1, 2, 3)를 돌려주므로 **임의의 정렬 순서**를 지정할 때 유용합니다 (MySQL 전용).
