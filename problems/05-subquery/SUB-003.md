# SUB-003. 특정 배우의 출연작

**유형:** 서브쿼리 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `IN 서브쿼리`

## 문제

배우 `PENELOPE GUINESS` 가 출연한 영화의 `title` 을 `title` 순으로 조회하세요. 조인 대신 `IN` 서브쿼리를 사용하세요.

**사용 테이블:** `film`, `film_actor`, `actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title
FROM film
WHERE film_id IN (
    SELECT fa.film_id
    FROM film_actor fa
    JOIN actor a ON a.actor_id = fa.actor_id
    WHERE a.first_name = 'PENELOPE' AND a.last_name = 'GUINESS'
)
ORDER BY title;
```

</details>

## 해설

`IN (서브쿼리)` 는 **여러 행 1열**을 돌려주는 서브쿼리와 함께 씁니다.
조인과 달리 서브쿼리 쪽에 중복이 있어도 바깥 행이 **중복되지 않는다**는 장점이 있습니다 (세미 조인).
