# SUB-014. 모든 장르를 빌려 본 고객 (관계 나눗셈)

**유형:** 서브쿼리 · **난이도:** ★★★★★ 최고급 · **태그:** `NOT EXISTS 이중 부정` `관계 나눗셈`

## 문제

**16개 장르를 모두** 한 번 이상 빌려 본 고객의 `customer_id`, `first_name`, `last_name` 을 `customer_id` 순으로 조회하세요.
`NOT EXISTS` 를 이중으로 사용하세요.

**사용 테이블:** `customer`, `category`, `rental`, `inventory`, `film_category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id, c.first_name, c.last_name
FROM customer c
WHERE NOT EXISTS (
    SELECT 1
    FROM category cat
    WHERE NOT EXISTS (
        SELECT 1
        FROM rental r
        JOIN inventory i      ON i.inventory_id = r.inventory_id
        JOIN film_category fc ON fc.film_id     = i.film_id
        WHERE r.customer_id    = c.customer_id
          AND fc.category_id   = cat.category_id
    )
)
ORDER BY c.customer_id;
```

</details>

## 해설

"모든 장르를 빌렸다" = "**빌리지 않은 장르가 존재하지 않는다**". 이중 부정이 관계 나눗셈의 정석 표현입니다.
같은 답을 `GROUP BY c.customer_id HAVING COUNT(DISTINCT fc.category_id) = (SELECT COUNT(*) FROM category)` 로도 구해 보고 비교해 보세요.
