# SUB-020. 고객별 첫 대여 영화

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `파생 테이블 조인` `그룹별 첫 행`

## 문제

고객 1~10번 각각의 **첫 대여**의 `customer_id`, `rental_date`, `title` 을 구하세요. `customer_id` 순.

**사용 테이블:** `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT r.customer_id, r.rental_date, f.title
FROM rental r
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id      = i.film_id
JOIN (
    SELECT customer_id, MIN(rental_date) AS first_date
    FROM rental
    WHERE customer_id <= 10
    GROUP BY customer_id
) m ON m.customer_id = r.customer_id
   AND m.first_date  = r.rental_date
ORDER BY r.customer_id, f.title;
```

</details>

## 해설

"그룹별 최솟값" 을 파생 테이블로 구하고 `(그룹키, 값)` 쌍으로 원래 테이블과 조인합니다.
`WHERE (customer_id, rental_date) IN (SELECT customer_id, MIN(rental_date) ... GROUP BY ...)` 로도 쓸 수 있지만,
MySQL 8.0 에서는 이 형태가 **10초 넘게** 걸립니다(행 생성자 IN 최적화 한계). 같은 의미라도 조인 형태가 훨씬 빠릅니다.
같은 시각에 두 건을 빌렸다면 두 행이 나올 수 있습니다 — 정확히 1행이 필요하면 `ROW_NUMBER()` 를 사용하세요.
