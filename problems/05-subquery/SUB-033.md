# SUB-033. 대여 이력이 유사한 고객

**유형:** 서브쿼리 · **난이도:** ★★★★★ 최고급 · **태그:** `자카드 유사도` `파생 테이블` `셀프 조인`

## 문제

고객 1번과 **빌린 영화가 가장 많이 겹치는** 고객 5명을 찾고, 자카드 유사도(교집합 / 합집합)를 구하세요.

- 출력: `customer_id`, `common_films`, `jaccard`(소수 3자리)
- `common_films` 내림차순, `customer_id` 순

**사용 테이블:** `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT o.customer_id,
       COUNT(*) AS common_films,
       ROUND(COUNT(*) / (
           (SELECT COUNT(DISTINCT i.film_id) FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
             WHERE r.customer_id = 1)
         + (SELECT COUNT(DISTINCT i.film_id) FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
             WHERE r.customer_id = o.customer_id)
         - COUNT(*)
       ), 3) AS jaccard
FROM (
    SELECT DISTINCT i.film_id
    FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
    WHERE r.customer_id = 1
) me
JOIN (
    SELECT DISTINCT r.customer_id, i.film_id
    FROM rental r JOIN inventory i ON i.inventory_id = r.inventory_id
    WHERE r.customer_id <> 1
) o ON o.film_id = me.film_id
GROUP BY o.customer_id
ORDER BY common_films DESC, o.customer_id
LIMIT 5;
```

## 해설

협업 필터링 추천의 첫 단계인 **사용자 유사도**를 SQL 로 계산했습니다.
|A∩B| 는 조인 후 COUNT, |A∪B| = |A| + |B| − |A∩B| 입니다. 집합 크기는 상관 스칼라 서브쿼리로 구했습니다.
