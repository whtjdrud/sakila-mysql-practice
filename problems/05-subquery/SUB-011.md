# SUB-011. EXISTS 로 존재 여부 확인

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `EXISTS` `세미 조인`

## 문제

**2006년에 대여 기록이 있는** 고객의 `customer_id`, `first_name`, `last_name` 을 `customer_id` 순으로 조회하세요.

**사용 테이블:** `customer`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id, c.first_name, c.last_name
FROM customer c
WHERE EXISTS (
    SELECT 1 FROM rental r
    WHERE r.customer_id = c.customer_id
      AND r.rental_date >= '2006-01-01'
)
ORDER BY c.customer_id;
```

</details>

## 해설

`EXISTS` 는 서브쿼리가 **한 행이라도 돌려주면 참**입니다. 무엇을 SELECT 하는지는 상관없어서 관례적으로 `SELECT 1` 을 씁니다.
조인 + DISTINCT 보다 의도가 명확하고, 첫 행을 찾으면 바로 멈출 수 있어 효율적입니다.
