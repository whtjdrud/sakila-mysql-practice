# SUB-019. 행 서브쿼리

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `행 서브쿼리` `튜플 비교`

## 문제

가장 최근 대여(`rental_date` 최댓값)와 **같은 고객, 같은 날짜**에 이뤄진 모든 대여의 `rental_id`, `customer_id`, `rental_date` 를 조회하세요.
`(customer_id, DATE(rental_date))` 쌍을 행 서브쿼리로 비교하세요. `rental_id` 순.

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rental_id, customer_id, rental_date
FROM rental
WHERE (customer_id, DATE(rental_date)) = (
    SELECT customer_id, DATE(rental_date)
    FROM rental
    ORDER BY rental_date DESC, rental_id DESC
    LIMIT 1
)
ORDER BY rental_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rental_id | customer_id | rental_date |
|---|---|---|
| 15966 | 374 | 2006-02-14 15:16:03 |

> 총 1행

</details>

## 해설

`(a, b) = (SELECT x, y ...)` 처럼 **여러 컬럼을 한 번에 비교**할 수 있습니다. `(a, b) IN (SELECT x, y ...)` 도 가능합니다.
(MySQL 은 `IN` 서브쿼리 안에서 `LIMIT` 을 지원하지 않지만, `=` 비교의 스칼라/행 서브쿼리에서는 지원합니다.)
