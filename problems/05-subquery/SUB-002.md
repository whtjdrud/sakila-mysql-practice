# SUB-002. 가장 비싼 영화

**유형:** 서브쿼리 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `스칼라 서브쿼리` `MAX`

## 문제

교체 비용(`replacement_cost`)이 **최댓값**인 영화의 `title`, `replacement_cost` 를 `title` 순으로 조회하세요.

**사용 테이블:** `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT title, replacement_cost
FROM film
WHERE replacement_cost = (SELECT MAX(replacement_cost) FROM film)
ORDER BY title;
```

</details>

## 해설

`ORDER BY replacement_cost DESC LIMIT 1` 은 **동점인 영화 중 하나만** 돌려줍니다. 최댓값과 같은 모든 행이 필요하면 서브쿼리 방식이 정확합니다.
