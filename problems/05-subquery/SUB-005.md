# SUB-005. 한 번도 대여하지 않은 고객

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `NOT IN` `NOT EXISTS`

## 문제

한 번도 대여하지 않은 고객의 수를 구하세요.

- 출력: `customers`

**사용 테이블:** `customer`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT COUNT(*) AS customers
FROM customer c
WHERE NOT EXISTS (SELECT 1 FROM rental r WHERE r.customer_id = c.customer_id);
```

</details>

<details>
<summary>실행 결과 보기</summary>

| customers |
|---|
| 0 |

> 총 1행

</details>

## 해설

결과는 0명입니다. 모든 고객이 최소 1회는 대여했습니다 — "0" 도 검증된 답입니다.
`NOT IN (SELECT customer_id FROM rental)` 로도 같은 답이 나오지만, 서브쿼리 결과에 NULL 이 하나라도 섞이면 **결과가 항상 0행**이 되는 함정이 있습니다(SUB-006 참고).
