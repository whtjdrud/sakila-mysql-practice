# SUB-008. 고객별 최근 대여일 (상관 서브쿼리)

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `상관 서브쿼리` `SELECT 절`

## 문제

고객 1~10번의 `customer_id`, 이름 `name`, 가장 최근 대여일 `last_rental` 을 SELECT 절 상관 서브쿼리로 구하세요. `customer_id` 순.

**사용 테이블:** `customer`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id,
       CONCAT(c.first_name, ' ', c.last_name) AS name,
       (SELECT MAX(r.rental_date) FROM rental r WHERE r.customer_id = c.customer_id) AS last_rental
FROM customer c
WHERE c.customer_id <= 10
ORDER BY c.customer_id;
```

## 해설

서브쿼리 안에서 바깥 테이블(`c.customer_id`)을 참조하면 **상관 서브쿼리**입니다. 개념적으로 바깥 행마다 한 번씩 실행됩니다.
값 하나만 필요할 때는 GROUP BY 조인보다 읽기 쉽지만, 여러 값(MAX, COUNT, SUM …)이 필요하면 서브쿼리가 여러 번 돌아 비효율적입니다.
