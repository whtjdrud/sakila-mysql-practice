# SUB-018. 파생 테이블과 조인

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `파생 테이블` `집계 후 조인`

## 문제

영화별 대여 횟수를 파생 테이블로 구한 뒤 `film` 과 조인해, 대여 횟수가 **자기 등급 평균보다 많은** 영화 수를 등급별로 구하세요.

- 출력: `rating`, `films`, `above_avg` — `rating` 순

**사용 테이블:** `film`, `inventory`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT f.rating,
       COUNT(*) AS films,
       SUM(t.rentals > ra.avg_rentals) AS above_avg
FROM film f
JOIN (
    SELECT i.film_id, COUNT(*) AS rentals
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY i.film_id
) t ON t.film_id = f.film_id
JOIN (
    SELECT f2.rating, AVG(x.rentals) AS avg_rentals
    FROM film f2
    JOIN (
        SELECT i.film_id, COUNT(*) AS rentals
        FROM rental r
        JOIN inventory i ON i.inventory_id = r.inventory_id
        GROUP BY i.film_id
    ) x ON x.film_id = f2.film_id
    GROUP BY f2.rating
) ra ON ra.rating = f.rating
GROUP BY f.rating
ORDER BY f.rating;
```

</details>

<summary>실행 결과 보기</summary>

## 해설

같은 파생 테이블(영화별 대여 횟수)이 두 번 등장합니다. 이렇게 반복되면 **CTE(`WITH`)** 로 한 번만 정의하는 것이 좋습니다 (CTE 유형 참고).
재고가 없는 영화(42편)는 INNER JOIN 으로 빠져 있다는 점도 확인하세요.
