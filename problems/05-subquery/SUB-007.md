# SUB-007. SELECT 절의 스칼라 서브쿼리

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `스칼라 서브쿼리` `SELECT 절`

## 문제

장르별로 영화 수와 **전체 영화 대비 비율**(%)을 구하세요. 전체 영화 수는 SELECT 절 서브쿼리로 구합니다.

- 출력: `category`, `films`, `pct`(소수 1자리) — `films` 내림차순, `category` 순

**사용 테이블:** `category`, `film_category`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category,
       COUNT(*) AS films,
       ROUND(100 * COUNT(*) / (SELECT COUNT(*) FROM film), 1) AS pct
FROM category c
JOIN film_category fc ON fc.category_id = c.category_id
GROUP BY c.category_id, c.name
ORDER BY films DESC, category;
```

</details>

## 해설

바깥 쿼리와 무관한 스칼라 서브쿼리는 **한 번만 실행**되고 결과가 재사용됩니다. 윈도우 함수 `SUM(COUNT(*)) OVER ()` 로도 같은 값을 구할 수 있습니다.
