# SUB-004. 장르로 영화 찾기

**유형:** 서브쿼리 · **난이도:** ★☆☆☆☆ 입문 · **태그:** `IN 서브쿼리` `중첩`

## 문제

장르가 `Music` 인 영화 중 등급이 `G` 인 영화의 `film_id`, `title` 을 `film_id` 순으로 조회하세요.
`IN` 서브쿼리를 **두 번 중첩**해서 풀어 보세요.

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT film_id, title
FROM film
WHERE rating = 'G'
  AND film_id IN (
      SELECT film_id
      FROM film_category
      WHERE category_id IN (SELECT category_id FROM category WHERE name = 'Music')
  )
ORDER BY film_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| film_id | title |
|---|---|
| 581 | MINORITY KISS |
| 718 | REBEL AIRPORT |

> 총 2행

</details>

## 해설

서브쿼리는 여러 겹으로 중첩할 수 있습니다. 안쪽부터 읽으면 이해가 쉽습니다: Music 의 id → 그 장르의 영화 id → 영화.
