# SUB-031. 국가별 최고 결제 고객

**유형:** 서브쿼리 · **난이도:** ★★★★☆ 고급 · **태그:** `상관 서브쿼리` `파생 테이블` `greatest-n-per-group`

## 문제

국가별로 결제 합계가 가장 큰 고객(동점이면 모두)을 구하세요. 고객이 5명 이상인 국가만 대상입니다.

- 출력: `country`, `customer`(이름 성), `total` — `country`, `customer` 순

**사용 테이블:** `payment`, `customer`, `address`, `city`, `country`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT t.country, t.customer, t.total
FROM (
    SELECT co.country_id, co.country,
           CONCAT(c.first_name, ' ', c.last_name) AS customer,
           SUM(p.amount) AS total
    FROM payment p
    JOIN customer c ON c.customer_id = p.customer_id
    JOIN address a  ON a.address_id  = c.address_id
    JOIN city ci    ON ci.city_id    = a.city_id
    JOIN country co ON co.country_id = ci.country_id
    GROUP BY co.country_id, co.country, c.customer_id, c.first_name, c.last_name
) t
WHERE t.country_id IN (
    SELECT ci.country_id
    FROM customer c
    JOIN address a ON a.address_id = c.address_id
    JOIN city ci   ON ci.city_id   = a.city_id
    GROUP BY ci.country_id
    HAVING COUNT(*) >= 5
)
  AND t.total = (
    SELECT MAX(s.total) FROM (
        SELECT ci.country_id, SUM(p.amount) AS total
        FROM payment p
        JOIN customer c ON c.customer_id = p.customer_id
        JOIN address a  ON a.address_id  = c.address_id
        JOIN city ci    ON ci.city_id    = a.city_id
        GROUP BY ci.country_id, c.customer_id
    ) s
    WHERE s.country_id = t.country_id
)
ORDER BY t.country, t.customer;
```

</details>

## 해설

파생 테이블 + 상관 서브쿼리 + IN 을 조합한 복합 문제입니다. 같은 집계가 반복되어 쿼리가 길어지는데,
CTE 와 `RANK() OVER (PARTITION BY country ...)` 를 쓰면 절반 길이로 줄어듭니다. 두 풀이를 비교해 보는 것이 이 문제의 목적입니다.
