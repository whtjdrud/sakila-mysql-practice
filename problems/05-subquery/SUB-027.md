# SUB-027. 가장 많은 영화에 출연한 배우의 출연작

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `중첩 서브쿼리` `IN`

## 문제

출연 편수가 **가장 많은 배우**(동점이면 모두)의 출연작 수를 장르별로 구하세요.

- 출력: `actor`, `category`, `films` — `actor`, `films` 내림차순, `category` 순

**사용 테이블:** `actor`, `film_actor`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT CONCAT(a.first_name, ' ', a.last_name) AS actor,
       c.name AS category,
       COUNT(*) AS films
FROM actor a
JOIN film_actor fa    ON fa.actor_id    = a.actor_id
JOIN film_category fc ON fc.film_id     = fa.film_id
JOIN category c       ON c.category_id  = fc.category_id
WHERE a.actor_id IN (
    SELECT actor_id
    FROM film_actor
    GROUP BY actor_id
    HAVING COUNT(*) = (
        SELECT MAX(cnt) FROM (SELECT COUNT(*) AS cnt FROM film_actor GROUP BY actor_id) m
    )
)
GROUP BY a.actor_id, a.first_name, a.last_name, c.category_id, c.name
ORDER BY actor, films DESC, category;
```

## 해설

3단 중첩: ① 배우별 출연 수의 최댓값 → ② 그 값과 같은 배우 → ③ 그 배우의 장르별 집계.
`MAX(COUNT(*))` 처럼 집계 함수를 중첩할 수는 없으므로 파생 테이블로 한 번 감쌉니다.
