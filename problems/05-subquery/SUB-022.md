# SUB-022. 결제 합계 상위 1% 고객

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `스칼라 서브쿼리` `백분위` `LIMIT`

## 문제

고객 수(599명)의 **상위 약 1%(6명)** 에 해당하는 결제 합계 기준값(6번째로 큰 합계)을 구하고,
그 이상을 결제한 고객의 `customer_id`, `total` 을 조회하세요. `total` 내림차순, `customer_id` 순.

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, SUM(amount) AS total
FROM payment
GROUP BY customer_id
HAVING SUM(amount) >= (
    SELECT total FROM (
        SELECT SUM(amount) AS total
        FROM payment
        GROUP BY customer_id
        ORDER BY total DESC
        LIMIT 1 OFFSET 5
    ) x
)
ORDER BY total DESC, customer_id;
```

</details>

| 526 | 221.55 |

> 총 6행

</details>

## 해설

기준값을 먼저 구하고 "기준값 이상" 으로 거르면 **동점자를 모두 포함**할 수 있습니다. 그냥 `LIMIT 6` 은 동점자를 자릅니다.
MySQL 은 같은 테이블을 참조하는 서브쿼리에 LIMIT 를 쓸 때 제약이 있어 한 번 더 감쌌습니다.
