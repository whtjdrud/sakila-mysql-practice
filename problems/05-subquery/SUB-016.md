# SUB-016. 두 번째로 높은 결제 금액

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `스칼라 서브쿼리` `N번째 값`

## 문제

결제 금액의 **두 번째로 큰 서로 다른 값**을 구하세요.

- 출력: `second_max`

**사용 테이블:** `payment`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT MAX(amount) AS second_max
FROM payment
WHERE amount < (SELECT MAX(amount) FROM payment);
```

</details>

<details>
<summary>실행 결과 보기</summary>

| second_max |
|---|
| 10.99 |

> 총 1행

</details>

## 해설

"최댓값보다 작은 것 중 최댓값" 은 면접 단골 문제입니다.
N번째 값을 일반화하려면 `SELECT DISTINCT amount ... ORDER BY amount DESC LIMIT 1 OFFSET N-1` 이나 `DENSE_RANK()` 를 사용합니다.
