# SUB-026. 대여와 연결되지 않은 결제

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `NOT EXISTS` `데이터 품질`

## 문제

`payment` 중 **존재하는 대여와 연결되지 않은** 결제의 `payment_id`, `customer_id`, `amount`, `payment_date`, `rental_id` 를 조회하세요.
`payment_id` 순.

**사용 테이블:** `payment`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT p.payment_id, p.customer_id, p.amount, p.payment_date, p.rental_id
FROM payment p
WHERE NOT EXISTS (SELECT 1 FROM rental r WHERE r.rental_id = p.rental_id)
ORDER BY p.payment_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| payment_id | customer_id | amount | payment_date | rental_id |
|---|---|---|---|---|
| 424 | 16 | 1.99 | 2005-06-18 04:56:12 | NULL |
| 7011 | 259 | 1.99 | 2005-08-23 06:13:16 | NULL |
| 10840 | 401 | 0.99 | 2005-07-12 06:26:10 | NULL |
| 14675 | 546 | 3.99 | 2005-07-30 21:16:20 | NULL |
| 15458 | 577 | 0.99 | 2005-05-27 00:46:39 | NULL |

> 총 5행

</details>

## 해설

데이터 품질 점검의 기본: **"있어야 할 것이 없는 행"** 을 찾습니다. 결과는 `rental_id` 가 NULL 인 결제 5건입니다.
반대 방향(결제가 없는 대여)은 0건이므로, 모든 대여에는 결제가 있습니다. 양방향을 모두 확인하는 습관을 들이세요.
