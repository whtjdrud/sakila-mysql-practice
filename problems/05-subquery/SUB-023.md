# SUB-023. 대여 횟수 중앙값

**유형:** 서브쿼리 · **난이도:** ★★★★☆ 고급 · **태그:** `중앙값` `상관 서브쿼리` `파생 테이블`

## 문제

고객별 대여 횟수의 **중앙값(median)** 을 구하세요. 윈도우 함수 없이 서브쿼리만 사용하세요.

- 출력: `median_rentals`

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT AVG(t.rentals) AS median_rentals
FROM (
    SELECT customer_id, COUNT(*) AS rentals
    FROM rental
    GROUP BY customer_id
) t
WHERE (SELECT COUNT(*) FROM (SELECT customer_id, COUNT(*) AS rentals FROM rental GROUP BY customer_id) a
        WHERE a.rentals < t.rentals) * 2 < (SELECT COUNT(DISTINCT customer_id) FROM rental)
  AND (SELECT COUNT(*) FROM (SELECT customer_id, COUNT(*) AS rentals FROM rental GROUP BY customer_id) b
        WHERE b.rentals > t.rentals) * 2 < (SELECT COUNT(DISTINCT customer_id) FROM rental);
```

</details>

## 해설

중앙값 = "자기보다 작은 값이 절반 미만이고, 큰 값도 절반 미만인 값". 그런 값들의 평균을 내면 홀수·짝수 개수 모두 처리됩니다.
MySQL 에는 `MEDIAN()` 함수가 없어 이런 트릭이 필요합니다. 윈도우 함수(`ROW_NUMBER` + `COUNT() OVER`)로 훨씬 간단히 풀 수 있습니다 (WIN 유형 참고).
