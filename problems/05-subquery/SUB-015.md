# SUB-015. ANY 와 ALL

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `ALL` `ANY` `비교 연산자`

## 문제

상영 시간이 **모든 `Children` 장르 영화보다 긴** 영화의 수 `longer_than_all` 과,
**어떤 `Children` 영화보다라도 긴**(=최소보다 긴) 영화의 수 `longer_than_any` 를 한 행으로 구하세요.

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT
  (SELECT COUNT(*) FROM film
    WHERE length > ALL (SELECT f.length FROM film f
                        JOIN film_category fc ON fc.film_id = f.film_id
                        JOIN category c ON c.category_id = fc.category_id
                        WHERE c.name = 'Children')) AS longer_than_all,
  (SELECT COUNT(*) FROM film
    WHERE length > ANY (SELECT f.length FROM film f
                        JOIN film_category fc ON fc.film_id = f.film_id
                        JOIN category c ON c.category_id = fc.category_id
                        WHERE c.name = 'Children')) AS longer_than_any;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| longer_than_all | longer_than_any |
|---|---|
| 59 | 995 |

> 총 1행

</details>

## 해설

`> ALL (...)` 은 `> MAX(...)`, `> ANY (...)` 는 `> MIN(...)` 과 같습니다. (`= ANY` 는 `IN` 과 같습니다.)
단, 서브쿼리가 **빈 집합**이면 `> ALL` 은 참, `> ANY` 는 거짓이 되고, NULL 이 섞이면 결과가 달라질 수 있어 MAX/MIN 이 더 예측 가능합니다.
