# SUB-021. HAVING 절 서브쿼리

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `HAVING` `스칼라 서브쿼리`

## 문제

출연 편수가 **배우 평균 출연 편수보다 많은** 배우의 수를 구하세요.

- 출력: `actors`, `avg_films`(배우 평균 출연 편수, 소수 2자리)

**사용 테이블:** `film_actor`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT COUNT(*) AS actors,
       (SELECT ROUND(COUNT(*) / COUNT(DISTINCT actor_id), 2) FROM film_actor) AS avg_films
FROM (
    SELECT actor_id
    FROM film_actor
    GROUP BY actor_id
    HAVING COUNT(*) > (SELECT COUNT(*) / COUNT(DISTINCT actor_id) FROM film_actor)
) t;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| actors | avg_films |
|---|---|
| 94 | 27.31 |

> 총 1행

</details>

## 해설

HAVING 에도 서브쿼리를 쓸 수 있습니다. 그룹 집계값을 전체 기준값과 비교할 때 사용합니다.
"배우 평균 출연 편수" 는 `전체 출연 기록 수 / 배우 수` 로 바로 구할 수 있습니다 (평균의 정의).
