# SUB-030. 직전 대여와의 간격

**유형:** 서브쿼리 · **난이도:** ★★★★☆ 고급 · **태그:** `상관 서브쿼리` `이전 행 찾기`

## 문제

고객 1번의 대여마다 **직전 대여일**과의 간격(일)을 구하세요. 윈도우 함수 없이 상관 서브쿼리를 사용하세요.

- 출력: `rental_id`, `rental_date`, `prev_rental_date`, `gap_days` — `rental_date`, `rental_id` 순
- 첫 대여의 이전 값은 NULL

**사용 테이블:** `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT r.rental_id, r.rental_date,
       (SELECT MAX(r2.rental_date) FROM rental r2
         WHERE r2.customer_id = r.customer_id AND r2.rental_date < r.rental_date) AS prev_rental_date,
       DATEDIFF(r.rental_date,
                (SELECT MAX(r2.rental_date) FROM rental r2
                  WHERE r2.customer_id = r.customer_id AND r2.rental_date < r.rental_date)) AS gap_days
FROM rental r
WHERE r.customer_id = 1
ORDER BY r.rental_date, r.rental_id;
```

## 해설

"나보다 이전 것 중 가장 늦은 것" = 직전 값. 윈도우 함수 `LAG(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date)` 와 같습니다.
같은 서브쿼리를 두 번 써야 하는 불편함이 있어 파생 테이블로 한 번 감싸거나 LAG 를 쓰는 편이 좋습니다.
