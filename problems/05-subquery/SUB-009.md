# SUB-009. 장르 평균보다 긴 영화 (상관 서브쿼리)

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `상관 서브쿼리` `WHERE` `그룹 평균 비교`

## 문제

**자기 장르의 평균 상영 시간보다** 긴 영화의 수를 장르별로 구하세요.

- 출력: `category`, `films_above_avg` — `category` 순

**사용 테이블:** `film`, `film_category`, `category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category, COUNT(*) AS films_above_avg
FROM film f
JOIN film_category fc ON fc.film_id     = f.film_id
JOIN category c       ON c.category_id  = fc.category_id
WHERE f.length > (
    SELECT AVG(f2.length)
    FROM film f2
    JOIN film_category fc2 ON fc2.film_id = f2.film_id
    WHERE fc2.category_id = fc.category_id
)
GROUP BY c.category_id, c.name
ORDER BY category;
```

</details>

## 해설

"전체 평균"이 아니라 **"내가 속한 그룹의 평균"** 과 비교할 때 상관 서브쿼리를 씁니다.
같은 결과를 파생 테이블(장르별 평균을 미리 계산 후 조인)이나 윈도우 함수 `AVG() OVER (PARTITION BY ...)` 로도 낼 수 있으니 세 방법을 모두 써 보세요.
