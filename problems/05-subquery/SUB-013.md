# SUB-013. G 등급을 한 번도 빌리지 않은 고객

**유형:** 서브쿼리 · **난이도:** ★★★☆☆ 중급 · **태그:** `NOT EXISTS` `조인 서브쿼리`

## 문제

**G 등급 영화를 한 번도 빌리지 않은** 고객의 `customer_id`, 이름 `name`, 전체 대여 횟수 `rentals` 를 구하세요. `customer_id` 순.

**사용 테이블:** `customer`, `rental`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id,
       CONCAT(c.first_name, ' ', c.last_name) AS name,
       (SELECT COUNT(*) FROM rental r WHERE r.customer_id = c.customer_id) AS rentals
FROM customer c
WHERE NOT EXISTS (
    SELECT 1
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.customer_id = c.customer_id
      AND f.rating = 'G'
)
ORDER BY c.customer_id;
```

</details>

## 해설

NOT EXISTS 서브쿼리 안에서도 조인을 자유롭게 쓸 수 있습니다. 결과는 6명입니다.
"오직 X 만 빌린 고객" 은 "X 가 아닌 것을 빌린 적이 **없는** 고객" 으로 바꿔 같은 패턴으로 풀 수 있습니다.
(참고: G·PG 를 모두 피한 고객은 0명입니다.)
