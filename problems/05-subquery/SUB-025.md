# SUB-025. 다른 매장 고객에게도 인기 있는 영화

**유형:** 서브쿼리 · **난이도:** ★★★★☆ 고급 · **태그:** `IN` `교집합`

## 문제

1번 매장 고객의 대여 TOP 50 영화 **이면서** 2번 매장 고객의 대여 TOP 50 영화인 영화를 구하세요.
(각 TOP 50 은 대여 횟수 내림차순, `film_id` 순으로 정확히 50편)

- 출력: `film_id`, `title` — `film_id` 순

**사용 테이블:** `rental`, `customer`, `inventory`, `film`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT f.film_id, f.title
FROM film f
WHERE f.film_id IN (
    SELECT film_id FROM (
        SELECT i.film_id
        FROM rental r
        JOIN customer c  ON c.customer_id  = r.customer_id
        JOIN inventory i ON i.inventory_id = r.inventory_id
        WHERE c.store_id = 1
        GROUP BY i.film_id
        ORDER BY COUNT(*) DESC, i.film_id
        LIMIT 50
    ) s1
)
  AND f.film_id IN (
    SELECT film_id FROM (
        SELECT i.film_id
        FROM rental r
        JOIN customer c  ON c.customer_id  = r.customer_id
        JOIN inventory i ON i.inventory_id = r.inventory_id
        WHERE c.store_id = 2
        GROUP BY i.film_id
        ORDER BY COUNT(*) DESC, i.film_id
        LIMIT 50
    ) s2
)
ORDER BY f.film_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| film_id | title |
|---|---|
| 103 | BUCKET BROTHERHOOD |
| 489 | JUGGLER HARDLY |

> 총 2행

</details>

## 해설

MySQL 은 `IN (SELECT ... LIMIT n)` 을 직접 지원하지 않습니다(`This version of MySQL doesn't yet support 'LIMIT & IN'`).
파생 테이블로 **한 번 더 감싸면** 우회할 수 있습니다. MySQL 8.0.31+ 라면 `INTERSECT` 로도 풀 수 있습니다.
결과는 단 **2편** — 두 매장 고객의 인기작 목록은 거의 겹치지 않습니다. (TOP 30 으로 줄이면 1편)
