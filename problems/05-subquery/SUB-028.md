# SUB-028. LATERAL 파생 테이블

**유형:** 서브쿼리 · **난이도:** ★★★★☆ 고급 · **태그:** `LATERAL` `그룹별 TOP N`

## 문제

장르마다 **대여 횟수 TOP 3 영화**를 구하세요. MySQL 8.0.14+ 의 `LATERAL` 을 사용해 보세요.

- 출력: `category`, `title`, `rentals` — `category`, `rentals` 내림차순, `title` 순

**사용 테이블:** `category`, `film_category`, `film`, `inventory`, `rental`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.name AS category, t.title, t.rentals
FROM category c
JOIN LATERAL (
    SELECT f.title, COUNT(*) AS rentals
    FROM film_category fc
    JOIN film f      ON f.film_id      = fc.film_id
    JOIN inventory i ON i.film_id      = f.film_id
    JOIN rental r    ON r.inventory_id = i.inventory_id
    WHERE fc.category_id = c.category_id
    GROUP BY f.film_id, f.title
    ORDER BY rentals DESC, f.title
    LIMIT 3
) t ON TRUE
ORDER BY category, t.rentals DESC, t.title;
```

## 해설

일반 파생 테이블은 바깥 테이블을 참조할 수 없지만, `LATERAL` 을 붙이면 **바깥 행(c)을 참조하는 상관 파생 테이블**이 됩니다.
"그룹마다 LIMIT N" 을 자연스럽게 표현할 수 있습니다. 윈도우 함수 `ROW_NUMBER()` 풀이와 비교해 보세요.
