# SUB-024. 같은 영화를 여러 번 빌린 고객

**유형:** 서브쿼리 · **난이도:** ★★☆☆☆ 초급 · **태그:** `파생 테이블` `HAVING`

## 문제

같은 영화를 **2번 이상** 빌린 적이 있는 고객의 수를 구하세요.

- 출력: `customers`

**사용 테이블:** `rental`, `inventory`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT COUNT(DISTINCT customer_id) AS customers
FROM (
    SELECT r.customer_id, i.film_id
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    GROUP BY r.customer_id, i.film_id
    HAVING COUNT(*) >= 2
) t;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| customers |
|---|
| 180 |

> 총 1행

</details>

## 해설

(고객, 영화) 쌍으로 그룹을 만든 뒤 HAVING 으로 거르고, 바깥에서 고객 수를 셉니다. **"어떤 조합이 반복되는가"** 를 찾는 패턴입니다.
