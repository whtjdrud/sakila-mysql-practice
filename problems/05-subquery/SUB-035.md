# SUB-035. 연속으로 같은 장르를 빌린 횟수

**유형:** 서브쿼리 · **난이도:** ★★★★★ 최고급 · **태그:** `상관 서브쿼리` `직전 행 비교`

## 문제

고객 1~5번 각각에 대해, 대여를 시간순으로 나열했을 때 **바로 직전 대여와 같은 장르**를 빌린 횟수를 구하세요.
윈도우 함수 없이 상관 서브쿼리로 직전 대여를 찾으세요 (같은 시각이면 `rental_id` 가 작은 것이 먼저).

- 출력: `customer_id`, `rentals`, `same_genre_streaks` — `customer_id` 순

**사용 테이블:** `rental`, `inventory`, `film_category`

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT x.customer_id, COUNT(*) AS rentals,
       SUM(x.category_id = (
           SELECT fc2.category_id
           FROM rental r2
           JOIN inventory i2      ON i2.inventory_id = r2.inventory_id
           JOIN film_category fc2 ON fc2.film_id     = i2.film_id
           WHERE r2.customer_id = x.customer_id
             AND (r2.rental_date < x.rental_date
                  OR (r2.rental_date = x.rental_date AND r2.rental_id < x.rental_id))
           ORDER BY r2.rental_date DESC, r2.rental_id DESC
           LIMIT 1
       )) AS same_genre_streaks
FROM (
    SELECT r.rental_id, r.customer_id, r.rental_date, fc.category_id
    FROM rental r
    JOIN inventory i      ON i.inventory_id = r.inventory_id
    JOIN film_category fc ON fc.film_id     = i.film_id
    WHERE r.customer_id <= 5
) x
GROUP BY x.customer_id
ORDER BY x.customer_id;
```

</details>

| customer_id | rentals | same_genre_streaks |
|---|---|---|
| 1 | 32 | 3 |
| 2 | 27 | 2 |
| 3 | 26 | 2 |
| 4 | 22 | 0 |
| 5 | 38 | 3 |

## 해설

"직전 행" 을 정확히 정의하려면 **동점 처리**(같은 시각)까지 정렬 조건에 넣어야 합니다: `(날짜, id)` 의 사전식 비교.
첫 대여는 직전 행이 없어 비교 결과가 NULL 이 되고, `SUM` 은 NULL 을 무시하므로 자연스럽게 제외됩니다.
`LAG(category_id) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id)` 로 다시 풀어 결과를 비교해 보세요.
