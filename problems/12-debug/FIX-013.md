# FIX-013. 비율이 전부 0 (DIV 정수 나눗셈)

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `DIV` `나눗셈` `형 변환` `디버깅`

## 문제

**증상:** 등급별 "대여료 4.99 영화 비율(%)" 이 전부 0 으로 나옵니다.

```sql
SELECT rating, SUM(rental_rate = 4.99) DIV COUNT(*) * 100 AS premium_pct
FROM film
GROUP BY rating
ORDER BY rating;
```

소수 1자리 백분율이 나오도록 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rating, ROUND(100 * SUM(rental_rate = 4.99) / COUNT(*), 1) AS premium_pct
FROM film
GROUP BY rating
ORDER BY rating;
```

</details>

## 해설

**원인:** `DIV` 는 **정수 나눗셈**이라 (예) 60 DIV 200 = 0, 거기에 100 을 곱해도 0 입니다. 다른 DBMS(SQL Server, PostgreSQL)에서는 정수 `/` 정수도 정수 나눗셈입니다.
**수정:** MySQL 은 `/` 가 소수 결과를 주므로 `/` 를 쓰고, 다른 DBMS 로 옮길 코드라면 `100.0 * a / b` 처럼 **먼저 소수로 만들고** 나누세요.
