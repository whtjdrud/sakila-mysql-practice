# FIX-010. 마지막 대여의 영화 제목 (ONLY_FULL_GROUP_BY)

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `GROUP BY` `ONLY_FULL_GROUP_BY` `그룹별 최신 행` `디버깅`

## 문제

**요청:** 고객 1~5번의 마지막 대여 일시와 **그때 빌린 영화 제목**. 아래 쿼리는 오류가 납니다:
`Expression #3 of SELECT list is not in GROUP BY clause ... incompatible with sql_mode=only_full_group_by`

```sql
SELECT r.customer_id, MAX(r.rental_date) AS last_rental, f.title
FROM rental r
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id      = i.film_id
WHERE r.customer_id <= 5
GROUP BY r.customer_id
ORDER BY r.customer_id;
```

의도대로(마지막 대여 1건의 제목, 같은 시각이면 `rental_id` 가 큰 것) 동작하게 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, last_rental, title
FROM (
    SELECT r.customer_id, r.rental_date AS last_rental, f.title,
           ROW_NUMBER() OVER (PARTITION BY r.customer_id ORDER BY r.rental_date DESC, r.rental_id DESC) AS rn
    FROM rental r
    JOIN inventory i ON i.inventory_id = r.inventory_id
    JOIN film f      ON f.film_id      = i.film_id
    WHERE r.customer_id <= 5
) t
WHERE rn = 1
ORDER BY customer_id;
```

</details>

## 해설

**원인:** `MAX(rental_date)` 는 그룹에서 최댓값 **하나**를 계산할 뿐, "그 최댓값을 가진 행의 다른 컬럼" 을 가져오지 않습니다. 고객의 대여가 30건이면 `f.title` 후보도 30개라 MySQL 이 거부합니다.
**수정:** 그룹별 최신 행이 필요하면 `ROW_NUMBER()` 로 1등 행을 고르거나, `(customer_id, MAX(rental_date))` 를 구해 다시 조인합니다 (SUB-020).
⚠️ `ANY_VALUE(f.title)` 로 오류만 끄면 **아무 대여의 제목**이 나와 조용히 틀린 답이 됩니다. 예전 MySQL(5.6 이하)은 기본 설정이 이랬기 때문에 레거시 쿼리에서 자주 발견되는 버그입니다.
