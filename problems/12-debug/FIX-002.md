# FIX-002. 영화가 없는 언어가 1편? (COUNT(*) 함정)

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `COUNT` `LEFT JOIN` `디버깅`

## 문제

**증상:** 영화가 한 편도 없는 언어(Italian, Japanese …)가 **1편**으로 나옵니다.

```sql
SELECT l.name AS language, COUNT(*) AS films
FROM language l
LEFT JOIN film f ON f.language_id = l.language_id
GROUP BY l.language_id, l.name
ORDER BY films DESC, language;
```

영화가 없는 언어는 0 이 나오도록 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT l.name AS language, COUNT(f.film_id) AS films
FROM language l
LEFT JOIN film f ON f.language_id = l.language_id
GROUP BY l.language_id, l.name
ORDER BY films DESC, language;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| language | films |
|---|---|
| English | 1000 |
| French | 0 |
| German | 0 |
| Italian | 0 |
| Japanese | 0 |
| Mandarin | 0 |

> 총 6행

</details>

## 해설

**원인:** LEFT JOIN 은 매칭이 없을 때 오른쪽을 NULL 로 채운 **행 1개**를 만듭니다. `COUNT(*)` 는 그 행도 셉니다.
**수정:** 오른쪽 테이블의 NOT NULL 컬럼(보통 PK)을 `COUNT(f.film_id)` 로 세면 NULL 이 빠져 0 이 됩니다.
