# FIX-009. 윈도우 함수를 WHERE 에 써서 오류

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `윈도우 함수` `WHERE` `파생 테이블` `디버깅`

## 문제

**증상:** 아래 쿼리는 `You cannot use the window function 'row_number' in this context` 오류가 납니다.

```sql
SELECT c.name AS category, f.title, f.length
FROM film f
JOIN film_category fc ON fc.film_id = f.film_id
JOIN category c ON c.category_id = fc.category_id
WHERE ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY f.length DESC, f.title) = 1
ORDER BY category;
```

의도(장르별 가장 긴 영화 1편, 동점이면 제목순)대로 동작하게 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT category, title, length
FROM (
    SELECT c.name AS category, f.title, f.length,
           ROW_NUMBER() OVER (PARTITION BY c.category_id ORDER BY f.length DESC, f.title) AS rn
    FROM film f
    JOIN film_category fc ON fc.film_id    = f.film_id
    JOIN category c       ON c.category_id = fc.category_id
) t
WHERE rn = 1
ORDER BY category;
```

## 해설

**원인:** 윈도우 함수는 WHERE·GROUP BY·HAVING **이후**(SELECT 단계)에 계산되므로 WHERE 에서 참조할 수 없습니다.
**수정:** 파생 테이블이나 CTE 에서 먼저 계산하고 바깥에서 거릅니다. (MySQL 은 Snowflake 의 `QUALIFY` 를 지원하지 않습니다.)
