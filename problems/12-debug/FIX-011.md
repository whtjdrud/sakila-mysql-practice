# FIX-011. 잘못된 조인 키

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `조인 키` `카테시안` `디버깅`

## 문제

**요청:** 결제 건별로 어떤 영화의 대여인지 붙이기 (`payment_id` 1~10). 그런데 결과가 수백 행이나 나옵니다.

```sql
SELECT p.payment_id, p.amount, f.title
FROM payment p
JOIN rental r    ON r.customer_id = p.customer_id
JOIN inventory i ON i.inventory_id = r.inventory_id
JOIN film f      ON f.film_id = i.film_id
WHERE p.payment_id <= 10
ORDER BY p.payment_id;
```

결제 1건당 정확히 1행이 나오도록 고치세요.

SELECT p.payment_id, p.amount, f.title

## 해설

**원인:** 결제와 대여를 **고객 번호**로 이으면 "그 고객의 모든 대여" 와 짝지어집니다 (결제 1건 × 대여 32건).
**수정:** 두 테이블을 잇는 진짜 관계는 FK `payment.rental_id → rental.rental_id` 입니다. 조인 전에 스키마 탐색에서 **FK 관계**를 확인하세요.
"결과 행 수가 기대보다 많다" 는 대부분 조인 키 문제입니다.
