# FIX-001. 사라진 고객들 (LEFT JOIN + WHERE)

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `LEFT JOIN` `ON vs WHERE` `디버깅`

## 문제

**요청:** "모든 고객의 2005년 5월 대여 건수(없으면 0)" — 그런데 아래 쿼리는 599명이 아니라 **520명**만 나옵니다.

```sql
SELECT c.customer_id, COUNT(r.rental_id) AS may_rentals
FROM customer c
LEFT JOIN rental r ON r.customer_id = c.customer_id
WHERE r.rental_date >= '2005-05-01' AND r.rental_date < '2005-06-01'
GROUP BY c.customer_id
ORDER BY c.customer_id;
```

599명 모두 나오도록 고친 쿼리를 작성하세요. 출력 컬럼과 정렬은 그대로입니다.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id, COUNT(r.rental_id) AS may_rentals
FROM customer c
LEFT JOIN rental r ON r.customer_id = c.customer_id
                  AND r.rental_date >= '2005-05-01' AND r.rental_date < '2005-06-01'
GROUP BY c.customer_id
ORDER BY c.customer_id;
```

## 해설

**원인:** 5월 대여가 없는 고객은 LEFT JOIN 결과에서 `r.rental_date` 가 NULL 인데, WHERE 의 비교가 NULL → 거짓 처리되어 행이 지워집니다. LEFT JOIN 이 INNER JOIN 이 된 것이죠.
**수정:** 오른쪽 테이블에 대한 조건은 **ON 절**로 옮깁니다. "LEFT JOIN 했는데 건수가 줄었다" 면 가장 먼저 의심할 곳입니다.
