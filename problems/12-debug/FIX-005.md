# FIX-005. 마지막 날이 빠진 기간 집계 (BETWEEN)

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `BETWEEN` `DATETIME` `반열린 구간` `디버깅`

## 문제

**요청:** 2005-07-31 하루를 포함한 **2005-07-25 ~ 2005-07-31** 대여 건수. 그런데 아래 쿼리는 실제(3,256건)보다 **679건 적게** 나옵니다.

```sql
SELECT COUNT(*) AS rentals
FROM rental
WHERE rental_date BETWEEN '2005-07-25' AND '2005-07-31';
```

고친 쿼리를 작성하세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT COUNT(*) AS rentals
FROM rental
WHERE rental_date >= '2005-07-25' AND rental_date < '2005-08-01';
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rentals |
|---|
| 3256 |

> 총 1행

</details>

## 해설

**원인:** `'2005-07-31'` 은 DATETIME 과 비교할 때 `2005-07-31 00:00:00` 이 되어, 31일 0시 이후 대여(679건)가 모두 빠집니다.
**수정:** 반열린 구간 `>= 시작일 AND < 종료일 다음 날`. `BETWEEN '...' AND '2005-07-31 23:59:59'` 는 밀리초가 있는 컬럼에서 여전히 빈틈이 생깁니다.
