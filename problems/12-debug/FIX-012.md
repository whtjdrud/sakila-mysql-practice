# FIX-012. 주소가 통째로 NULL (CONCAT 과 NULL)

**유형:** 쿼리 디버깅 · **난이도:** ★★☆☆☆ 초급 · **태그:** `CONCAT` `CONCAT_WS` `NULL` `디버깅`

## 문제

**요청:** 주소 1~6번의 전체 주소 문자열(`address`, `address2`, `district` 를 `, ` 로 연결). 그런데 일부 행이 **NULL** 로 나옵니다.

```sql
SELECT address_id, CONCAT(address, ', ', address2, ', ', district) AS full_address
FROM address
WHERE address_id <= 6
ORDER BY address_id;
```

값이 없는 부분은 건너뛰도록 고치세요. (빈 문자열도 건너뜁니다)

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT address_id,
       CONCAT_WS(', ', NULLIF(address, ''), NULLIF(address2, ''), NULLIF(district, '')) AS full_address
FROM address
WHERE address_id <= 6
ORDER BY address_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| address_id | full_address |
|---|---|
| 1 | 47 MySakila Drive, Alberta |
| 2 | 28 MySQL Boulevard, QLD |
| 3 | 23 Workhaven Lane, Alberta |
| 4 | 1411 Lillydale Drive, QLD |
| 5 | 1913 Hanoi Way, Nagasaki |
| 6 | 1121 Loja Avenue, California |

> 총 6행

</details>

## 해설

**원인:** `CONCAT` 은 인자 하나라도 NULL 이면 결과 전체가 NULL 입니다. 주소 1~4번은 `address2` 가 NULL 입니다.
**수정:** `CONCAT_WS(구분자, ...)` 는 NULL 인자를 건너뜁니다. 빈 문자열은 건너뛰지 않으므로 `NULLIF(x, '')` 로 NULL 로 바꿔 함께 처리했습니다 (주소 5·6번은 `address2` 가 빈 문자열).
