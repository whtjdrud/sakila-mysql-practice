# FIX-003. 매출이 두 배로? (조인 팬아웃)

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `팬아웃` `SUM` `집계 후 조인` `디버깅`

## 문제

**요청:** 고객 1~5번의 총 결제액과 총 대여 횟수. 그런데 결제액이 재무팀 숫자보다 **훨씬 큽니다.**

```sql
SELECT c.customer_id, SUM(p.amount) AS total_paid, COUNT(r.rental_id) AS rentals
FROM customer c
JOIN payment p ON p.customer_id = c.customer_id
JOIN rental r  ON r.customer_id = c.customer_id
WHERE c.customer_id <= 5
GROUP BY c.customer_id
ORDER BY c.customer_id;
```

정확한 `total_paid`, `rentals` 가 나오도록 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT c.customer_id, p.total_paid, r.rentals
FROM customer c
JOIN (SELECT customer_id, SUM(amount) AS total_paid FROM payment GROUP BY customer_id) p
  ON p.customer_id = c.customer_id
JOIN (SELECT customer_id, COUNT(*) AS rentals FROM rental GROUP BY customer_id) r
  ON r.customer_id = c.customer_id
WHERE c.customer_id <= 5
ORDER BY c.customer_id;
```

</details>

## 해설

**원인:** 고객 1명에 결제 32건, 대여 32건이면 조인 결과는 32 × 32 = 1,024행이 되어 결제액이 **32배**로 부풀려집니다 (1:N 두 개를 한 번에 조인한 **팬아웃**).
**수정:** 각 테이블을 **고객 단위로 먼저 집계**한 뒤 조인합니다. `COUNT(DISTINCT ...)` 로 건수는 고칠 수 있어도 SUM 은 고칠 수 없습니다.
