# FIX-016. 평균의 평균

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `평균` `가중 평균` `집계 단위` `디버깅`

## 문제

**요청:** "전체 결제의 건당 평균 금액" (= 모든 결제 금액의 평균). 그런데 아래 쿼리는 미세하게 다른 값을 냅니다.

```sql
SELECT ROUND(AVG(avg_amount), 4) AS avg_payment
FROM (
    SELECT customer_id, AVG(amount) AS avg_amount
    FROM payment
    GROUP BY customer_id
) t;
```

요청대로의 값과, 원래 쿼리의 값을 나란히 구하세요.

- 출력: `correct_avg`, `avg_of_avgs` (둘 다 소수 4자리)

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT ROUND((SELECT AVG(amount) FROM payment), 4) AS correct_avg,
       ROUND((SELECT AVG(avg_amount)
              FROM (SELECT customer_id, AVG(amount) AS avg_amount FROM payment GROUP BY customer_id) t), 4) AS avg_of_avgs;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| correct_avg | avg_of_avgs |
|---|---|
| 4.2007 | 4.1979 |

> 총 1행

</details>

## 해설

**원인:** "고객별 평균의 평균" 은 결제가 1건인 고객과 40건인 고객에게 **같은 가중치**를 줍니다. 건당 평균과는 다른 지표입니다.
**수정:** 원하는 단위(결제 건)에서 바로 평균을 내거나, `SUM(합계) / SUM(건수)` 로 가중 평균을 냅니다.
둘 중 어느 것이 맞는지는 질문에 달려 있습니다 — "평균적인 고객의 평균 결제액" 이라면 오히려 평균의 평균이 정답입니다.
