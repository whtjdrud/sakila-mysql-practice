# FIX-007. 이전 고객의 값이 섞임 (PARTITION BY 누락)

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `LAG` `PARTITION BY` `디버깅`

## 문제

**요청:** 고객 1~3번의 **각 고객의 첫 대여**는 직전 대여 간격이 NULL 이어야 합니다. 그런데 고객 2번의 첫 대여에 고객 1번의 마지막 대여 날짜가 들어갑니다.

```sql
SELECT customer_id, rental_id, rental_date,
       DATEDIFF(rental_date, LAG(rental_date) OVER (ORDER BY customer_id, rental_date, rental_id)) AS gap_days
FROM rental
WHERE customer_id <= 3
ORDER BY customer_id, rental_date, rental_id;
```

고친 쿼리를 작성하세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, rental_id, rental_date,
       DATEDIFF(rental_date, LAG(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id)) AS gap_days
FROM rental
WHERE customer_id <= 3
ORDER BY customer_id, rental_date, rental_id;
```

## 해설

**원인:** PARTITION BY 가 없으면 윈도우는 **전체 결과 하나**라서, 정렬상 바로 앞 행(다른 고객)의 값을 가져옵니다. 음수 간격이 나오는 것도 이 때문입니다.
**수정:** "고객별" 계산이면 `PARTITION BY customer_id`. `ORDER BY customer_id` 를 넣는 것으로는 경계가 나뉘지 않습니다.
