# FIX-004. 결과가 0행 (NOT IN 과 NULL)

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `NOT IN` `NULL` `NOT EXISTS` `디버깅`

## 문제

**요청:** 영화의 원어(`original_language_id`)로 쓰인 적 없는 언어 목록. 그런데 결과가 **0행**입니다.

```sql
SELECT name
FROM language
WHERE language_id NOT IN (SELECT original_language_id FROM film)
ORDER BY name;
```

올바른 결과가 나오도록 고치세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT name
FROM language l
WHERE NOT EXISTS (SELECT 1 FROM film f WHERE f.original_language_id = l.language_id)
ORDER BY name;
```

## 해설

**원인:** `original_language_id` 는 모두 NULL 입니다. `x NOT IN (NULL, ...)` 은 항상 NULL(거짓 취급)이라 아무 행도 남지 않습니다.
**수정:** `NOT EXISTS` 로 바꾸거나, 서브쿼리에 `WHERE original_language_id IS NOT NULL` 을 추가합니다. (SUB-006 참고)
