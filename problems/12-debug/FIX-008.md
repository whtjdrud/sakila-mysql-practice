# FIX-008. 마지막 값이 자기 자신 (LAST_VALUE 프레임)

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `LAST_VALUE` `윈도우 프레임` `디버깅`

## 문제

**요청:** 고객 1~3번의 **마지막 대여일**을 모든 행에 붙이기. 그런데 `last_rental` 이 매 행의 `rental_date` 와 똑같습니다.

```sql
SELECT customer_id, rental_id, rental_date,
       LAST_VALUE(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id) AS last_rental
FROM rental
WHERE customer_id <= 3
ORDER BY customer_id, rental_date, rental_id;
```

고친 쿼리를 작성하세요.

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT customer_id, rental_id, rental_date,
       LAST_VALUE(rental_date) OVER (PARTITION BY customer_id ORDER BY rental_date, rental_id
                                     ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS last_rental
FROM rental
WHERE customer_id <= 3
ORDER BY customer_id, rental_date, rental_id;
```

## 해설

**원인:** ORDER BY 가 있는 윈도우의 기본 프레임은 "처음 ~ **현재 행**" 이라, 프레임의 마지막 값 = 현재 행입니다.
**수정:** 프레임을 파티션 전체로 넓히거나, 더 간단히 `MAX(rental_date) OVER (PARTITION BY customer_id)` 를 씁니다.
