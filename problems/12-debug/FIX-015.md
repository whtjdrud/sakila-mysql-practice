# FIX-015. 동점자가 잘린 TOP 3

**유형:** 쿼리 디버깅 · **난이도:** ★★★☆☆ 중급 · **태그:** `LIMIT` `RANK` `동점` `디버깅`

## 문제

**요청:** "결제 합계 TOP 3 고객에게 상품 지급, **동점자는 모두 포함**". 그런데 아래 쿼리는 4위와 동점인 3위 고객 중 한 명을 빠뜨립니다... 혹은 빠뜨릴 수 있습니다.

```sql
SELECT customer_id, SUM(amount) AS total
FROM payment
GROUP BY customer_id
ORDER BY total DESC
LIMIT 3;
```

동점을 포함해 **결제 합계 4위까지**(공동 4위 포함) 모든 고객이 나오도록 고치세요. (현재 데이터에서 4위가 동점입니다)

- 출력: `rnk`, `customer_id`, `total` — `rnk`, `customer_id` 순

<details>
<summary>정답 쿼리 보기</summary>

```sql
SELECT rnk, customer_id, total
FROM (
    SELECT customer_id, SUM(amount) AS total,
           RANK() OVER (ORDER BY SUM(amount) DESC) AS rnk
    FROM payment
    GROUP BY customer_id
) t
WHERE rnk <= 4
ORDER BY rnk, customer_id;
```

</details>

<details>
<summary>실행 결과 보기</summary>

| rnk | customer_id | total |
|---|---|---|
| 1 | 526 | 221.55 |
| 2 | 148 | 216.54 |
| 3 | 144 | 195.58 |
| 4 | 137 | 194.61 |
| 4 | 178 | 194.61 |

> 총 5행

</details>

## 해설

**원인:** `LIMIT n` 은 정렬 후 **정확히 n행**만 남기므로 경계의 동점자를 임의로 자릅니다. 2차 정렬이 없으면 누가 잘릴지도 실행마다 달라질 수 있습니다.
**수정:** "N위까지" 는 `RANK() <= N`. 4위가 공동(MARION SNYDER, RHONDA KENNEDY)이라 5명이 나옵니다.
